# 事件与可观察性

如何用事件理解、展示和诊断一次执行？

## 叙述方向

从一次工具执行的界面变化反推事件，解释事件生成、传输、消费和历史展示的关系，再观察连接结束与断连边界。沿一条任务关联模型、步骤、工具和产物的记录，说明如何定位耗时、错误与缺失反馈；区分已有事件能力与待补追踪手段。

## 材料与范围

主要载体：RayAgent；按需对照异步 labs。材料与实现入口见 [素材索引](map.md#chapter-materials)。

区分模型 token 流与产品事件流；异步 HTTP 为理解事件服务。
