# 课程创作约定

本文件只维护 RayAgent 课程特有的定位、冻结状态与修改范围。项目通用规则由根工作指南统一维护，本文件不重复定义。

## 课程定位

以 RayAgent 为实践载体，学习 Agent Harness 的核心机制、系统设计与工程验证。Harness 指模型之外组织信息、行动、反馈与任务运行的工程职责组合，不指特定框架。

labs 用于隔离机制，RayAgent 用于研究机制组合后的设计与取舍。通用知识范围不受现有脚本限制，但应明确已有实现与能力差距。读者自行决定阅读、运行或修改，不设置必需、选做或进阶参与层级；课程不以从零搭建、TS 重写或框架迁移为目标。

## 冻结约定

- 课程正文已冻结：默认不新增章节，不恢复制作账本或按章源码索引。
- 允许措辞、配图与局部勘误；机制表述与实现不一致时再改正文。
- 阅读路径为目录 → 本章 → 下一章；正文不链向已移除的制作文档。
- 缺口与 `unverified` 范围写在本章内；运行命令仍只维护在 lab 或服务指南。
- 允许补充与课程直接相关的小范围 labs 脚本和 RayAgent 局部修复；新增产品功能、全局重构和框架迁移另行确定范围。
