# 课程创作约定

本文件只维护 RayAgent 课程特有的定位、冻结状态与修改范围。项目通用规则由根工作指南统一维护，本文件不重复定义。

## 课程定位

以 RayAgent 为实践载体，学习 Agent Harness 的核心机制、系统设计与工程验证。Harness 指模型之外组织信息、行动、反馈与任务运行的工程职责组合，不指特定框架。

labs 用于隔离机制，RayAgent 用于研究机制组合后的设计与取舍。通用知识范围不受现有脚本限制，但应明确已有实现与能力差距。读者自行决定阅读、运行或修改，不设置必需、选做或进阶参与层级；课程不以从零搭建、TS 重写或框架迁移为目标。

## 课程升级与背景约定

- 原 16 章已完成验收，作为阶段 3 的旧基线；阶段 4 按统一计划更新为新版课程，保持 16 章结构，不长期并列维护两套教材。
- 旧方案的价值、推导与证据归入[背景说明](../docs/background/README.md)，课程主线使用已实现并验证的新内容；通用双循环等方案比较仍可保留，不称作当前主路径。
- 实现工作包完成后同步更新受影响正文与图片；未实施的目标不得预先写成事实。当前章节处理状态统一记录在第四阶段进度，不另建制作账本或按章源码索引。
- 阅读路径为目录 → 本章 → 下一章；正文不链向已移除的制作文档。
- 本章实验的验证条件与局限随案例说明；当前产品能力缺口统一链接能力与边界，运行命令仍只维护在 lab 或服务指南。
- labs 与产品变化按第四阶段对应工作包执行；计划编制不自动授权代码实施，未纳入的功能和框架迁移不扩大范围。
