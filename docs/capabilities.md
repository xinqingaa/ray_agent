## 上下文治理的具体边界

容量以字符系数近似，在获得 usage 后校准；换模型的新运行重新估算，不复用前一模型 prompt_tokens。默认应用窗口为 200000，实际受该模型配置与目录上限约束。已有 E7 观察采用临时调低的窗口，不能证明默认窗口下的长任务可靠。

压缩按完整轮次选择，保留调用与结果配对；较早内容交给摘要，用户原文按总字符限额从近期向前重新注入，其余由摘要覆盖。摘要可能丢细节，原文也不是无限量保留。压缩不会拆开单批多个大结果；最近保留区或固定输入本身放不下、摘要失败或压缩后仍超限时，以 context_limit 失败。手动压缩失败不替换原记忆，成功不删除持久历史。

超长工具结果提供首尾预览和完整文件路径，可以再读全文；浏览器提取本身未取得的内容不能靠落盘恢复。服务端容量拒绝按 OpenAI 兼容客户端 400/413 与错误关键词识别，有替身检查，尚无真实供应商超长拒绝的运行记录。

## 浏览器与视觉边界

浏览器按 document/viewport/element 与 text/interactive/both 提取可见正文和交互元素，导航默认返回观察，动作可以要求同次观察。达到节点、字符或元素上限标为 `incomplete`；未提取内容不能从结果落盘恢复。它不是完整可访问性树，iframe、封闭 Shadow DOM 和 canvas 尚无专门提取。

标签页需显式选择，弹窗不自动接管。元素引用绑定真实 DOM 节点和标签页，可跨同一存活页面的适配器重建；节点替换、导航或浏览器重建后需重新观察。坐标输入核对目标与实际焦点。动作成功但观察失败应只补观察，不重复动作。日志只覆盖连接后事件，有数量和单条长度上限。

`web_fetch` 只读取公开 HTTP(S) 80/443 地址，逐跳校验并固定公开 IP，有重定向、时间、传输/解压大小与 MIME 限制；不携带浏览器 Cookie、认证或环境代理。登录及 JS 页面需要浏览器。正文容器和登录识别是启发式，不能保证所有站点正文完备。

显式截图 `analyze=true` 才会向支持视觉的当前模型输入像素，`deliver=true` 登记永久附件，`deliver=false` 为临时观察图。视觉图规范化到最长边 2048、2 MiB，下一请求最多两张，每张预留至少 1024 tokens；同批超额明确失败。捕获限制为每运行 8 次/24 MiB、单张 8 MiB/8192 边/1600 万像素，捕获及存储共 20 秒。事件恢复配额，事件落库前崩溃的尝试不保证完整计数。

历史保存图片引用及来源、哈希、MIME、尺寸，base64 在发请求时装配。临时图满 24 小时且运行进入终态后回收字节，保留元数据；运行或等待中的图片受保护。永久附件及旧自动截图不批量清理。真实 Flash 像素识别、Pro 非视觉降级和提前到期回收见[浏览器、视觉与资源验证](plan/evidence/browser-visual-resources-2026-10-08.md)，未连续观察完整 24 小时，也未验证真实 COS 云桶删除。

## 文件预览与下载边界

核对日期 2026-10-09。预览不再按统一 5 MiB 阈值禁用：文本每段 64 KiB；CSV/TSV、XLSX/XLS 每窗口最多 200 行、50 列，行起点最高 100000。二进制解析输入最多 64 MiB；超限 CSV 可查看已取得前缀，其他二进制降级为下载。XLSX 解压总量最多 128 MiB、10000 个条目；位图最多约 3355 万像素，缩略图最长边 1600。解析最多并发三个子进程，每次约 12 秒墙钟、10 秒 CPU，Linux 子进程地址空间上限 768 MiB。派生缓存最多 64 项/32 MiB、保留 60 秒；项目版本改变后拒绝旧分页请求。取消时等待当前文件读取结束再关闭句柄。

Excel 保留关键字体、颜色、对齐、边框、列宽、当前窗口内完整合并格及常见数值格式。公式显示已保存结果，无缓存时显示公式并标记；不重算公式，不还原图表、条件格式、宏、打印布局或跨窗口合并格，复杂数值格式可能退回原值。CSV 按 UTF-8 读取，超长字段可能拒绝解析；单元格和总显示文字另有输出预算。文本分页可能切断 Markdown 结构，JSON 仅在完整可解析时格式化；没有通用编码自动识别。

PDF 使用浏览器阅读器及 Range，SVG 作为受限制的图片资源加载；HTML 只读为文本。DOCX/PPTX、压缩包及未知类型当前保留下载入口。位图缩略图以首帧为主，不能保证动画完整重现。临时截图沿用原到期规则，到期返回 410；共享预览不延长存储寿命。附件 ZIP 每次最多 100 个不同文件、实际总量最多 512 MiB，重名加序号。原文件下载不受预览预算限制。

定向用例覆盖真实格式解析、分页、版本冲突、取消、符号链接、损坏文件、Range 和 ZIP，真实页面覆盖销售表与已有截图。COS、所有 PDF 阅读器、原生触屏、完整键盘/读屏与全部 Office 样式未逐项实测；当前证据不能外推这些组合。

| 范围 | 当前限制 |

## 界面验证的覆盖范围

真实走查覆盖过文件交付、提问/审批/停止、事件补齐、项目连续任务与恢复、模型设置和受控浏览器续接。2026-10-08 的记忆抽屉与开发者视图记录属于局部阅读/导航体验，见[冻结总计划](background/phase-4/total-plan.md#6-证据记录)，不能外推全部后端写入或错误分支。

以下仍需与已验证路径分开判断：工具策略的其他规则添加/删除、恢复默认和保存失败没有完整真实浏览器走查；全部内置工具的 ask/deny 分支不能由一次浏览器审批推出。一般设置字段的保存/校验没有逐项真实操作，已单独验证的模型设置以专项为准。原生文件夹选择的完整浏览器路径未走通，多层目录、覆盖确认和失败筛选主要由扫描器与组件检查覆盖；上传中断/恢复的 HTTP 证据不能代替全部 UI 网络故障路径。中文输入法组合由脚本覆盖，原生触屏与读屏未审计。

这些限制用于判断适用范围，不是已排期的尾项。旧计划中未实施的目标不自动转入待办，新需求按[维护入口](plan/README.md#后续工作的规划方式)另行确定范围。
