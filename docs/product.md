# RayAgent 产品说明

RayAgent 通过 Web 会话承接任务，组织目标、输入资料、计划、工具记录和产物。独立对话适合单项任务；托管项目让多次对话共享文件、说明、笔记与有来源的摘要。

![RayAgent 产品能力与 Harness 职责](assets/product-overview.svg)

## 会话与执行

从独立对话或托管项目发起任务；项目可以新建空项目，也可以通过本地文件夹导入材料。打开历史会话可继续交流，已有会话的项目归属不更换。侧栏切换独立对话与项目时保留页面和草稿，点击项目名称进入主页，名称前的独立箭头展开或收起对话，新增对话入口聚焦主页输入且保留草稿；发送时才创建对话。项目主页默认展示新对话输入与项目对话；对话、文件、说明、笔记使用稳定页签切换。项目与独立对话复用相同列表项。

发送目标可以开始新运行，上传附件作为输入。Agent 在同一个循环中调用工具、查看结果并继续判断，复杂任务可以维护计划清单。计划记录进度，程序不按清单调度工作。

运行中可以补充要求，内容在当前工具批次结束后的下一次模型请求前纳入。缺少信息时，Agent 提问并等待回答；回复继续同一次运行。结束后再发送则开始新运行，历史记录保留。

计划模式用于先分析和列出方案，程序拒绝副作用工具，包括 Shell 和写文件、写笔记；有效计划形成并结束后才提供按计划执行。手动压缩用于整理模型上下文，不删除会话历史。

工具策略支持直接执行、执行前询问或禁止，具体规则优先。MCP 和远程 Agent 默认询问。审批卡显示工具及参数，批准只执行这一项，拒绝把原因交回 Agent；等待审批期间需先批准、拒绝或停止。刷新可以继续处理审批，API 重启会使待审批调用失效。

首次消息保存临时标题，随后异步生成简短标题。会话顶部及列表提供手动重命名与 AI 建议；建议需要保存才生效，迟到的自动标题不覆盖手动修改。

## 工具与观察

| 能力 | 用户可取得的结果 |
|---|---|
| 文件与 Shell | 沙箱内的读写、查找、命令输出和进程操作 |
| 网页检索与公开网页读取 | 检索结果、无需登录的网页正文 |
| 浏览器 | 页面正文与交互元素、点击输入等动作、显式截图 |
| 计划与提问 | 可查看的计划进度、等待回答的问题 |
| MCP 与 A2A | 外部工具结果、远程任务状态与回传内容 |
| 文件交付 | 已生成文件的下载附件 |

时间线展示消息、工具、提问、审批、交付及终态。右侧“查看”使用单层的本次对话、项目文件与页面入口；没有浏览器记录时不显示页面。本次对话区分交付结果与输入材料，“下载本次交付”只打包明确交付文件。项目文件可预览、下载单个文件或跳转主页管理；开启开发者模式后工作台增加原始结果与终端。默认跟随可显示的新操作，手动选择后固定，有新结果可返回时提供入口。对话图片以 96×96 圆角缩略图展示，名称、大小和尺寸在点击后的预览中查看；其他附件和交付文件单击文件卡片直接打开大预览，工作台中的会话文件单击整行在当前区域打开；下载按钮独立操作，会话文件可打包成一个 ZIP 下载。CSV 与 Excel 使用表格查看，工作簿可切换工作表；文件图片与浏览器截图共用缩放和大图查看，当前 UI 没有远程桌面接管入口。

普通浏览器动作以文本观察反馈，不自动截图。显式截图可以用于模型分析、作为下载附件，或两者兼有；视觉分析需要当前模型支持图片。临时观察图到期回收后仍保留历史记录，图片本身不再可下载。

设置里开启开发者模式后，开发者视图展示运行、事件、模型轮次、上下文预算与实际请求重建结果，可导出 JSON。上下文面板区分最近请求占用、压缩后的估算和会话累计用量。预算配置已变化时，旧请求数值保留来源标记，不能按新窗口理解旧占用；没有数据时不显示虚构百分比。累计输入包含历次重复发送的上下文，缓存命中是输入的子集。正在生成的文本逐步展示；刷新或断线后，尚未保存的半截文本不保留，已保存的记录按序号补齐。

## 托管项目

项目文件页的“添加文件”只保存文件供后续任务使用，不发消息或开始任务；输入框附件则随消息交给 Agent。普通文件列表省去 uploads/outputs 目录层级，保留其中的真实路径和用户子目录，不按目录推断成果来源。文件位置可按需展开；文件管理不暴露系统目录开关，内部 uploads/outputs 仍由存储管理；界面保留用户子目录。

项目文件是平台保存的副本：可以从本地上传、预览、下载单个文件或整个项目，不回写本地，不接入宿主机目录或 Git。导入先扫描规则并审核文件树，显示排除项、敏感项与覆盖确认；上传进度区分传输字节和已发布文件数。排除或取消上传不代表已经发布的成功文件被撤销；失败时保留成功项并处理失败项。筛选审核树只影响查看，不悄悄改变上传集合。

项目对话的输入附件保存在 uploads；交付文件已经位于项目工作区时引用该文件，工作区外产物另保存至 outputs。消息附件与项目副本分别显示结果：附件交付成功但副本保存失败时，仍可下载附件，并单独重试项目副本，不要求重新执行工具或重新交付。副本状态读取失败显示尚未确认，不能当作已经保存。

打开项目或项目新对话只导航，首次发送受理时才创建会话。已有会话不更换项目归属。同项目只允许一个活动运行，等待回答或审批也占用项目；文件操作、恢复和环境收尾期间同样禁止新的写入。冲突给出占用原因和所属对话，首次发送被拒绝不会新增空会话。

项目文件页提供当前列表搜索、上传、下载与弹窗预览，项目操作菜单提供设置、恢复项目文件、操作记录、摘要与记忆预览及归档；恢复与操作记录打开独立弹窗，不改变当前页签；导出只包含当前项目文件，不含对话历史。文件恢复列出操作前保存点及关联对话，普通界面不展示原始审计 JSON。

每次项目运行前保存文件快照，保留数量默认五份，可在设置中调整为一至七份。快照读写失败不开始执行，超限时明确提示本次没有快照。整项目恢复先保护当前文件；失败保留阻止标记，可以重试或回到恢复前。恢复仅改变文件，不回滚笔记、摘要和对话。归档保留文件与历史，可以恢复；归档项目可清理快照，不删除项目工作文件。对象回收失败仍保留重试入口，即使快照清单已经为空。项目操作菜单、侧栏菜单和项目设置提供永久删除：确认范围，非空项目输入项目名称。运行、等待、文件操作、摘要生成或压缩未结束时拒绝受理。清理任务固定对象清单，先清理资源再删除业务记录，失败保留进度与重试入口；其他对话仍引用的共享附件保留。

项目记忆由说明、笔记和对话摘要组成。笔记可由用户或 Agent 按版本修改，修改记录可查看，历史内容可以取回编辑。摘要保留来源、截止位置与代次，支持编辑和重生成；生成失败保留原有内容。编辑冲突提供最新版本供处理，不静默覆盖草稿。

摘要管理可以查看当前对话的来源记录；运行预览只纳入近期其他对话，避免重复当前历史。浏览修改记录或运行预览时保留编辑草稿；取回历史笔记先进入草稿，保存后才生效。

每次新运行冻结项目说明、笔记与近期其他对话摘要；运行预览可查看将纳入的材料。正在执行或等待续接的运行使用原冻结版本，之后的修改在新运行生效。

## 模型与设置

普通模式设置提供项目文件保护、外观、只读外部工具与远程协作信息、执行权限及数据管理。数据管理中的危险操作“清空所有数据”需要输入确认短语，删除全部项目（含归档）、对话、附件、笔记和保存点，保留模型与服务配置。清理完成后同步清除当前及同源标签页的相关草稿并刷新列表。开发者模式默认关闭，开启后增加执行上限、模型提供商、MCP 与远程 Agent 连接编辑及技术观察；开关仅改变展示，保存在当前浏览器并同步同源标签页。外观保存在当前浏览器；服务配置由 API 保存。已知模型分别配置温度、生成上限和上下文窗口，思考开关与档位按模型目录显示。

对话首次运行保存参数；同模型后续运行沿用这条对话的参数，切换模型时下一次新运行读取目标模型的配置。正在执行或等待的运行保持自己的配置快照。模型菜单关闭时提交改动，失败保留草稿与原因。菜单中的档位沿用厂商名称；模型之间语义不兼容时明确回退到目标默认档位，不假定同名选项等价。

设置弹层关闭后返回原会话和草稿；切换分区保留未保存内容，退出有修改时需处理提醒。通用、模型和策略配置需保存，主题与阅读字号在当前浏览器即时生效。

工具策略可设置所有 MCP 工具、所有远程 Agent、单个服务、内置工具集及单个函数，具体规则优先，未命中规则直接执行。恢复默认先形成草稿，保存后生效；默认外部工具询问，其他工具直接执行，计划与提问豁免策略。策略变化在后续执行及等待续接时读取，已批准调用若改为禁止仍不执行。策略只判断工具，不检查参数，也不构成路径或网络围栏。

## 完成、停止与结果核验

| 状态 | 含义 |
|---|---|
| 等待 | 需要用户回答或批准，运行仍未结束 |
| 已完成 | 循环正常结束，已有最终回复 |
| 失败 | 请求、容量或运行器等错误使执行结束 |
| 已停止 | 用户停止本次运行 |
| 已中断 | 服务重启或执行协程丢失，需要重新发起 |

程序在结束前对明确文件交付、交付失败和未完成计划做有限反馈，仍不能证明业务目标正确。判断成果应看工具记录和实际产物：附件能否下载，内容是否符合要求；回复中的文件路径不等于交付完成。普通文件需通过交付工具成为附件，显式截图也可直接登记为附件。

停止会取消执行并尝试终止本次登记的 Shell 进程组，不回滚已有文件，也不保证远程任务同步结束。独立对话沙箱按会话复用；项目运行进入终态后需停止环境、确认旧写入者静止，再释放项目占用。API 重启后运行中和等待审批的任务中断，等待回答的任务可以续接。发送失败或超时会先核对是否已经受理，并保留可恢复的草稿；不要把客户端超时直接当作任务不存在。失败条提供重试入口，历史失败记录仍保留。

核验结果时分别查看最终回复、实际工具结果与下载文件。回复能解释处理范围，工具记录能说明动作，产物内容才支持业务结论；本项目的销售表验收采用独立检查证明当次结果，不表示产品内建了通用业务验收。能力限制与证据见[能力与边界](capabilities.md)。
