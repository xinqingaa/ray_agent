# RayAgent 产品说明

RayAgent 通过 Web 会话承接目标和资料，执行工具并交付答复与文件。独立对话处理单项任务；托管项目让多次对话共享文件、说明、笔记与有来源的摘要。

![RayAgent 产品任务全景：目标与资料、持续执行、答复与文件，以及支撑任务的四组能力](assets/product-task-map.svg)

## 会话与执行

### 发起任务与输入材料

从首页或项目主页输入目标，首次发送才创建会话；打开入口不会开始任务。历史会话保留原消息和项目归属，终态后再次发送开启新运行。

- 文件或图片随消息交给 Agent；混合粘贴保留文字，图片可预览或移除。
- 切换页面保留所属页面与草稿，上传期间不能发送。
- 项目文件页添加资料只保存材料，不发消息或启动任务。

图片由后台按本次模型能力与容量组织，用户无需选择技术输入模式：

- 支持视觉且符合预算时提供像素与文件路径，其余保留原文件并说明未启用视觉的原因。
- 活动运行的补图沿冻结模型处理；PNG、JPEG、WebP 和 GIF 首帧可进入像素输入，原图保持不变。
- 普通识图有像素时直接回答；OCR、属性读取和图片编辑按明确要求使用工具。

格式与容量见[运行参数与限额](limits.md)。

### 计划与继续执行

Agent 在同一循环中调用工具、读取反馈并决定下一动作。复杂任务可维护整体阶段与阶段内步骤，保留目标、范围和预期成果；计划勾选不证明业务完成。

- **补充要求**：在当前工具批次结束后的下一次模型请求前纳入。
- **回答提问**：沿同一次运行继续；结束后再发消息才开始新运行。
- **查看计划**：可了解整体进度与当前工作，展开及历史清单显示层级和状态。
- **计划模式**：先调研与制定方案，程序拒绝 Shell、写文件和写笔记等副作用工具。
- **按计划执行**：在有效计划形成并结束后出现，确认具体版本后显示准备执行。
- **手动压缩**：整理模型上下文，保留会话历史。

文字确认按普通消息处理。计划条在本次运行写出或承接清单后出现，结束后仍可查看各份最新计划。展示契约见 [UI 设计说明](../ray_agent/ui/DESIGN.md#页面与状态契约)。

### 权限与等待

工具策略支持直接执行、执行前询问和禁止，具体规则优先。MCP 外部业务调用与远程委派默认询问，计划与提问豁免。

- 审批卡展示工具与参数，批准只针对具体调用，拒绝将原因交回 Agent。
- 等待审批期间先批准、拒绝或停止；刷新后可以继续处理，API 重启使旧审批失效。
- 策略匹配工具及服务身份，不对任意参数内容、文件路径或网络地址建立访问围栏。

## 工具与观察

Agent 可以按任务使用以下能力：

- 在沙箱中读写和查找文件，执行命令并管理进程。
- 搜索网页，读取无需登录的公开正文，或通过浏览器查看页面和交互元素、点击输入及显式截图。
- 更新计划、向用户提问，通过 MCP 调用外部工具，通过 A2A 委派远程任务。
- 将明确交付的文件保存为可下载附件。

### 过程与结果展示

- **时间线**：保存消息、工具、提问、审批、交付和终态。右侧“查看”组织对话材料、项目文件与页面，没有浏览器记录时不显示页面。
- **浏览器**：普通动作提供文本观察，不自动截图。显式截图可用于模型分析、下载交付或两者兼有；分析需要视觉模型。临时观察图到期后保留引用，字节不再可下载。
- **统计**：区分本次运行与会话累计用量，生成速度为可见文本估算，缓存输入不重复加算。缺失数据不显示假数值，配置改变不重写历史统计。
- **开发者模式**：增加日志、原始结果、终端、上下文预算和请求重建，支持导出持久日志。开关只控制展示，当前 UI 没有远程桌面接管入口。

流式半截文本是临时展示，刷新或断线后不保留；已经保存的记录按序号补齐。聊天与日志切换保留草稿和阅读状态。

### 文件预览

预览用于阅读，下载保留原字节。文本分段、表格按窗口读取；项目文件改版后重新加载，损坏、超限或不支持时说明原因并提供下载。

| 类型 | 预览能力与边界 |
|---|---|
| 文本、CSV | 分段或按表格窗口读取 |
| Excel | 工作表与常见格式，显示已保存公式结果或标记未缓存；不重算公式，不还原图表、宏和完整打印布局 |
| 图片、PDF | 图片预览与浏览器 PDF 阅读，缩略图以首帧为主 |
| HTML | 新标签页隔离运行脚本，不能访问本站存储或通过 fetch/XHR 取数；外部静态资源仍可加载 |
| DOCX、PPTX、压缩包及未知类型 | 保留原件下载入口 |

HTML 的内存存储替身在刷新后清空，需要动态取数的页面可下载后本地打开。预览预算见[运行参数与限额](limits.md)。

## 托管项目

### 文件管理与副本

项目保存平台副本，不回写本地，不接宿主机目录或 Git。项目主页分为对话、文件、说明、笔记和摘要；文件列表保留用户子目录与真实路径。

文件从导入到交付有不同的保存阶段：

1. **导入预检**扫描文件树，展示排除项、敏感项和覆盖确认；筛选不改变上传集合。
2. **上传发布**区分传输和发布，部分失败保留成功项，取消不撤销已发布文件。
3. **材料使用**将输入附件保存到项目材料区，随消息交给 Agent。
4. **成果保存**对项目工作区内文件引用原件，对区外产物补存副本；附件和副本分别显示结果。

副本失败时附件仍可下载，也可单独重试补存；读取失败显示未确认。可以下载单文件或导出当前项目文件，导出不包含对话历史。

### 占用、保护与生命周期

同项目只允许一个活动运行，准备、等待回答与审批都保持占用。上传、恢复与环境收尾也阻止冲突写入；冲突说明原因及所属对话，首次发送被拒绝不会新增空会话。

- **开始运行**：前保护当前文件；快照读写失败不执行，超限明确说明未保护。
- **恢复文件**：前先保护现状；失败保留阻止标记，允许重试目标或回到恢复前。
- **归档**：保留材料和历史，可以恢复，也可清理快照。
- **永久删除**：需要确认范围，非空项目输入名称；活动运行、文件操作或后台记忆处理未结束时拒绝。
- **清理失败**：保留进度与重试入口；其他会话仍引用的共享附件继续保留。

恢复只改变文件，不回滚笔记、摘要、对话和旧附件。项目设置管理名称与生命周期，恢复和操作记录使用独立入口。保存点配置见[运行参数与限额](limits.md)。

### 项目记忆

项目背景由三类可查看、可纠正的材料组成：

- **说明**：表达固定要求与背景，新运行读取所选版本。
- **笔记**：保存长期结论，用户与 Agent 按版本修改；历史取回先进入草稿，保存才生效。
- **摘要**：记录其他对话的工作与来源，可编辑或重新生成；失败保留原文，迟到生成不覆盖新编辑。

新运行冻结说明、笔记和近期其他对话摘要，排除重复的当前历史。执行与等待续接保持原冻结内容，后来修改在新运行生效；冲突提供最新版本，不静默覆盖草稿。

开发者预览区分当前候选背景与实际运行快照。摘要有损，不提供向量检索或长期知识质量保证。

## 模型与设置

### 模型选择与生效范围

| 场景 | 使用的选择或配置 |
|---|---|
| 新对话、项目新对话 | 浏览器最近确认的模型与思考 |
| 已有会话 | 会话自己的选择；仅浏览历史不改变新对话偏好 |
| 对话首次运行 | 记录当时采样参数，同模型后续运行沿用 |
| 换模型后的新运行 | 读取目标配置并重新估算容量 |
| 执行或等待中的运行 | 使用自己的冻结快照 |

模型菜单关闭时提交变化，失败保留草稿；保存或发送成功才更新最近选择。会话字段尚未加载时由后端沿用原设置，思考档位来自模型目录，不假定跨系列等价。

### 设置与数据管理

- 普通设置提供项目保护、外观、执行权限、外部协作信息和数据管理。
- 开发者模式提供执行上限、逐模型参数与外部协作连接编辑；模型上游地址和密钥由部署配置管理。
- 设置分区切换保留草稿，未保存退出有提醒；应用配置保存后生效，主题和阅读字号在当前浏览器即时生效。
- 全局清空需要确认短语，删除项目与业务数据，保留模型及服务配置，完成后刷新列表并清除相关草稿。

首条消息后异步生成标题，手动命名优先；AI 建议保存后生效。详细交互规则见 [UI 设计说明](../ray_agent/ui/DESIGN.md)，配置数值见[参数页](limits.md)，部署见[运行指南](../ray_agent/README.md)。

## 完成、停止与结果核验

| 状态 | 含义 | 后续处理 |
|---|---|---|
| 等待 | 需要回答或审批，运行未结束 | 处理问题或审批后续接 |
| 已完成 | 循环正常结束，有最终回复 | 核对成果与业务要求，必要时继续提要求 |
| 失败 | 请求、容量或运行器错误使执行结束 | 保留原失败记录，可以重新发起 |
| 已停止 | 用户停止本次运行 | 已写文件保留，远程任务未必同步结束 |
| 已中断 | 服务重启或执行协程丢失 | 重新发起；等待提问可跨重启续接 |

成果与终态分别判断：

- 文件路径不代表交付，普通文件经交付工具成为下载附件；“下载本次交付”只包含明确交付文件，不混入输入材料。
- 复杂任务记录预期成果，必要成果缺失时说明部分交付；正文成果保留完整正文，文件答复说明累计成果与实际缺口。
- 结束反馈不证明业务正确，应结合实际工具结果、下载字节与内容核验，程序没有通用业务验收器。
- 停止取消执行并尝试终止登记的 Shell 进程组，不回滚文件。独立对话复用环境，项目确认环境静止后释放占用。
- 发送超时先核对受理结果，保留草稿，避免直接重发造成重复执行。
