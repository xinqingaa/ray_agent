# RayAgent 产品说明

RayAgent 围绕会话组织任务：目标、输入资料、执行计划、工具记录和产物共同构成一次可查看的工作过程。本文说明已有产品能力与使用边界；系统实现见[架构说明](architecture.md)，配置与启动见[运行指南](../ray_agent/README.md)。

## 会话与任务

用户可以创建会话、发送目标并上传附件，也可以打开历史会话继续交流。上传文件会同步到沙箱，作为任务可读取的输入。Agent 生成计划后逐步执行，并根据步骤结果调整剩余计划；页面同步展示步骤、消息和工具记录。

Agent 可以发送进展通知或向用户提问，收到回复后继续处理任务。执行中也可以补充要求，后续计划可能随之调整；新消息不会立即打断每一个正在进行的工具动作。

## 工具与执行环境

| 能力 | 已有操作 | 运行条件 |
|---|---|---|
| 文件 | 读取、写入、文本替换、内容搜索、文件查找 | 操作沙箱内文件；上传与交付需要文件同步 |
| Shell | 执行命令、读取输出、等待进程、写入输入、终止进程 | 使用沙箱进程环境，权限和依赖取决于镜像 |
| 网页检索 | 按查询词检索并返回网页信息 | 需要搜索适配及目标站点可达 |
| 浏览器 | 导航、查看、点击、输入、按键、选择、滚动、脚本与控制台操作 | 需要沙箱浏览器可连接，目标页面可访问 |
| 用户交互 | 通知进展、提出问题并等待回复 | 由会话消息与任务输入承接 |

工具结果返回模型上下文，供后续判断使用；页面中的工具记录则面向用户观察。两者相关，但不是同一份完整数据。

页面可以查看沙箱画面，文件、命令和浏览器操作在执行环境中进行。动态创建环境与连接已有环境的配置和使用条件见[沙箱指南](../ray_agent/sandbox/README.md#与-api-连接)。

## 外部工具与远程 Agent

MCP 将外部服务发布的工具接入任务。用户可以在设置中添加服务、检查连接状态和发现的工具，随后让 Agent 在任务中调用它们并查看结果。

A2A 用于发现远程 Agent 并委派任务，支持提交后的状态查询和结果回传。远程工作结果回到本地 Agent，参与后续执行。两种协议均由本地 Plan + ReAct 使用；接入成功并不代表支持协议的全部可选能力。

页面设置还可调整模型参数与服务地址。模型凭据、协议配置、生效方式及本地验收入口统一见[运行指南](../ray_agent/README.md#模型与工具)和[协议接入指南](../ray_agent/api/README.md#mcpa2a)。

## 观察、历史与交付

执行过程中，页面持续展示消息、计划、步骤、工具及用量信息，刷新后仍可查看已保存的历史。模型生成期间可能暂时没有新内容，当前不逐字展示生成中的回答。

任务可以将指定沙箱文件同步并作为消息附件交付。界面支持文件列表、适用格式的预览和下载；支持情况取决于文件类型。需要取得成果时，应确认消息中的附件可以打开或下载，不能只依据 Agent 提到某个文件路径就判断交付完成。

## 当前边界

- 任务以会话为单位，没有独立的长期项目工作区模型。保留历史和记忆不意味着进程重启后自动恢复未完成执行。
- 用户可以请求停止，但取消不回滚已经产生的文件修改或外部副作用，也不保证所有子进程和远程任务同步结束。
- 等待回复、正常完成、执行失败和用户停止的含义不同。页面结束展示并不能单独证明目标已经完成，应结合回复、执行记录与实际成果确认。
- 任务结束不等于销毁沙箱。容器隔离也不等于按任务建立了文件、网络和工具的细粒度权限策略。
- 计划完成和 Agent 总结不能替代独立的成果验收。目前没有通用的目标验收系统。

本说明依据当前实现静态核对，不把工具存在等同于所有任务组合均经过端到端验证。既有验收范围见[执行计划](../PLAN.md)，带日期的观察证据见[调研索引](research/README.md)。
