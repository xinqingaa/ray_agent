# 调研与评估

本目录保存带日期和代码基线的调研快照，用于记录评估依据、运行观察和候选方案。它们不是当前架构规范、产品决策或已排期的改造计划。

当前系统结构以[架构说明](../architecture.md)为准，项目阶段以[执行计划](../../PLAN.md)为准，部署和复现步骤以各服务指南为准。引用调研结论时应同时查看文档日期和代码基线。
