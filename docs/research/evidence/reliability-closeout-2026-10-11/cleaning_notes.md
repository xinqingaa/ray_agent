## 处理规则

1. **去重**：按 `order_id` 去重，重复出现时保留第一行，删除后续重复行。
2. **缺失排除**：`amount` 或 `refund` 为空的行整行排除，不以 0 代替，并单独列明（见下）。
3. **净额**：`净额 = amount - refund`。
4. **计算方式**：全程使用 Python `Decimal` 十进制定点运算，结果保留 2 位小数，不做浮点运算。
