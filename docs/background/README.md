## 较早比较留下的认识

比较与复审留下这些判断：保留技术栈并渐进改造，项目、目录、会话、运行和环境寿命不同；课程的通用结构有价值，步骤划分不等于授权，复杂度要有可观察收益；实际文件任务暴露上下文、流式、状态和交付问题，需分项核对；循环、日志与记忆、工作区和流式要分开看，增强集中在核心链路；定向阅读真实源码后，撤回固定评测门槛，先决定循环，并保留成果验证。

这些分析没有实际运行 Codex，源码比较不能视为其恢复、权限或副作用机制均已验证。较早统一改造计划里有解释价值的选择已进入主题背景，不作为现行工作清单。

课程正文仍对应标签 `baseline-v1` 上的旧双循环；单循环阶段以标签 `v2` 标记。这些标签不指代最新部署。正式同步需要阅读最新真实源码、当前文档与有效证据，见 [课程同步范围](../course-sync.md)。
