# 课程同步范围

原 16 章以 `baseline-v1` 的双循环实现完成验收，当前产品已演进为单循环 Harness。课程正文与配图尚未同步；目录保留旧基线说明，当前能力以 `docs/` 和源码为准。

课程同步需要单独授权。本轮文档收敛不修改章节正文、课程配图或实验实现，旧逐章分析、小节建议与配图判断完整保存在[课程同步参考稿](../lessons/plans/course-sync-reference.md)，它是冻结资料，不作为当前执行状态表。

## 同步时需要重新评估的内容

| 主题 | 应与当前实现对齐的事实 |
|---|---|
| 循环、规划与结束 | 单循环、计划工具、有限结束反馈与业务成果核验的区别 |
| 上下文与状态 | 结果整形、预算与压缩、模型配置快照、项目记忆冻结 |
| 控制与观察 | 运行身份、事件账本、文本增量、请求重建、审批与中断 |
| 环境与文件 | 按需资源、项目占用、快照与恢复、交付和旧写入者收尾 |
| 浏览器 | 文本观察、真实节点引用、动作后观察、显式视觉与临时图 |
| 协议与可靠性 | 按需发现、协议边界、有界读取并发与当次验证条件 |

继续采用 16 章结构，保留有教学价值的通用方案比较；旧双循环可以作为取舍案例。同步开始时以参考稿为盘点起点，根据当时的源码与证据逐章校准，特别重评浏览器、项目、视觉与模型配置相关章节；不把旧计划中的目标当成已实现内容。章节分工见[课程目录](../lessons/README.md)，写作规则见[课程创作约定](../lessons/AGENTS.md)。
