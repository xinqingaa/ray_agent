# 模型连接、用量与语音输入

## 模型连接如何生效

本机核心从用户 TOML 读取模型连接，文件记录各提供商的名称、地址、协议、密钥、所提供的模型及目录外模型的声明。设置页通过核心接口读写该文件，界面不保存另一份连接数据。连接的公开状态只包含地址、协议、模型声明和密钥掩码；保存前的测试返回耗时或上游状态与错误消息，核心清除上游可能回显的密钥。

**能力目录由核心持有。** 内置模型的窗口、输出上限、工具、图片、思考档位、缓存与单价由核心的模型目录定义：模型菜单读取可用模型（`GET /api/app-config/models`），提供商设置页读取完整目录（`GET /api/app-config/llm/catalog`）。目录不含地址与密钥。界面只展示目录，不维护能力白名单。目录读取失败时，设置页仍可编辑和保存，模型能力与单价暂不显示，保存结果以核心为准。

**上游读取只补充目录外模型。** 设置页的「读取模型列表」由核心请求上游 `/models`，逐项解析模型 ID 及可识别的能力字段（窗口、输出、工具、图片、思考档位与单价）。字段按项独立解析：某个字段缺失或超出可采信范围，只使该字段视为未报告；单个条目无效只跳过该条目。同一列表中重复的 ID 保留先出现者，ID 含密钥的条目被跳过，结果按 ID 排序返回。顶层结构不是模型列表时整次读取失败。上游模型列表只表示这些模型可作为候选，不保证当前密钥有权调用该模型，也不保证其在当前配额或地区可用；能否使用以「检测」或实际调用的结果为准。

核心把上游报告归并为可保存的能力，每个字段标明来源：

| 来源 | 含义 |
|---|---|
| 目录 | 目录模型的全部字段，忽略上游的报告 |
| 上游 | 目录外模型，上游报告了该字段且通过范围检查 |
| 未确认 | 目录外模型，上游未报告或报告无效，使用保守值，界面标「能力未确认」 |

目录外模型未报告时的取值如下。窗口与输出用保守默认值，具体数值见[运行参数与限额](limits.md#模型连接与能力探测)。工具在界面新增时默认开启，并标「能力未确认」，可用「检测」确认；图片没有可靠来源，核心不做图片能力探测，未报告时关闭并标未确认；思考未报告且没有档位时关闭。文件中缺省的 `tools` 仍视为关闭，以保持旧配置的行为不变，因此只有界面新增的模型才会默认开启工具。

单价没有依据时（上游未报告，或目录模型没有内置单价）为空，核心把它的来源记为未确认。单价不属于能力标记，界面不显示「能力未确认」：目录外模型的单价栏显示「未填写单价」，目录模型显示「未计价」。单价为空的模型只统计 Token，费用为空。

**保存时由核心归类。** 保存时名称属于目录的模型记为目录模型，其余记为自定义模型，未声明能力的自定义模型使用上述默认声明。同一模型 ID 被多个提供商启用时，保存被拒绝并指出已占用的提供商，界面中已被占用的模型也不能启用。读取文件时遵守同一规则：同一模型在多个提供商中出现，按文件顺序由先出现的提供商提供，后面的声明被忽略，并在对应提供商的状态中说明；单个模型的字段无效只忽略该模型，同样在状态中说明；提供商级别的配置无效时，该提供商不可用并说明原因，地址仍显示，便于修正。

自定义模型可声明思考档位，声明后思考开关随之开启，运行时按所选档位发送给上游。档位名称不能为保留名 `enabled` 或 `disabled`。

**工具检测。** 「检测」对单个模型发送一次带工具定义的最小请求，只依据上游的结果下结论：

- 上游接受请求：确认支持工具。界面把工具设为开启并移除未确认标记，保存后写入文件。
- 上游以 400 或 422 拒绝请求体：判为不支持，界面说明原因（含 HTTP 状态），建议关闭工具，由用户点「关闭工具」确认，不自动改动。
- 其他结果（密钥或权限、模型或地址、其他 4xx、限流、服务端错误、超时、连接失败）：无法判断，作为检测失败返回并说明原因，能力标记不变，可再次检测。

图片能力不做检测。检测请求只读取结论，不写入配置。

提供商删除后，引用它的会话在下一次运行时需要换模型。界面保存按读取到的文件版本写回指定提供商，核心保留注释与其他字段，在同一目录写入受限权限的临时文件，重新核对文件身份后替换。检测到外部编辑时提示重新读取。最后一次核对与文件替换之间仍有一个很短的外部竞争窗口。

新运行读取当前连接，执行中和等待续接沿用冻结的连接及模型声明。运行快照保留非密钥配置，凭据在当前核心进程内可用于续接。核心重启后，续接要用用户配置中仍能匹配的原凭据。配置操作见[运行指南](../ray_agent/README.md#模型连接)。

## 用量如何记录与计算

核心在模型请求出口记录每笔请求，涵盖主任务、上下文压缩、标题、记忆提炼、会话摘要、实际发出模型请求的连接测试，以及本机和云端语音转写。记录带请求时间、用途、提供商和模型，并关联当时已存在的会话、运行或工作区。失败或未完成请求若上游已返回用量则保留其 Token 与费用估算，缺少用量时仅计入次数并将费用留空。计价使用响应中的 Token 或转写时长，音频请求另记时长。

费用按各厂商官方结算币种分别估算（DeepSeek 聊天与转写使用人民币 CNY，OpenAI 使用美元 USD），界面不虚构实时汇率并分别展示或并列显示混合币种；统计图表在混合币种下按固定参考比例换算柱高，悬停读数仍保留原币种。计算涵盖输入缓存未命中、缓存命中、OpenAI 缓存写入（30 分钟 / 12 小时）及超长上下文阶梯倍率（大于 272K 输入时按对应倍率），并从目录模型归属识别中转连接上的内置模型以按官方标准计价。思考 Token 是输出 Token 的细分。DeepSeek 聊天依请求发出时间按 UTC 工作日时段估算，节假日低谷优惠、账单折扣与赠送额度不计入。DeepSeek 转写用上游报告的音频时长及官方人民币刊例价估算。本机转写成功时依据录音采样记时长，费用记零。目录外模型可声明单价，缺少价格依据时金额留空。金额、版本和时段随请求固化，更新单价只改变后续记录。 [DeepSeek 聊天定价](https://api-docs.deepseek.com/quick_start/pricing/) · [DeepSeek 转写定价](https://api-docs.deepseek.com/guides/asr/) · [OpenAI 定价](https://developers.openai.com/api/docs/pricing)

统计接口在本机时区划分时间桶，按范围及提供商聚合。设置页默认展示近 7 天，并与上一等长区间对比。自定义范围采用整点起止，结束时刻不含。费用趋势可下钻到当天，日历可点选日期或按住 Shift 选择连续时段。星期×小时视图随筛选变化，可固定格子查看请求、Token 和主要模型，也可按本机时区标出 DeepSeek 高峰。总费用累加有价格的请求，无价格的请求仍计次数。规格与保留窗口见[限额](limits.md#用量与语音)。运行内费用随已完成轮次、压缩与终态汇总更新，标题、工作区后台摘要、记忆和转写计入所属会话累计。用量从部署后新请求开始。删除会话解除关联，整体统计继续保留，清空全部数据删除全部用量记录。

## 语音如何进入输入框

输入框默认显示麦克风。首次点击时，如果语音偏好还未选择，编辑区上方会并列说明两种转写方式、录音去向及资源状态。用户选择后才开始录音。缺少模型时可从语音条下载，缺少云端连接时可前往模型提供商配置。也可在「设置 → 通用 → 语音转文字」选择本机、DeepSeek 云端或关闭。关闭后隐藏麦克风。应用缺少系统麦克风权限时，会提示系统设置路径。

本机转写使用随包的 `whisper.cpp` 和按需安装的多语言模型，面向普通话和英语。模型下载后可离线使用，模型文件占用磁盘，推理进程在转写时使用本机内存，结束后释放。当前组件面向 Apple Silicon 的 macOS，设置页会提示该设备是否可用。DeepSeek 支持更多语言，点完成后核心才用官方连接凭据把录音发到转写接口。 [DeepSeek 语音识别](https://api-docs.deepseek.com/zh-cn/guides/asr/)

两种方式共用 WebView 录音和 WAV 校验。每段录音使用开始时选定的方式，本机音频经回环和进程管道传递。转写成功后文字追加到原草稿，可在发送前编辑。失败后的录音在内存中保留，可沿同一方式重试或丢弃。切换方式时用新录音开始新请求。取消或离开对应会话时清理录音及在途请求。

后续安排见[OpenAI 转写](plan/usage-models-voice.md)。
