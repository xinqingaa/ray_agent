# 模型连接、用量与语音输入

## 模型连接如何生效

本机核心从用户 TOML 读取模型连接。设置页可以新增、编辑和删除提供商，读取上游模型列表，并在保存前用草稿测试所选协议。测试返回耗时或上游状态和错误消息，核心清除上游可能回显的密钥。连接的公开状态只包含地址、协议、模型和密钥掩码。

界面保存按读取到的文件版本写回指定提供商。核心保留注释与其他字段，在同一目录写入受限权限的临时文件，重新核对文件身份后替换。检测到外部编辑时提示重新读取。最后一次核对与文件替换之间仍有一个很短的外部竞争窗口。

提供商可以选择目录模型，也可以声明目录外模型的窗口、输出上限、工具、图片、思考开关和单价。未声明的工具、图片和思考能力默认关闭，模型请求省略并行工具字段。上游会直接报告不支持的协议或能力。同一模型 ID 对应一个提供商。删除提供商后，原会话在下一次运行时需要换模型。

新运行读取当前连接，执行中和等待续接沿用冻结的连接及模型声明。运行快照保留非密钥配置，凭据在当前核心进程内可用于续接。核心重启后，续接要用用户配置中仍能匹配的原凭据。配置操作见[运行指南](../ray_agent/README.md#模型连接)。

## 用量如何记录与计算

核心在模型请求出口记录每笔请求，涵盖主任务、上下文压缩、标题、记忆提炼、会话摘要、实际发出模型请求的连接测试，以及语音转写。记录带请求时间、用途、提供商和模型，并关联当时已存在的会话、运行或工作区。失败和缺少用量的请求计入次数，费用为空。计价使用成功响应中的 Token 或转写时长，音频请求另记时长。

费用用美元估算，按输入缓存未命中、缓存命中和输出计算。思考 Token 是输出 Token 的细分。DeepSeek 聊天依请求发出时间按 UTC 工作日时段估算，节假日低谷优惠、缓存写入、批量档位、账单折扣与赠送额度不计入。DeepSeek 转写用上游报告的音频时长及刊例价估算。目录外模型可声明单价，缺少价格依据时金额留空。金额、版本和时段随请求固化，更新单价只改变后续记录。 [DeepSeek 聊天定价](https://api-docs.deepseek.com/quick_start/pricing/) · [DeepSeek 转写定价](https://api-docs.deepseek.com/guides/asr/) · [OpenAI 定价](https://developers.openai.com/api/docs/pricing)

统计接口在本机时区划分时间桶，按范围及提供商聚合。设置页默认展示近 7 天，并与上一等长区间对比。自定义范围采用整点起止，结束时刻不含。费用趋势可下钻到当天，日历可点选日期或按住 Shift 选择连续时段。星期×小时视图随筛选变化，可固定格子查看请求、Token 和主要模型，也可按本机时区标出 DeepSeek 高峰。总费用累加有价格的请求，无价格的请求仍计次数。规格与保留窗口见[限额](limits.md#用量与语音)。运行内费用随已完成轮次、压缩与终态汇总更新，标题、工作区后台摘要、记忆和转写计入所属会话累计。用量从部署后新请求开始。删除会话解除关联，整体统计继续保留，清空全部数据删除全部用量记录。

## 语音如何进入输入框

输入框默认显示麦克风。语音转写偏好未选择时，首次点击会就地说明录音将发送到官方 DeepSeek 语音识别接口，并由用户确认后才开始录音；在通用设置中也可直接选择 DeepSeek 或关闭，关闭后入口隐藏。录音在点完成后才由核心发送。WebView 把采样转为单声道 PCM WAV。录音在内存中使用，失败时可重试或丢弃，成功后的文本留在输入框供编辑。核心从官方 DeepSeek 连接取凭据，独立调用转写接口。应用缺少系统麦克风权限时，界面提供到系统设置的路径。 [DeepSeek 语音识别](https://api-docs.deepseek.com/zh-cn/guides/asr/)

本机和 OpenAI 转写的后续安排见[语音转写扩展](plan/usage-models-voice.md)。
