# 换班版启动说明

## 在 RayAgent 试用

在成果里打开 **换班版试用入口.html**，点击「打开本机换班页」。也可以在运行服务的电脑上访问 <http://127.0.0.1:8765/>。如果服务已停止，按下面的步骤重新启动。

## 转发给同事

转发 **值班换班版源码.zip** 即可。包内有 Vue 前端源码、Python 服务、初始排班、构建脚本、已构建的 `dist/` 和这份说明。

1. 解压后在终端进入解压出的 `duty-swap` 文件夹。需要 Python 3.9 或更新版本。
2. macOS 或 Linux 运行 `python3 server.py`。Windows 运行 `py -3 server.py`。
3. 终端打印地址后，在同一台电脑的浏览器打开 <http://127.0.0.1:8765/>。在终端按 `Ctrl+C` 可停止服务。

运行时只需要 Python 标准库。源码包内已包含 Vue 生产版及许可证，可离线启动。如果端口被占用，可加 `--port 8766`，然后打开终端打印的地址。服务仅监听 `127.0.0.1`，每位同事运行的是自己的本机副本，改动各自保存。

## 换班和保存

选择日期，在「调整主值」里选择改某天的主值，或与另一天互换主值。查看预览后点击「保存换班」。两天互换会一次写入。备班沿用原安排，如果与新主值为同一人，保存前会提示。主值变化会带动前一天的交接对象更新，范围限于这一周内的日期。

改动默认写入 `data/schedule.sqlite3`，刷新和重启会从同一个数据库读取。搬迁到另一台电脑时，如需带上已保存的改动，先停止服务，再把该数据库复制到新副本的 `data/` 目录。可通过 `--db` 指定不同的数据文件。

## 前端构建产物

**值班换班版前端构建.zip** 包含 `dist/` 和 Vue 许可证。可将 `dist/` 放到 `server.py` 同级目录，由 Python 服务提供页面和保存接口。

修改源码后，在 `duty-swap` 目录运行 `python3 build.py`（Windows 为 `py -3 build.py`），重新生成 `dist/`，然后重启服务。
