# 跨模块契约

本页定义技术基线中的共同规则，不描述当前已经实现的能力。字段为逻辑契约；身份、错误、版本、长操作、能力声明与事件信封已由核心的 Pydantic 模型固化，生成方式与使用约定见[契约指南](../../ray_agent/contracts/README.md)，实现位置见[代码地图](../code-map.md#共享契约)，不在本页复制。

## 身份与数据归属

| 身份 | 契约 |
|---|---|
| `workspace_id` | 新建工作区时生成，不由名称、文件夹路径、角色或窗口推导；独立对话为空 |
| `install_id` | 本机安装身份，用于文件夹标记与实例发现，不是用户账号 |
| `root_id / relative_path` | 可访问根内的位置：每个工作区一个文件夹根，每个会话一个工作目录根；远程客户端不提交任意桌面绝对路径 |
| `instruction_version` | 工作方式的不可变版本，运行背景清单按版本引用 |
| `session_id / run_id` | 保留既有独立身份与会话内事件序号，一个会话至多一个活动运行 |
| `document_id / revision` | 文档身份与不可变内容版本分开；移动不强制变更身份，内容变化产生新版本 |
| `memory_id / version` | 记忆独立版本，状态、来源与替代关系不由向量索引决定 |
| `skill_id / content_hash` | 区分来源身份与包内容；同名不同来源不得混淆 |
| `operation_id / request_id` | 分别定位长操作与业务幂等请求；同身份不同内容返回冲突 |
| `instance_id / generation` | 标识核心启动代次及后台任务版本，阻止迟到回调写回已替换对象 |

采用应用级 SQLite 数据库，所有工作区对象显式带范围；检索索引按工作区分开，通用设置和用户级 Skill 目录由独立入口管理。数据范围由服务端从资源关系解析，不直接信任客户端或模型传入的工作区 ID。

跨工作区分享不在首批实现。全局导航只读各工作区元数据，不调用无范围的记忆或文档检索。应用级模型连接可复用，工作区的工具启用与远端凭据使用范围另行绑定。

上述隔离是应用的数据与工具服务边界；按 D5 启用的 Shell 仍可能访问当前系统用户能访问的文件。不能将本机执行描述为对恶意脚本也成立的强隔离工作区。

## 对外 API 与能力声明

保留现有会话、运行、工具和计划事件语义；新 schema 与接口直接使用工作区命名，围绕工作区与文件夹、工作方式、记忆、文档、检索、后台操作与 Skill 来源增加。桌面版不读取原部署数据，不为旧项目接口保留兼容层。

核心握手返回协议版本、构建身份、实例身份、存储版本及能力声明。能力至少区分文件访问、本机命令、浏览器、全文检索、语义索引、OCR 和远程控制；组件未安装或权限关闭时返回可恢复的不可用原因。

API 错误保留结构化代码、当前资源版本、可读原因及可重试信息。长操作先返回 `operation_id`，查询和取消沿同一身份；网络结果未知先读回，不重新发起覆盖。新增业务接口使用 OpenAPI 生成共享类型，SSE 联合类型与事件版本一同维护；桌面与移动不各自手写另一份契约。

契约以 Python 核心的 Pydantic 模型为唯一来源：HTTP 接口经 FastAPI 导出 OpenAPI，SSE 事件联合类型导出 JSON Schema，UI 的 TypeScript 类型由两者生成；Rust 宿主只使用握手与能力类型，并由契约检查对齐。生成结果纳入版本控制，过期时检查失败。现有手写的前端接口类型在所属工作包改动对应接口时替换为生成类型，首个交付完成前全部替换。

文件预览、来源原文和下载使用短期、资源限定的票据。fetch 型 SSE 携带实例令牌；不把令牌放进 URL、生成 HTML 或永久日志。新能力由 UI 控制是否提供入口，不让不可用按钮假装任务已受理。

### 新接口族与调用方

| 接口族 | 请求／响应必须表达的内容 | 调用方 |
|---|---|---|
| 核心握手与状态 | 协议／schema／构建／实例身份、能力及不可用原因 | 原生宿主、CoreClient |
| 工作区与文件夹 | 工作区版本、文件夹绑定与可用状态、标记冲突及可选处理；绑定需桌面原生选择凭证 | 工作区 UI、本机文件服务 |
| 工作方式 | 当前版本、基于版本的更新、Agent 提议及确认／拒绝 | 设置 UI、提议工具 |
| 记忆 | 基础版本、变更身份、来源、确定性、常驻／候选状态及撤销 | 记忆 UI、受限模型工具 |
| 文档登记与修订 | 文件身份、内容版本、解析／索引状态、可取消操作身份 | 文件夹面板、扫描任务 |
| 搜索与来源读取 | 查询、来源类型；返回不可变来源身份、位置、片段与版本 | 上下文装配、模型工具、引用 UI |
| 操作查询／取消／重试 | 操作类型、所有者、代次、终态与结果、取消／重试是否可用 | 各操作界面 |
| Skill 来源与可用目录 | 范围、规范来源、启停、版本及不兼容原因；显式选择稳定身份 | 设置、输入框、运行装配 |
| 组件与执行资源 | 平台清单、安装状态、运行时／浏览器是否可用、工作区执行开关 | 桌面设置、执行器 |
| 设备配对与撤销 | 设备身份、授权工作区、一次性交换结果、可撤销状态 | 桌面设置、移动原生层 |

生成链路、身份、错误、版本、长操作、能力声明与事件信封已经建立；表中各接口族的具体请求与响应由所属工作包按这些规则定义、生成并实现路由和调用方。新增接口不直接暴露数据库通用 CRUD 或任意桌面路径。会话发送、计划确认、审批与停止沿既有接口族扩展幂等身份。

## 本机与移动访问

桌面默认监听回环地址，通过宿主与核心的受控启动通道交换实例令牌和端口，不能把同端口上的任意进程视为本应用。CoreClient 统一提供请求、订阅、文件和重连，PlatformAdapter 只处理原生能力。

辅助移动端采用用户显式开启的局域网配对：桌面原生桥负责受认证的 TLS 入口，配对码／二维码携带桌面身份指纹和一次性交换材料；手机原生层固定身份，持有可撤销的设备令牌。普通 WebView 网络限制通过平台网络适配处理，不关闭全局证书验证或启用不受限明文访问。

原生入口采用 Rust 的 axum／TLS 服务代理受认证请求到回环核心；移动层用 reqwest 流式请求和 Tauri Channel 传递事件，文件上传下载流式处理，不把整份大文件转成 JSON／Base64。路由和设备授权由同一范围检查维护，原生代理不绕过核心权限。配对证书变化必须重新核对，不能为了重连接受另一台同地址机器。

未配对客户端不可访问工作区；已配对设备只获得用户选择的范围。设备可撤销，手机不接触桌面模型密钥或原生文件桥。公网中继、自动发现、云推送和双向同步不在默认交付中；局域网访问采用同一业务协议，新增传输不创建另一套业务核心。能力声明中的远程控制目前报告未实现，局域网入口在后续阶段 P12 实现。

核心不托管可从浏览器打开使用的独立 Web 应用。Tauri 加载随包发布的界面资源，生成 HTML 与外部网页使用无桥接的隔离预览或系统浏览器；移动端使用固定桌面身份的原生传输。本机 HTTP／SSE 与局域网配对接口属于客户端通信，不作为 Web 产品入口。

## 受理、事务与持久任务

- SQLite 业务写入由单核心的写协调器进入短事务，事务中不调用模型、网络或长文件 IO。
- 消息受理将用户消息、幂等身份、运行／等待状态和待消费输入同事务提交；输入消费与相应上下文记录同事务提交。
- 事件序号、运行状态和相关业务状态在一次事务中更新，提交后唤醒订阅；漏通知用序号查询补读，文本增量继续是临时展示。
- 索引、记忆提炼、会话摘要、组件安装和清理使用持久 `background_jobs`／操作记录；重启按类型决定重新排队或标为可重试失败，不通用重放全部工作。
- 模型调用和 Shell 副作用不具备数据库事务的恰好一次保证，已开始但无法确认的动作保留未知结果。

审批等待的范围、版本和具体动作必须固定；回复时重查当前资源与权限，变化后旧批准失效。保持现有提问可重建、旧审批重启失效及执行中断规则，除非所属工作包明确替换并检查。

后台操作统一使用 `queued / running / succeeded / failed / cancelled`，运行中可附带取消请求和阶段，不把“已请求取消”作为终态。业务运行保持原有终态集合。取消、重试与结果查询都核对来源与范围，原操作已完成时返回完成结果，不制造另一份相同副作用。

## 版本、引用与删除

每次模型请求记录实际用过的工作方式、记忆、检索片段和 Skill 版本，包含内容或可按引用读回的内容对象。后续更新不会改写旧请求；再次查询可以读取新版本，但形成新的工具或上下文事件。

撤销访问、删除与失效在下一次请求及读取前重新核对；即使旧运行持有版本引用，也不能据此继续读取已撤销材料。删除检索片段先更新权威可见状态，再异步清理派生字节；旧引用展示删除或不可用。来源块与检索工具结果携带内部来源标记，可撤除失效内容并保留调用结果配对；不声称能从既有自由文本中自动消除所有同义转述。删除记忆、删除源会话和清理历史是不同操作，历史已发送给外部模型的内容不能撤回。

文件、索引与数据库不作为跨资源原子事务。内容先写临时对象、校验并发布，再由短事务建立可见指针；失败留下可辨认的孤立对象。回收依据引用和操作状态，不根据目录为空或通知成功判断已经释放。

解除文件夹绑定或删除工作区不删除文件夹及其中的用户文件。删除应用数据需要固定范围、阻止新写入并完成持久清理；清空对话、删除记忆、删除文件分别表达，不连带误删。来源仍存在时删除记忆不等于删除来源，但要抑制同一来源重复提炼已撤回条目。

## 资源与配置

数据根位于系统应用数据目录，数据库不得放在网络共享盘或云盘同步目录。资源目录按数据库、工作区内容对象、Skill 快照、检索、组件和临时文件分别管理；工作区文件夹独立绑定，应用只在其中写入身份标记。

组件和模型清单固定版本、平台、校验和、许可与下载来源；更新不静默切换 Embedding 模型或浏览器协议。密钥使用操作系统凭据存储，配置与运行快照只记录引用及非秘密值。

并发、超时、容量、目录排除、组件下载、常驻记忆、工作方式长度和上下文预算集中由类型化配置提供；实际默认数值在实施时统一写入[参数页](../limits.md)，本计划不复制数值。当前预算、模型选择、图片能力与工具策略继续生效，工作方式、记忆和检索输入同样计入请求容量。

解析、OCR 和记忆提炼分别配置模型／资源身份、预算与数据外发策略，不能静默复用任意已连接厂商。普通模型连接、思考参数、图像输入、MCP／A2A 与计划工具按现有契约适配；已有能力若因本地环境差异不可用，需要在交付范围内明确，不能以客户端升级为由悄悄删除。

传输实现依据为 [axum](https://docs.rs/axum/latest/axum/)、[reqwest](https://docs.rs/reqwest/latest/reqwest/)和 [Tauri Channel](https://v2.tauri.app/develop/calling-frontend/#channels)。这些只说明端口可实现，移动真机、流式背压、文件取消和身份固定仍属于 P12 的交付检查。
