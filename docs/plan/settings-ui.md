# 设置与旧版界面残留整理

范围已确认，实施待启动。改动只涉及界面，不改核心接口与共享契约。由 Haiku 按批次实施，主代理负责决策与验收。[语音转写扩展](usage-models-voice.md)交付前不改其涉及的文件：`voice-settings.tsx`、`components-section.tsx`、`usage-format.ts`、`chat-input.tsx`、`voice-input.tsx` 与录音相关模块。

## 问题与根因

| 问题 | 代码事实 |
|---|---|
| 通用分区杂乱 | 宿主偏好即时生效，独立对话本机执行却走底部保存条；开发者模式下另有三项循环上限；语音行说明最长 |
| 开关抖动 | 宿主偏好异步读取，开关先以关闭、半透明渲染，读到后带过渡滑到实际值；切换一项时两项一起禁用变淡；下方行异步插入后出现滚动条，右对齐控件整体左移；开发者模式说明随未保存状态换文案。均为推断，待在宿主窗口复现确认 |
| 字号看不到数值 | 外观分区用纯文字档名覆盖了带数值的预设标签 |
| 工作台宽度不可见 | 宽度只能拖动或双击恢复，外观分区没有对应设置 |
| 上游新模型接不进来 | 编辑器的目录表写死在界面；目录外模型只能逐个打开自定义表单，表单打开期间保存、测试与其他模型全部禁用；上游列表是无搜索的限高芯片区；同一模型的状态分散在目录、自定义与上游三处；不会提示上游新增模型；单价输入没有单位 |
| 弹框局限 | 设置是覆盖弹层，编辑提供商又叠一层弹框；`/settings` 路由存在但不在应用外壳内 |
| 文件夹面板旧版操作 | 右侧面板标签行、收起按钮左侧的「文件夹操作」菜单只有「添加文件」「刷新目录」两项；文件夹已订阅外部变更并自动刷新，添加文件另有拖放、回形针和工作区底部按钮 |
| 右键是英文系统菜单 | 应用没有自定义右键菜单，会话、工作区与文件树上右键弹出 WebView 原生菜单 |
| 会话行「更多」 | 悬停出现的旧式图标按钮，菜单只有重命名和删除，右键无对应入口 |

## 设计

### 设置独立页面

齿轮与 `openSettingsSection` 都导航到 `/settings`，分区写在查询参数里，并记住来源位置。页面位于应用外壳内，保留全局轨道并高亮设置，不显示会话列表；左侧为分区导航，内容区居中限宽，右上角「返回」回到来源位置。`openSettingsSection` 保持签名，调用方不变。Skill 与运行组件仍从设置导航跳到各自页面。未保存修改的离开保护沿用现有拦截，覆盖轨道与返回。删除设置弹层；对话草稿已按作用域保存，返回后恢复。

### 通用分区

移除三项循环上限的界面，后端字段与默认值不变，保存时原值透传。通用只保留即时生效的开关：独立对话本机执行改为切换即保存，失败恢复原值并在本行提示，通用不再使用底部保存条。按「对话」「通知」「高级」分组，开发者模式放在高级组。每行说明压缩为一句；语音行内容待语音线交付后再精简，本批只调整位置。

防抖动措施：滚动区固定滚动条占位；偏好读到前显示同尺寸占位，不播放滑动过渡；只禁用正在写入的开关并以忙碌状态表达，不改透明度；开发者模式说明固定，阻止关闭的原因只在尝试时提示；公共开关组件只过渡颜色与滑块位移。

### 外观分区

阅读字号的分段显示档名与数值。新增工作台宽度：显示当前宽度，提供预设档位与恢复默认，说明也可拖动分隔条调整。写入工作台现有的宽度偏好，下次打开工作台时生效，确认组件内的内存值不会覆盖新偏好。

### 模型提供商

编辑与新增从弹框改为设置页内的详情视图，顶部可返回提供商列表；保存、删除与取消固定在详情底部，测试结果与外部写入冲突提示留在详情内。

详情上半部分是连接信息，测试连接紧邻密钥。下半部分是统一的模型列表，合并目录模型、上游返回的模型与手动添加的模型。每行包含勾选、模型 ID、来源（目录、上游、手动）、能力摘要和单价摘要，可展开；条目较多时显示搜索。

已保存且有密钥的提供商打开详情时自动读取一次上游列表，新出现的模型标「新」，列表顶部汇总新增数量；读取失败不阻塞编辑。勾选目录外模型即加入并带默认能力，行内标注「默认能力」，展开后编辑窗口、输出上限、能力与单价。校验在行内即时进行，错误停在该行；任一行有错误时保存不可用并定位到该行。列表底部可输入模型 ID 回车添加，供不返回模型列表的上游使用。单价输入带货币前缀与「每百万 Token」后缀，缓存单价留空显示「同输入」。

核心只接受目录模型放在 `models`、目录外模型放在 `custom_models`，界面分类必须与之一致。写死的目录表先移到独立模块；由核心公开完整目录替换它，需要改共享契约，等语音线交付后另行安排。

逐模型参数（温度、单次生成预算、应用上下文预算）只在开发者模式下显示。

### 文件夹面板、右键与会话行

去掉「文件夹操作」菜单。工具栏直接提供添加文件（提示里写明目标目录）与在 Finder 中显示；手动刷新移除，读取失败的状态保留重试。工作区首页文件夹面板的底部添加栏与工具栏入口合并为一处，拖放保持不变。收起按钮旁不再有「更多」。

引入与下拉菜单同风格的右键菜单组件。会话行右键提供重命名与删除，与悬停的「更多」共用同一组操作，并按现行视觉调整「更多」按钮。工作区目录行右键提供在 Finder 中显示、重命名、归档或取消归档与删除，复用现有对话框。文件树条目右键提供预览、在 Finder 中显示与添加文件到此目录。其余区域屏蔽 WebView 原生菜单，可编辑区域与已选中文字保留系统菜单以便复制粘贴。

## 实施顺序与完成条件

1. **外观与模型提供商。** 与语音线无文件重叠，可先做。字号显示数值，工作台宽度可查看和切换；从读取上游到勾选目录外模型、保存、在输入框模型选择器选中并完成一次运行可以走通；目录模型与目录外模型的保存不被核心拒绝。
2. **文件夹面板、右键与会话行。** 文件夹面板没有「更多」菜单；会话、工作区和文件树右键出现中文菜单，其他区域不出现英文原生菜单，输入框仍可右键复制粘贴。
3. **设置独立页面与通用整理。** 语音线交付后开始，开工前核对 `settings-view.tsx` 与 `general-section.tsx` 有无新改动。设置从轨道进入并能返回原位置与草稿；未保存修改离开时被拦下；通用只剩即时开关，打开设置与切换开关时没有位移或闪烁。
4. **走查与文档。** 主代理在宿主窗口逐项验收，记录之前漏掉的旧版残留并补入本计划。把有效设计合入 [UI 设计说明](../../ray_agent/ui/DESIGN.md)的设置、导航与文件夹面板段落及[模型连接说明](../model-usage.md)，按需更新[代码地图](../code-map.md)，在计划索引补入口，完成后清理本计划。

每批完成后在界面目录运行 lint 与构建，并用组件状态目录核对受影响的状态。核心流程以宿主窗口走查为准。
