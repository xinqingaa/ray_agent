# 首页简化与输入体验优化

状态：2026-10-10 用户授权范围已完成实现，包含用户图片的视觉输入链路；首次分项验证与随后授权的自动处理、缩略图调整分别记录。实施前代码基线为 `52ad2d685a18a38407cd6ddc800e3a68c6149d74`。本次依据用户首页截图与源码核对制定方案。

首页应集中承接新任务。移除快速开始和最近对话，补齐图片粘贴、输入高度自适应和进入首页自动聚焦，四项调整均合理。图片成为附件与模型理解图片属于不同能力；本计划同时解决粘贴接入和用户附件的模型视觉输入。

## 评估与当前依据

| 用户提出的问题 | 当前实现与判断 | 建议 |
|---|---|---|
| 快速开始和最近对话可以移除 | 首页示例只是填入文字；首页和侧栏都展示独立对话。移除可让新任务输入成为主要操作，但会减少初次使用的示例引导 | 移除两个模块，保留目标提示；历史入口沿用侧栏，窄屏通过侧栏抽屉访问 |
| 剪贴板图片无法识别 | 共用输入框只有文件选择处理，没有图片粘贴处理。上传接口可以接收文件，不需要为粘贴新增上传接口 | 从用户触发的粘贴事件提取图片，接入同一附件上传流程 |
| 输入内容增多后高度不变 | 文本区固定为 `46px`，禁止手动调整，也没有内容高度计算 | 保留两行起始高度，随内容增高和回缩，到达上限后内部滚动 |
| 进入首页应自动聚焦 | 输入组件没有自动聚焦选项；现有聚焦用于填入文字、命令操作和空消息提示 | 首页进入后聚焦一次，草稿恢复后仍可直接继续输入；不随重渲染反复聚焦 |

实现入口统一见[代码地图](../code-map.md)。`ChatInput` 同时用于独立首页、项目主页和会话页，图片粘贴与自适应应修复在共用组件；移除模块与默认聚焦仅针对独立首页。

修改前，用户附件只有沙箱路径进入模型文本，已有视觉引用由浏览器截图生成。本轮复用视觉引用、容量治理与请求重建，补齐用户图片输入；专用 OCR 服务、自动切换模型及独立识图 Agent 不在范围内，Agent 可以自行选择现有工具尝试读取图片原文件。

## 交互契约

### 首页布局

保留品牌、现有目标提示和输入区，沿用语义颜色、字体与阅读列宽。删除快速开始、最近对话及仅为这两个模块服务的引用和逻辑；侧栏共享会话状态与订阅继续保留，不因移除首页列表宣称减少了网络订阅。

短内容时维持安静的居中布局；输入或附件增多后允许页面滚动，保证内容顶部和发送工具栏可达。检查垂直居中容器在内容超过视口高度时的溢出，不留下不可滚动到的顶部区域。项目主页的对话列表保持其现有职责。

### 图片粘贴

将文件选择中的上传协调提取为共用入口，文件选择和图片粘贴都使用现有上传接口、项目预检规则、附件列表和草稿保存。粘贴事件读取 `clipboardData.items` 中的图片文件，必要时回退到文件列表；同一次事件只使用一套提取结果，避免同一图片上传两遍。浏览器只提供文字、图片地址或 HTML 时，不将它们误当作图片文件，也不自动下载外部图片。

有效文件名保持原名；截图文件没有可用名称或扩展名时，按实际 MIME 类型生成带唯一后缀的图片名。连续粘贴相同内容视为用户再次添加，不做跨事件的内容去重。

纯文本保持原生粘贴。图片和纯文本同时存在时，添加图片并保留文本按当前选区插入的行为；只有图片需要由组件接管时才阻止默认动作。正在提交、压缩、确认发送结果或上传时沿用已有禁用规则；拒绝接入的图片粘贴给出简短原因。

上传期间显示处理中状态并禁止发送；成功后只显示图片缩略图，不展示名称、重复后缀和大小。悬浮或键盘聚焦时，右上角显示预览小眼睛与移除按钮，触屏保留入口；图片本身也可打开通用预览，名称与大小在预览查看。上传失败保留文字和已有附件，多图部分失败只添加成功项。每批上传绑定发起时的草稿作用域，迟到响应不能写入另一页面或草稿。只保存已上传附件的元数据，不将图片 base64 写入草稿存储。

本轮沿用消息需要文字目标的发送规则；只粘贴图片不自动发送，空文字提交时引导补充要对图片做什么。上传成功表示图片已成为输入材料；发送受理后，支持视觉的模型才获得像素输入，分析结论仍需依据模型实际回复。

### 用户图片视觉输入

图片粘贴与文件选择共用同一附件记录。原文件保存并同步沙箱；后台按本次实际模型能力组织输入，PNG、JPEG、WebP 和 GIF 首帧生成最长边不超过 2048 px、最多 2 MiB 的 JPEG 输入，原图最多 20 MiB、4000 万像素。透明区域合成白底、EXIF 方向校正，原始附件不改写。每条消息最多两张用于像素输入；超过数量预算时整批作为文件材料，格式或编码不符合限制的图片单独作为文件材料。

受理事件保存图片引用与输入规格，不保存 base64。模型请求从原附件读取并核对原图摘要，按同一规则重建副本、校验摘要后输入；沿用上下文预算和请求重建。用户图与浏览器图区分来源，尚未观察的图片不能被历史限额静默挤掉；已观察旧图可转为文字引用。

输入区不显示视觉能力状态、图片输入模式或能力切换提示，也不因能力未知和图片数量阻止发送。运行中的补充以活动运行冻结能力为准；非视觉或未知模型获得附件路径，Agent 自行选择工具处理。自动处理说明保存在事件并进入模型上下文，明确哪些图片没有像素，不将文件提供等同于已经看图。用户请求模式仍是 `auto`，避免自动组织输入破坏发送核对；旧客户端 `files` 保留兼容。原文件读取及引用校验失败仍明确报错。

### 输入高度

按实际 `scrollHeight` 计算高度，先解除上一次高度再测量，确保删除内容后能够回缩。覆盖键入、显式换行、文本粘贴、草稿恢复、程序设置文字和成功发送后的清空。

起始高度保持两行；建议上限约为十二行，并受当前视口可用高度约束，最终数值在浏览器走查中确定。达到上限后启用纵向滚动，不隐藏用户查看长内容所需的滚动提示。附件区和底部工具栏独立排版，发送按钮始终可达。

输入宽度变化、侧栏开合、字体大小或视口变化后重新测量，覆盖软换行。测量不得覆盖选区、打断中文组合输入或造成尺寸观察的反复触发；斜杠菜单继续跟随输入区域。

### 首页聚焦

为共用输入组件增加由调用方启用的聚焦选项，默认关闭；仅独立首页开启。当前草稿已加载、文本区可编辑且首页可见后聚焦一次，使用 `focus({preventScroll: true})` 避免额外滚动。

重新进入首页时再次聚焦；输入、上传、模型目录更新和会话列表更新不触发再次聚焦。用户已经操作其他控件或弹窗时不抢焦点；已有草稿保持内容，默认将光标放到末尾。保留项目页新增对话入口的主动聚焦行为，不扩展为所有页面自动聚焦。

移动端检查软键盘弹出后的可视区域与工具栏可达性；浏览器对自动唤起软键盘的限制属于实际验证条件，不宣称桌面聚焦验证覆盖了移动端。

## 实施顺序与完成条件

| 顺序 | 工作 | 完成条件 |
|---|---|---|
| 1 | 简化独立首页 | 两个模块及专属逻辑移除，历史对话可从侧栏和窄屏抽屉访问；长内容下页面可滚动 |
| 2 | 共用上传协调与图片粘贴 | 系统截图可粘贴成附件，支持视觉时图片进入模型请求；其余自动提供文件材料，不要求用户选择输入方式；缩略图预览与移除入口清晰，纯文本、混合粘贴和迟到响应归属正确 |
| 3 | 共用输入高度自适应 | 内容增多时增高，删除和清空后回缩，草稿恢复与宽度变化后重新适配；超长内容滚动且按钮可达 |
| 4 | 首页一次性聚焦 | 直接打开和路由返回首页均可继续输入，保留草稿；普通重渲染与弹窗操作不抢焦点 |
| 5 | 回归与文档合入 | 在真实浏览器验证受影响交互，完成所属指南的相关检查；实现后将事实合入产品和 UI 文档 |

四项为同一次前端工作，完成后统一验收。实施期间保持现有发送恢复、计划模式、模型选择、中文输入和项目附件规则。执行循环调度、数据库迁移和课程不属于本次计划的实施范围；部署更新由用户在实现完成后另行授权。

## 验证范围

实际浏览器检查以独立首页为主，并对共用组件在项目页、会话页做定向回归。桌面宽屏与窄屏、浅色与深色均检查布局；重点覆盖以下场景：

- 用真实系统剪贴板粘贴截图与复制的图片文件；普通文字、图文混合、多张图片、连续粘贴、上传失败、部分成功和上传中重复操作。
- 短输入、多行、长文本软换行、删除回缩、草稿恢复、发送清空、侧栏开合、字号变化，以及超过高度上限后的滚动。
- 首次进入、从会话返回首页、有草稿进入、输入暂不可用、用户已操作其他控件和弹窗；中文组合输入、Enter/Alt+Enter、斜杠命令与 Tab 导航。
- 首页模块移除后的历史对话入口，项目页附件预检和会话页发送恢复；上传过程中离开或切换草稿时的响应归属。

类型检查、lint、生产构建和现有斜杠、命令状态、发送恢复检查按 [UI 开发指南](../../ray_agent/ui/README.md#检查与构建)执行。仅为上传协调、混合粘贴与作用域归属等关键分支增加必要的行为检查；布局、自适应和系统剪贴板必须通过真实浏览器验证，合成粘贴事件不能代替系统剪贴板验收。移动端软键盘与未实际测试的浏览器单独记录覆盖边界。

实施完成后更新[产品说明](../product.md)、[UI 设计说明](../../ray_agent/ui/DESIGN.md)与[能力与边界](../capabilities.md)中的相关事实；只在新增检查入口时更新代码地图和 UI 指南。架构职责没有变化时不更新架构说明。

## 浏览器机制参考

用户触发的粘贴事件可以通过 `clipboardData` 读取数据；无需引入主动读取剪贴板的按钮流程，见 [MDN 粘贴事件数据](https://developer.mozilla.org/en-US/docs/Web/API/ClipboardEvent/clipboardData)。内容高度测量见 [MDN scrollHeight](https://developer.mozilla.org/en-US/docs/Web/API/Element/scrollHeight)。聚焦需要考虑滚动、读屏与移动端软键盘影响，见 [MDN 自动聚焦](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/autofocus)。
