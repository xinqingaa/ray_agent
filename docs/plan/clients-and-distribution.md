## P10：签名、公证、更新与离线包

- Developer ID 签名与公证 DMG；证书与凭据不进仓库。
- 签名更新源与失败回退（与[备份与正式更新](implementation.md#备份与正式更新留给-p10)衔接）。
- 离线组件包：与在线安装同一哈希／可启动校验路径，不从任意 URL 跑安装脚本。
- 完整第三方许可证清单随安装包交付（内部包已有摘要 `THIRD_PARTY_NOTICES.md`）。

## P11：Windows

- 按系统与架构分别构建原生依赖与 Tauri 安装程序并签名。
- 更新与备份机制沿用 P10，在 Windows 上重复首个交付检查。

## P12：移动端

- 同一共享 UI 的 Android／iOS 构建；不打包桌面 sidecar。
- 配对桌面核心后的阅读、发送、审批；无桌面式子进程与文件夹选择时需原生适配。
- 断线恢复不自动重发业务动作；手机不持有桌面密钥或业务库。
