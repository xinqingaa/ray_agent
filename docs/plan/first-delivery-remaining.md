## P9 Mac 闭环

### F12 内部包整体验收

用量、提供商编辑与 DeepSeek 语音纳入整包验收。用系统授权和录音验证回填、拒绝授权和失败重试，并核对新请求费用。场景见[运行检查](../../ray_agent/README.md#运行检查)。

在完整内部包验证真实模型跨会话使用材料和记忆、脚本、组件与浏览器、停止退出、覆盖安装和数据保留，并在没有开发环境的 Apple Silicon Mac 重复。完整包已有本机组件与真实模型短任务的验证记录。全部场景按[首个交付门槛](implementation.md#交付检查口径首个交付)关闭。

整包桌面回归覆盖带 Skill 和图片发送、计划失败后查看所属清单、Finder 跨窗口拖入、竖图预览、原生选择器、撤销确认，以及成果和文件预览的错误恢复。对照原型复验独立 Skill 页、范围入口、来源总开关、三态、三种手动导入和市场卡片。在筛选和目录浮层开合、导入方式切换与预览、市场加载和简介回填时核对外框及列表位置。核对简介、双安装落点和等待续接。用三个工作区及有分页的对话列表复验切换，检查已展开目录、主区输入和会话阅读位置，也核对窄窗口、键盘焦点和减少动态效果。操作入口见[运行检查](../../ray_agent/README.md#运行检查)。
