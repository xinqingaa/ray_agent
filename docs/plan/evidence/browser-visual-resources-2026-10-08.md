| 缺口 | 修复与实测 |
| --- | --- |
| R1 节点身份 | 页面内 Map 绑定原 DOM 节点；克隆替换或同节点名称变化后旧 ref 拒绝，不重新匹配目标；真实 Chromium 通过 |

| R4 观察失败 | 动作成功保留，观察失败使后续写操作未执行；循环与 ScriptedLLM 检查调用配对、原动作不重放 |
