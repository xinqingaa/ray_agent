## 基线与单循环对照

双循环基线 `961005d` 在 2026-09-28 各执行 E1–E6 一次；单循环基线 `0d9ea1f` 加当时未提交清理在 2026-09-29 执行 E1–E7/E6-deny 各两次。环境为 macOS 本地 Compose、动态沙箱、DeepSeek Flash，采样 0.7/8192/65536；压缩任务临时窗口为 24576、输出上限 4096。

| 场景 | 基线观察 | 单循环观察 |
|---|---|---|
| 纯回答与跨轮记忆 | 10 次模型调用、2 次通知工具 | 两次任务各 2 次模型调用、0 工具，记忆检查通过 |
| 文件交付与源材料保护 | 16 次模型调用，结果检查通过 | 5/4 次模型调用，下载 JSON total=60、源文件保持 |
| 提问续接 | 10 次模型调用 | 两次各 4 次，提问和回复配对通过 |
| 长命令停止 | 会话为 completed，停止后标记仍增长，检查失败 | 两次均 cancelled/user_stop，10 秒内标记不增长 |
| 受控网页读取 | 9 次模型调用 | 两次各 5 次，校验码通过 |
| MCP 批准与拒绝 | 仅有批准场景 | 批准取得 6912，拒绝后夹具未收到调用，两次分别通过 |
| 低窗口压缩 | 无此场景 | 两次各压缩 2 次，12 个校验码及源文件结果通过 |

单循环共 16 次必过检查通过，未出现模型重试；已完成轮次的首字延迟为 245–1748 ms。旧镜像没有完整内容身份，缓存与资源条件未严格对齐，不给统一提速、费用或成功率结论。基线原始 JSON 因评测指南引用保留在 [原路径](w0-baseline-2026-09-28-961005d.json)。

该阶段临时 PostgreSQL 9 项通过；全量 API 检查曾有宿主机无法解析数据库地址的接口错误，不能写为全量通过。沙箱进程测试、UI 类型/构建和事件脚本通过，脚本保留 SSE EOF/CRLF 两项限制。受控 MCP/A2A、审批、浏览器及断连补齐为当时专项，不能推广到任意第三方服务。

## 受理与资源归属

2026-10-02、产品 `89aa642` 的标准八类评测各一次通过；API core/protocol 在独立 PostgreSQL 下 329 项通过，沙箱 3 项通过。模型为 deepseek-reasoner、0.7/8192/65536，不能将其与 Flash 基线构成严格性能比较。

首次受理失败、超时读回、慢启动与迟到容器由 50 项定向检查及 UI 脚本覆盖。浏览器没有完整注入所有 HTTP 失败；固定输入拒绝不改记忆、等待续接与审批占用分别检查。项目互斥及恢复证据见 [项目验证](projects-and-files.md)。

2026-10-11、`53873fd` 之上的工作树增加构建身份、结构化计划承接与真实视口。独立 PostgreSQL 验证相同请求并发六次只创建一个执行，过期/跨会话冲突、终态重试读回原结果；没有新增数据库表。真实 UI 按钮显示准备执行，首批业务动作前选择步骤。

七项日常任务加两次定向复测分布在三个构建中，不是最终版本九项重跑。新运行提示升级的实际请求读回通过，历史与等待提示不改写。构建指纹只证明纳入范围的输入一致，不证明上游、配置或所有等待行为可靠。

## 预算与压缩的证据边界

2026-10-10 首批预算与 Shell 等待修改有 317 项核心检查通过、57 项跳过；没有可追溯的该计划真实预算耗尽复测。后续 2026-10-12 真实长任务一次压缩并进入末段，最终 partial；收尾写入、审批计数与请求重建另有确定性检查，见 [计划与成果验证](plans-and-delivery.md)。

低窗口触发压缩不能证明默认 200000 窗口压力通过。模型传输重试与工具执行一次有脚本化检查，不是所有网络未知副作用的幂等保证。多进程认领、API 崩溃后的任意执行恢复、Linux 部署和长期 TTL 没有全面运行证据。
