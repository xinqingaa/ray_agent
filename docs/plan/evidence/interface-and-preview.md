2026-10-10 首次实现基于 `52ad2d6` 后的工作树：115 项后端检查通过、一项跳过，包含真实 Pillow 编码、受理和请求重建，模型/存储/沙箱为替身。前端实际组件检查图片提取、混合文字、部分成功、上传禁发、迟到响应及草稿。
