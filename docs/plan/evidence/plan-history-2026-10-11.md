# 计划清单查看验收

日期：2026-10-11。按用户反馈将原侧面板方案精简为独立 todo 弹框。范围仅为计划可查看性，不包含目标覆盖修复。

## 当前实现

- 会话页右上角仅保留清单图标，点击打开轻量弹框，不进入工作台。
- 每份计划只展示最新待办，跨运行承接和重复核对不新增一份计划。
- 多份清单用前后箭头与序号切换；单份不显示导航，无计划时显示“当前对话暂无计划清单”。
- 清单只读，完成项弱化、当前项强调；停止、失败、中断或进度未确认只显示简短状态。
- 弹框显示“计划清单”标题，复用原计划清单的编号、绿色完成勾选、当前步骤高亮、状态文字与完成数量；不显示用户消息引用、核对时间、旧版本或调整记录。
- 打开期间保留所选计划，关闭后重新打开默认最新；原始事件仍保留。

- 生产 Docker UI 构建通过；已更新 8088 服务，API/UI 内容指纹匹配、服务健康。
- 浏览器使用真实会话 `0d760b27-d59f-4046-a708-105ac94ff8f2`，部署前后均核对最新 6 条待办及桌面、390px 弹框操作、Escape 关闭和入口焦点恢复，无页面错误。

## 边界

仅展示已保存的结构化清单，不把文字方案转换为待办。勾选完成不证明原始目标已经覆盖或业务成果已经验收。
