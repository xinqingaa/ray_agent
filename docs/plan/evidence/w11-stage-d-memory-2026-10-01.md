## 已实施

- 项目说明、笔记与版本、最近对话摘要在锁住项目行的受理事务中读取，冻结至 run 配置。摘要排除当前对话，最多十条，注入文本合计最多1500字符，保留对话、来源、截止 seq 与代次。说明和笔记不静默截断；waiting 沿用本次运行冻结全文，后续新运行读取新版本。
- 基础 system 记忆继续保留原文，项目段只拼接到请求；中英文项目段都已提供。手动压缩按当前项目说明、笔记和摘要估算，不把项目段写入记忆。固定输入不足时普通运行 context_limit；手动压缩422且不改记忆或事件。
- 项目内注册 `update_project_notes(content, base_version)`，独立对话不注册。成功返回新版本；冲突返回当前全文和版本，超过8000字符拒绝。计划模式和工具策略沿用统一管线。笔记全文、版本、来源及运行关联在同事务写项目审计和 `project_notes` 会话事件；用户编辑与 Agent 共享版本。
- 项目设置和笔记支持版本条件保存。设置 UI 已补说明、笔记、版本计数、冲突后的重新加载入口；开发者事件类型增加项目笔记。UI 类型检查通过，当前 UI 镜像尚未重建，这部分尚无浏览器验证。
- 项目 completed 后独立异步请求短摘要，不进入 Agent run 计数。输入仅首条用户目标与各 completed run 最后一条助手回复，各自截断。手动摘要设 manual，自动请求不覆盖；重新生成递增代次并恢复 auto。提交检查来源、代次与截止 seq，旧请求丢弃，失败保留旧摘要。启动将未完成的生成标记失败并使旧代次失效。一般会话保存不回写摘要字段，避免覆盖新结果。
- 业务迁移追加 `f6cad3e75b86`，保留既有迁移和数据。

## 失败及复验

1. 核心回归首先因手动压缩的内存 UoW 缺少新仓库接口失败（249 passed / 44 skipped / 1 failed），补齐替身接口后254 passed / 45 skipped，再在独立PG上299 passed。产品没有为了替身缺失放宽一致性契约。
2. 笔记工具替身断言错误地要求关键字参数，实际回调位置参数；修正测试后通过。
3. 新增手动笔记容量测试误认为预置用户事件不存在；改成比较前后事件不变后9项通过，追加受理冻结后14项通过。
4. 两次类型命令误在仓库根执行了 npx 的同名占位包，不是类型通过证据；在 UI 所属目录实际执行后通过。
5. 初次业务迁移核对误查默认 `manus` 库，该库没有 alembic_version；实际产品库 `rayagent_phase4_20260920` 为 f6。未向默认库写入或改变数据。
6. 真实模型401失败已记录，已请求用户在本地配置有效凭据，不传聊天密钥，不替换或清除既有凭据。尚未有真实模型成功复验。
