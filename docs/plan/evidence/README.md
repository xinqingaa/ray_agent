# 验证资料的使用方式

本目录是项目验证资料的唯一留存位置，按能力主题保留历史验证摘要和必要复核材料。阶段结论和关键报告索引维护在 [维护入口](../README.md#关键验收)，当前能力与限制维护在 [能力与边界](../../capabilities.md)。专题方案引用相应报告，不各建一套证据目录。

报告分别标注版本、日期、模型和环境。本地替身、真实数据库、真实浏览器、真实模型和独立产物核验不能相互替代；历史通过不自动覆盖后续修改，不将不同构建的结果拼成当前版本全面通过。

2026-10-13 依据 Git `b62fda5` 中的原报告整理，未重跑产品验收。完整事件、重复日志、过渡产物和中间截图可以退出留存；各报告列出原路径，可用 `git show b62fda5:<原路径>` 追溯。留存 JSON 是历史观察，不是本次重新执行的输出。历史出处中的路径保持原样，正文可点击链接指向本目录的实际资料。

材料保留主要结论、代表性失败和可独立复核的必要依赖。销售案例保留输入、工作簿、导出的单元格、下载哈希、事件记录及核验脚本；旧基线 JSON 保持评测引用路径。没有保留完整产物的案例明确说明不能仅凭当前目录完整复跑。新增一次性测试报告先输出到临时目录，确认有长期价值后再选入，不默认提交全部转储。
