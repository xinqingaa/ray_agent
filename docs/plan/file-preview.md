# 文件与截图统一查看

用户已授权实施，现已完成。范围为对话附件、交付卡、会话文件、浏览器截图和托管项目文件的只读查看、表格预览、大文件分段读取及多附件 ZIP 下载；不改 Agent 循环，不同步课程，不加入 Office 编辑器。

## 交互契约

- 文件名可打开查看；不支持的类型仍可查看元数据和下载。图标使用短提示和可访问名称，不可用原因不能只藏在禁用按钮内。
- 图片共用适应窗口、缩放、原始尺寸、拖动与下载操作。浏览器页保留操作上下文，临时图的寿命不因预览改变。
- 主动查看后固定当前对象；关闭大预览回到原阅读位置。正常状态保持安静，前端不承载设计解释、技术方案或长篇能力说明。
- 文件页不显示交付工具原始 JSON；开发者视图保留事件。项目副本状态与附件交付状态保持独立。
- CSV/TSV 使用表格，XLSX/XLS 支持工作表切换和关键单元格格式。公式不重算，复杂样式缺失不冒充完整还原。
- 去掉统一 5 MB 禁用规则，按类型控制读取、解压、像素、输出范围和处理耗时。分页和部分预览使用短状态，不把上限解释铺在界面。

## 实现与验证

共享查看器与来源适配分别处理附件、项目当前文件和临时截图。预览解析在有界子进程中执行，项目读取继续使用不跟随符号链接的文件 IO；缓存区分项目版本，旧响应不得覆盖新选择。附件批量下载生成单个 ZIP，不改变源文件。

完成条件：销售表三个输入与交付工作簿可读，图片各入口交互一致；大于 5 MB 的正常文件可按类型预览；分页、损坏文件、临时图到期、项目版本变化、乱序响应、ZIP 重名与故障得到检查；源文件字节不变。后端定向测试、前端类型/lint/build、已有相关恢复检查及真实服务和浏览器验证分别记录，不互相替代。

完成结果与关键证据见[统一预览验收](evidence/file-preview-2026-10-09.md)，当前交互维护在 UI 设计说明，预算与未验证范围维护在能力与边界。此计划不扩展为新工作清单。
