# 用量统计、模型连接编辑与语音输入

首个交付进入 P9 前追加的三项能力。**已授权：原型（`prototype/`）；服务端与共享界面：未授权实施。** 原型的入口与评审方式见[原型说明](../../prototype/README.md)，设计规则见[原型设计](../../prototype/DESIGN.md#用量模型连接与语音)。

## 现状与缺口

- 每轮模型请求的 Token（输入、缓存命中、输出、思考）记录在轮次事件，运行汇总累加。标题、记忆提炼与摘要等辅助请求不进入轮次事件，用量没有记录。没有按时间与模型聚合的存储，也没有价格与费用概念。
- 模型连接只能在用户配置文件中手写，设置页只读。模型 id 必须在内置目录中，目录外的模型被忽略并提示"未知模型"，新增模型需要改代码。
- 没有音频输入。两家已接入的聊天模型中，DeepSeek 不接受音频；OpenAI 提供独立的转写模型，按音频时长计费。RayAgent 没有云端服务，“服务端”是本机核心，转写要么在本机运行识别模型，要么调用付费的云端接口。

## 一、用量与估算费用

### 目标

按请求记录 Token 和估算费用。对话内只给一项简短的费用，可以在设置中关闭；设置提供按范围、提供商与模型的完整统计。

### 设计

1. **请求级记录**：新增用量表，每次拿到 usage 的模型请求写一行：时间、会话／运行／工作区（可空）、用途（主任务、压缩、标题、记忆、摘要、转写）、提供商、模型、输入、缓存命中、输出、思考 Token、音频时长、估算费用、价格版本、计价时段。记录在模型客户端统一完成，辅助请求不再遗漏。请求失败、没有 usage 时不写费用，只计次数。
2. **写入时固化费用**：费用按请求当时的价格计算并保存，调价不改写历史。价格表随核心发布，带版本、更新日期与来源；自定义模型可在连接配置中填写单价，未填写时只统计 Token，费用显示为空而不是零。
3. **计价规则**：未命中缓存的输入、缓存命中与输出分别计价。DeepSeek 按请求时刻判断高峰（工作日 UTC 01–04、06–10 点）与低谷价；法定节假日的低谷价无法可靠判断，按高峰估算。OpenAI 的超长提示加价在当前窗口上限下不会触发；缓存写入、批量与优先级档位、账单折扣和赠送额度不计入。界面用小字说明估算口径，以服务商账单为准。
4. **聚合接口**：按范围与提供商筛选。范围为预设（今天、24 小时、近 3 天、近 7 天、近 30 天、近 90 天）或自定义起止；自定义精确到整点，起止都在保留期内，结束不含。返回总计与上一等长周期的对比、时间桶、提供商→模型明细、用途拆分、星期×小时矩阵（每格带主要模型），以及近 13 周的逐日费用。桶大小由跨度决定：两天内按小时，八天内每 3 小时，更长按天；预设范围中今天与 24 小时按小时，近 3 天每 3 小时，其余按天。时间桶按本机时区划分。精度只到整点，因为记录按小时聚合，计价时段也按小时划分。
5. **对话内投影**：轮次完成与运行汇总事件附带本轮或本运行的估算费用，界面据此实时累加；会话累计由聚合接口提供。
6. **历史回填**：主循环的历史用量可从轮次事件与运行快照中的模型回填，标记为回填，按回填时的价格估算。
7. **数据生命周期**：删除会话时保留用量记录、解除与会话的关联，总额不变；清空全部数据时一并删除。

### 界面

- 回复底部的统计行追加一项估算费用。悬停显示模型、计价时段、输入／缓存／输出 Token 与本对话累计。运行中，过程标题随轮次更新已花费。设置关闭后对话内不显示任何费用。
- 设置新增「用量」分区：费用显示开关、范围与提供商筛选、四项指标（估算费用、Token、请求、缓存命中，含与上期对比）、按提供商堆叠的费用柱状图、热力图、提供商→模型明细表、用途拆分与估算口径说明。
- 自定义时段在范围分段的最后一项打开锚定浮层：月历选起止日期，默认整天，打开「按小时」后选起止整点；超出保留期的日期不可选，结束早于开始时不能应用。
- 热力图与范围的关系：「日历」固定显示近 13 周的长期节奏，所选范围内的日期正常显示、其余变淡；点击某天把范围切到这一天，Shift 点击选择连续几天。「时段」（星期×小时）只统计所选范围，点击格子固定查看明细，可标出 DeepSeek 高峰时段。两种视角共用侧栏：悬停、键盘或固定的那一格显示费用、请求、主要模型与计价时段，否则显示汇总；悬停格子高亮对应的行列标签，悬停图例某一档只突出该档。整张图只占一个 Tab 位，方向键移动，Enter 选择，Esc 取消。
- 柱状图：悬停或方向键所在的柱子突出，图上方固定的读数行显示该段费用、请求与各提供商金额；按天的柱子在日历上联动标出同一天；点击按天或每 3 小时的柱子下钻到当天按小时。
- 稳定性：分区骨架只渲染一次，筛选、下钻与悬停只就地更新内容；读数行、侧栏、指标卡与热力图区域尺寸固定，表格与用途列表的行集合不随时间范围增减，页面不因交互跳动或滚动。
- 图表用自研 SVG 组件 [charts.js](../../prototype/charts.js)，布局计算与渲染分离：布局函数只返回几何数据，共享界面可以映射为 React 元素，不需要插入 HTML 字符串。颜色经 CSS 变量传入，系列色按实体固定，已用色觉与对比度校验工具在浅色和深色下分别校验。

### 依赖与完成条件

依赖模型客户端的统一出口和连接配置中的单价字段（第二节）。完成条件：主任务与各类辅助请求都有用量记录；六档范围的聚合结果与逐条记录求和一致；调价后历史费用不变；关闭偏好后对话内不显示费用；未填单价的模型显示为空而不是零。

## 二、模型连接与自定义模型

### 目标

在设置中新增、编辑、删除提供商，更换地址与密钥，选择目录模型或声明目录外的模型，保存前可以测试连接。上游不支持某项能力时直接报出上游错误，不做兼容回退。

### 设计

1. **单一来源**：连接仍保存在用户配置文件，密钥不进入业务库与日志。核心负责写回：保留注释与未知字段，写临时文件后原子替换，权限 0600。
2. **并发修改**：读取结果附带文件身份作为版本，保存时校验；文件在外部被改过则返回冲突，界面提示重新读取后再保存。
3. **接口**：
   - 列出提供商与读取状态（已有）。
   - 新增或更新一个提供商：不传密钥时保留原密钥，响应只返回掩码。
   - 删除提供商：引用其模型的会话在下次运行时按"端点缺失"报错并提示换模型。
   - 用草稿测试连接：不保存，读取上游模型列表或发一次最小请求，返回耗时与上游错误原文（状态码与消息），密钥不回显。
   - 读取上游模型列表，帮助填写模型 id。
4. **用户声明的模型**：配置可为提供商声明目录外的模型，填写上下文窗口、输出上限、工具调用、图片输入、思考开关与可选单价。目录对这类模型使用声明值，未声明的能力按保守默认（不发送思考与工具批量字段）。能力填错时由上游报错，错误原样进入运行失败原因。
5. **生效时机**：沿用现有规则，新配置用于下一次运行，进行中与等待续接的运行使用原快照。

### 界面

「设置 → 模型提供商」改为可编辑卡片：地址、协议、密钥掩码、模型数与测试结果就地显示。添加与编辑使用对话框：类型预设（DeepSeek、OpenAI、OpenAI 兼容）、名称（兼容类型）、地址、协议、密钥（已有密钥只显示掩码，需点「更换」才输入）、目录模型勾选、自定义模型（含从服务读取模型列表）。底部提供测试连接、删除、取消与保存；测试失败显示上游返回的错误。「打开配置文件」保留为次要入口。

### 依赖与完成条件

依赖保留注释的 TOML 写入库。完成条件：界面完成的增删改与手写配置文件等价；外部修改后保存得到冲突而不是覆盖；测试连接在上游不支持时显示上游原始错误；密钥不出现在任何响应与日志中；声明的自定义模型可被会话选择并按声明参数请求。

## 三、语音转文字

### 选择

先做语音转文字：录音 → 本机核心转写 → 文字填入输入框，用户修改后再发送。默认在本机转写，云端转写作为可选。不接多模态语音模型。原因是两种协议的音频输入格式不同，DeepSeek 不接受音频；音频进入上下文后还要处理容量与计费；实时语音还涉及双向流、打断与播放。Agent 任务以工具调用为主，语音直接进入模型带来的收益不足以覆盖这些成本。

### 设计

1. **录音**：输入框的麦克风按钮开始录音，录音条显示时长与波形，提供取消（Esc）与完成。录音只在内存中暂存，转写成功或丢弃后释放。
2. **本机转写（默认）**：作为运行组件「语音转写」提供，内含 whisper.cpp 可执行文件与多语言模型，复用组件的下载、校验、原子切换与重试。核心以子进程调用，在 Apple Silicon 上用 GPU 加速，离线可用、不产生费用。界面用 Web Audio 直接采集 16 kHz 单声道 PCM 并封装为 WAV，避免引入音频转码依赖。组件未安装时，首次点麦克风提示安装或改用云端。模型大小与识别质量的取舍在实施时实测中文样本后确定。
3. **云端转写（可选）**：经已配置提供商的转写模型（首选 OpenAI `gpt-transcribe`）转写，按音频时长计费并写入用量表。DeepSeek ASR 的接口格式需先核实，再决定是否作为选项。两种方式都写入用量记录，用途为"转写"，本机转写费用为零。
4. **失败**：转写失败时保留录音，显示原因（本机组件无响应或上游错误），提供重试与丢弃。
5. **设置**：「设置 → 通用 → 语音转文字」在本机、OpenAI 与关闭之间选择；关闭后输入框不显示麦克风。

### 风险与完成条件

需要实测打包后 WebView 的麦克风权限：宿主需声明麦克风用途说明，首次使用时由系统询问。本机转写组件需要按其他组件的方式构建与签名。完成条件：内部包在无开发环境、无网络的 Mac 上完成组件安装后的授权、录音、本机转写、填入与失败重试；切换到云端后同一流程可用并计费；拒绝授权时给出前往系统设置的说明；转写进入用量统计。

## 实施顺序

原型已完成（本页授权范围）。服务端与共享界面获得授权后按以下顺序实施：用量记录与价格表 → 聚合接口与用量界面 → 连接写回与自定义模型 → 语音转写。前两项可独立交付；自定义模型的单价依赖连接写回；本机转写依赖组件构建，云端转写依赖已配置的转写提供商。
