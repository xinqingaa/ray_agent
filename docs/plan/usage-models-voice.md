# 语音转写扩展

当前实现及使用方式见[模型连接、用量与语音输入](../model-usage.md)。本机与 OpenAI 转写保留为后续计划，待另行授权。

## 本机转写

新增受管运行组件，包含 Apple Silicon 可执行文件、Metal 加速和多语言模型。复用组件的下载、校验、原子发布和重试，从中文、粤语和夹杂英文的样本核对识别效果，确定模型尺寸。核心复用当前 WAV 接口与用量记录，音频留在本机，费用记零。打包后在无开发环境的 Mac 完成组件安装，再断网验证录音、转写、回填、失败重试和丢弃。

## OpenAI 转写

使用已配置的 OpenAI 连接接入文件转写，实施时核对现行模型、返回的用量和时长计价。接入同一个语音偏好、音频校验和用量接口。验证提供商切换、权限拒绝、上游失败、重试和费用记录。
