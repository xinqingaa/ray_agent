# 用户交互与文件阅读优化方案

状态：项目信息结构、查看器、输入、开发者入口和统计调整已实施并收尾。当前使用见[产品说明](../product.md)，交互细则见 [UI 设计说明](../../ray_agent/ui/DESIGN.md)，形成过程见[交互背景](../background/interaction-and-configuration.md)。

## 目标与范围

让用户知道入口属于哪个项目或对话、将看到什么、编辑何时生效，以及关闭后返回哪里。材料阅读不需要启动任务，技术观察不占据普通阅读流程。

覆盖项目导航、记忆、预览、输入、开发者偏好和统计。展示开关不改变权限与执行事实，模型接入见[模型方案](model-connections-and-selection.md)。

## 事件投影与连续阅读

提交与读取分开：发送负责受理，详情与一条事件订阅负责状态，按最后序号补齐并去重。

会话视图由统一投影产生：

- 同一运行与轮次内按调用身份合并开始和结果，多次运行按事件顺序连接。
- 失败和重试保留原事件，普通时间线可折叠旧提示，但不能删改持久事实。
- 主区依据实际活动显示处理中，计划阶段和工具活动分别表达，工具名不证明阶段完成。
- 消息只引用当时已交付的附件，不关联未来版本；临时增量由完整消息替换，不永久保留两份。

等待、拒绝、取消、未执行及未知效果可区分。实时走秒由组件计算，纯投影不依赖时钟；工作台默认跟随最新操作，手动选择后固定，并提供返回最新入口。关闭技术入口停止不必要轮询，原始结果按需展开。

## 共用命令状态与容量入口

- 输入、菜单、斜杠与上下文环消费同一命令状态，说明发送、上传、审批、压缩和项目占用的不可用原因，只读导航继续可用。
- “按计划执行”依赖有效计划、具体版本和受理结果；入口在回复下方，提交时禁用，不形成后续动作的永久批准。
- 容量展示使用同一份窗口、预留、估算及冻结背景，无数据不显示假比例，压缩后估算增大不称为释放空间。

停止、重新开始和压缩沿真实动作处理，不为菜单数量增加命令。压缩超时先读回，设计见[上下文方案](execution-and-context.md#手动压缩与容量可解释性)。

## 项目信息结构与返回路径

| 入口 | 职责 | 返回与状态 |
|---|---|---|
| 侧栏项目与新增对话 | 打开主页或聚焦输入 | 保留草稿，发送才创建会话 |
| 对话、文件、说明、笔记、摘要 | 稳定材料管理 | 页签、搜索和编辑各有归属 |
| 项目设置 | 名称及归档/删除 | 回原页签，焦点回入口 |
| 恢复与操作记录 | 独立修复流程 | 不切当前页签 |
| 对话项目记忆 | 阅读共享背景 | 保留对话位置与输入 |
| 修改记录 | 历史取回草稿 | 保存后才改当前版本 |
| 开发者上下文 | 候选背景及运行快照 | 来源明确，无快照不冒充已使用 |

侧栏不重复项目管理菜单，设置不承担内容导航；对话侧阅读材料，不另建项目管理后台。标题与页签固定，内容区滚动，长文本保持可达。

会话临时标题、异步建议与手动命名沿同一事实更新：建议保存后生效，迟到自动结果不覆盖手动名称，列表与顶部保持一致。

## 设置、删除与草稿状态链

1. 名称按裁剪后的有效值比较，未改不提交；失败留表单并保留草稿，成功同步名称并退出。
2. 取消、关闭、Escape 与遮罩共用离开保护，保存中不重复提交或关闭。
3. 名称草稿未处理时禁止归档/删除；删除进入独立确认，取消返回设置并恢复焦点，不并列两个可操作弹框。
4. 占用导航退出整条弹层链；切项目、冲突与迟到响应检查对象归属，不污染新项目或静默覆盖编辑。

归档与删除业务设计见[项目方案](projects-and-data.md#归档删除与业务清空)，真实删除验证使用隔离材料。

## 记忆内容与技术观察

说明、笔记和摘要属于稳定内容分区，修改记录是辅助历史，实际输入快照属于技术观察。辅助视图保留草稿并明确返回原分区，摘要编辑不叠加第二层弹窗。

当前项目组合是新运行的候选背景，活动运行使用冻结快照；候选不能冒充实际输入，等待也不随当前编辑改变。开发者偏好在同源标签页同步，关闭时回退可见内容并停止技术轮询，普通阅读与运行状态保持。

原始事件、请求重建和 JSON 操作用于检查，不等于远程桌面接管。

## 统一文件查看与下载

文件卡、工作台和项目文件共用只读查看器，打开不启动运行或沙箱：

- 文本分段、表格按窗口读取，绑定版本与预算，损坏、超限、改版和到期有明确出口。
- Excel 还原工作表、常见格式与已有公式缓存，不承诺完整 Office 还原。
- 图片缩放保持焦点返回，HTML 在独立页面隔离运行，但不承诺完整网络隔离。
- 原件下载保持字节，ZIP 只包含明确范围，不收集无关输入材料。

解析和缓存有容量与期限，项目改版后不沿用旧分页。工具历史用当时结果，当前文件注明当前状态，不能冒充历史快照。

## 共用输入、上传与图片

- **草稿归属**：上传绑定发起作用域，切页、清空或换草稿后迟到结果不加入新内容；部分失败保留成功项。
- **内容高度**：键入、粘贴、恢复、程序填充和宽度变化后重测，删除与发送后回缩，超限内部滚动，工具栏可达。
- **输入连续性**：不破坏中文组合输入、选区或斜杠菜单；首页初次编辑及路由返回聚焦，普通渲染和上传更新不抢焦点。
- **图片处理**：缩略图可预览及移除，后台按能力与容量组织像素或文件，原图与输入副本分开，同名附件使用不同路径。
- **消息衔接**：受理、注入、等待和请求重建保留图片来源及原因说明；上传成功不代表模型读过像素。

普通识图与明确 OCR、属性读取、编辑分别处理，不自动安装识图环境。移动软键盘需真实条件验证，桌面聚焦不代表覆盖。

## 统计、浮层与可达性

统计区分本次与累计、模型耗时与任务墙钟，调整位置不改变口径。Tooltip 用于短解释，菜单提供选项，对话框承担编辑与确认；无障碍名称与可见说明一致。

关闭浮层后焦点回到入口，窄屏、高字号和键盘操作保持可达，不以固定高度截断内容。

局部尺寸、颜色与样式以实现为准。

## 模块责任与依赖

| 模块 | 前置条件 |
|---|---|
| 事件投影 | 后端身份明确，组件消费同一视图 |
| 输入、上传与命令 | 草稿作用域、受理身份及不可用原因统一 |
| 项目、设置与记忆 | 保存、冲突、脏状态和返回路径一致 |
| 预览服务与查看器 | 有预算、版本化读取先于类型展示 |

主区状态依赖运行活动，消息链接依赖当时交付，清单依赖稳定身份。最近模型偏好见[模型方案](model-connections-and-selection.md#responses-通信与最近选择)，执行引导见[计划方案](long-task-trust-and-delivery.md)。

## 完成条件

- 切换、关闭、冲突与保存失败保留草稿及阅读位置，入口归属清楚。
- 等待、终态与工具结果分开，历史文件不指向后来版本。
- 预览分页、改版与异常有出口，迟到上传、混合粘贴及中文输入可用。
- 开发者开关只改展示，隐藏入口停止不必要轮询。

组件替身、浏览器、解析器和模型输入各验证不同路径，入口见 [UI 指南](../../ray_agent/ui/README.md#检查与构建)和 [API 指南](../../ray_agent/api/README.md)。
