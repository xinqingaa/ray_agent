# 用户交互与文件阅读优化方案

状态：项目信息结构、查看器、开发者入口、首页输入和统计调整已实施；首次分项验收、后续组件检查与仅构建修订分开见 [界面验证](evidence/interface-and-preview.md)。2026-10-13 依据 Git `b62fda5` 合并原多轮专项，不重做界面或配图。

问题形成过程见 [交互与配置背景](../background/interaction-and-configuration.md)。当前操作维护在 [产品说明](../product.md)，详细交互规则维护在 [UI 设计说明](../../ray_agent/ui/DESIGN.md)。本篇保留信息结构、状态关系及完成条件。

## 目标与范围

会话执行体验维护：已实施并完成本地定向和有限真实验收。授权日期为 2026-10-13，范围为修复模型生成工具参数时主区状态缺失、将消息中的沙箱文件链接关联到当时已交付附件，并使收起的计划条展示当前子步骤和整体进度，展开与历史清单通过勾选和层级表达进度，避免重复计数。状态由当前运行活动驱动；文件引用由事件顺序中的交付身份驱动；历史消息不改写，旧回复不能关联未来版本。执行层的细化引导、进度提醒和最终回复规则见[计划与交付方案](long-task-trust-and-delivery.md)。完成条件为定向检查、原会话回放、桌面/窄屏界面观察和不同任务的真实验证；不重做界面或改变执行内核。

让用户清楚入口属于哪个项目或对话、将看到什么、编辑何时生效，以及关闭后返回哪里。查看材料与成果无需启动任务，技术观察不占据普通阅读流程。

范围包含项目主页与管理、记忆视图、文件预览、共用输入、开发者偏好和统计位置。执行权限、运行事实和文件保护继续沿原服务契约，不因界面开关改变；模型接入设计另见 [模型方案](model-connections-and-selection.md)。

## 事件投影与连续阅读

提交消息只负责受理，详情及一条事件订阅负责读取；按最后 seq 重连并去重，不为发送再建立第二条独立过程流。run 事件决定运行状态，按钮提交中只是临时交互状态，不能乐观改写服务端事实。

会话视图由纯投影统一生成：同一运行与轮次的工具按 call ID 合并开始/结果，多次运行按事件顺序连接，旁白、回复、提问、审批、交付、压缩和失败尝试分别表达。失败轮次不因后来相同内容重试而隐藏；终态仍无结果的调用说明中断或未知效果，不改成成功。

组件读取同一运行、计划、工具、文件及用量视图，不各自从工具名推断阶段。等待回复与等待审批可区分，工具成功、失败、拒绝、未执行、取消和截断可观察。实时走秒由组件根据时间戳计算，投影不依赖时钟；模型增量是临时展示，完整事件到来时替换，不永久保留两份回复。

工作台默认跟随可见新操作，用户手动选择后保持固定，并提供返回最新结果的入口；关闭技术入口停止不必要轮询。原始输出按需展开，普通记录用动作摘要和必要错误，不能从隐藏详情推断动作没有发生。

## 共用命令状态与容量入口

输入区、附件/命令菜单、斜杠入口和上下文环消费同一 command context。发送、上传、等待审批、压缩、项目文件占用和未修复状态有对应原因；导航和只读查看不因不可写被隐藏。前端预判断不替代服务端准入。

计划模式与执行模式使用同一循环，副作用允许清单由程序维护；有效计划生成并结束后才出现执行入口，按钮不构成所有未来动作的永久批准。停止、重新开始和手动压缩沿真实动作处理，不为了菜单数量增加新命令。

上下文环及详情分别表达实际输入和估算来源，窗口、输出预留与余量来自同一快照，项目固定背景计入预算。没有数据不显示假百分比，压缩后估算变大也不说释放空间。手动压缩超时后先读回结果，完整设计见 [上下文方案](execution-and-context.md#手动压缩与容量可解释性)。

## 项目信息结构与返回路径

| 入口 | 职责 | 返回与状态 |
|---|---|---|
| 侧栏项目名称 | 项目主页 | 保留页面和草稿，不隐式创建运行 |
| 项目新增对话 | 聚焦主页输入 | 发送才创建会话 |
| 主页对话/文件/说明/笔记/摘要 | 稳定内容管理 | 页签、搜索与编辑状态有明确归属 |
| 主体项目设置 | 名称与归档/删除 | 返回原页签，焦点回到入口 |
| 恢复与操作记录 | 独立管理弹窗 | 不切换当前页签，失败可读与可修复 |
| 对话项目记忆 | 查看说明、笔记和摘要 | 保留对话阅读位置与输入 |
| 修改记录 | 取回历史进入草稿 | 保存后才修改当前版本 |
| 开发者上下文预览 | 当前组合与实际运行快照 | 标明来源对话，无快照不假称已使用 |

侧栏不重复项目菜单，设置不承担说明/笔记导航；摘要在主页稳定分区，技术预览只在开发者入口。容器标题不因模式切换改变，项目名提供归属。

标题、页签及管理弹窗操作栏保持固定，正文承担滚动。文件、长说明与摘要各有稳定阅读位置；不能为固定高度让长内容不可达。对话侧保持材料/成果阅读，不成为第二套项目管理后台。

会话标题沿首次临时标题、异步建议与手动保存的生命周期处理。建议需要保存才生效，迟到自动结果不能覆盖手动修改；重命名入口在顶部与列表保持同一事实，不能让导航刷新产生两个名称。

## 设置、删除与草稿状态链

名称按有效裁剪值判断是否改变，未改时保存禁用；成功同步名称并退出，失败留在表单保留草稿。取消、关闭、Escape 和遮罩采用同一离开保护，保存中不能重复提交或关闭造成结果归属不清。

名称草稿未处理时归档/删除不可用并说明原因。删除进入独立确认，原设置暂时退出，取消确认回到设置并恢复焦点；占用导航先退出整条弹层链。不可同时出现两个可操作弹框。

并发冲突、切换项目和迟到响应均检查归属。旧请求不能污染新项目，编辑冲突提供最新状态，不静默覆盖草稿。归档和删除的业务差别及清理失败入口由 [项目方案](projects-and-data.md)维护，视觉验收不删除真实用户数据。

## 记忆内容与技术观察

说明、笔记、摘要是内容分区，修改记录是辅助视图，实际输入快照属于开发者观察。查看辅助内容保留原分区与编辑草稿，返回名称明确；摘要编辑在同一内容流程内进行，不叠加第二层编辑弹窗。

当前项目组合是可用于新运行的候选背景，活动运行快照是实际冻结输入。预估与实际使用分别显示，等待运行不被当前编辑改变。版本、摘要截止和生成冲突沿后端契约，开发者开关不改变内容来源。

开发者偏好保存于当前浏览器并同步同源标签页，跨页保持。关闭时隐藏技术页签，当前选中隐藏入口需要回退到可见内容，终端轮询也应停止；输入草稿、正常文件阅读和运行状态不改变。原始事件、请求重建、JSON 展开/复制/下载用于检查，不等于远程桌面接管。

## 统一文件查看与下载

文件卡、工作台和项目文件使用统一查看能力，打开文件不启动运行或沙箱。文本、CSV/Excel、图片和 HTML 按类型展示；原始下载是独立操作，保留原字节，批量 ZIP 只包含明确范围。

文本按段，表格按窗口分页，Excel 支持工作表切换与有限格式还原；损坏、超限、未知类型、到期和版本冲突都有明确出口。解析与缓存有容量和时间限制，项目分页不能在改版后继续使用旧版本结果。图片共用缩放、大图和焦点返回。

HTML 在隔离页面展示自己的脚本与存储，应用接口访问受到约束；不能宣称完整外部网络隔离或所有依赖都可用。预览不等于完整 Office 还原，解析结果也不替代原件。

源附件与明确交付区分，“本次交付下载”不收集全部输入材料。查看工具历史采用当时结果，当前文件内容注明当前状态，不能冒充过去的文件快照。

## 共用输入、上传与图片

独立首页聚焦输入，历史入口沿侧栏；上传、粘贴和草稿逻辑由共用输入协调。附件请求绑定发起作用域，切页、清空或换草稿后的晚到响应不归入新内容。部分失败保留成功项，上传中发送按实际状态处理。

输入高度按 scrollHeight 重测，键入、换行、粘贴、草稿恢复、程序填充和宽度变化都覆盖；删除和成功发送后回缩，达到高度上限时内部滚动，工具栏和发送按钮可达。中文组合输入、选区和斜杠菜单不能被测量破坏。

首页初次可编辑及路由返回时一次聚焦，普通重渲染、上传更新和弹框操作不抢焦点。移动端软键盘需要真实条件单独验证，桌面聚焦不代表已覆盖。

图片在输入区以缩略图预览、查看和移除。后台按能力、数量、编码与容量自动组织：符合条件的进入像素请求，其余保留文件材料并保存原因。用户不必选择技术输入模式；原图和模型输入副本分别记录，同名独立附件使用不同沙箱路径。

图片消息在正常受理、运行注入、等待续接与请求重建中保持来源及说明。上传成功不能被模型解释为已读取像素；普通识图与工具处理边界见 [能力文档](../capabilities.md#用户图片输入)。

## 统计、浮层与可达性

运行统计关联当前过程和终态，明确本次与会话累计、模型耗时与任务墙钟、生成速度与费用口径。位置调整不修改运行事实。没有实际新浏览器验收的修订，不能沿用早期公式检查宣称展示已验证。

Tooltip 仅解释短信息，菜单承载可操作选项，对话框承载编辑与确认。公共提示和无障碍名称一致，避免按钮同时出现两份提示。关闭回到调用入口，键盘操作、窄屏和高字号保持内容可达。具体尺寸、颜色和局部样式在实现及 UI 说明维护，不续写每次修改日志。

## 实施依赖与验收

| 顺序 | 工作 | 必须检查 |
|---|---|---|
| 1 | 稳定内容分区、入口和返回路径 | 项目/会话归属、当前页签、无重复入口 |
| 2 | 设置及记忆编辑状态链 | 脏状态、保存失败、冲突、迟到响应、弹层与焦点 |
| 3 | 统一预览与下载 | 真实解析、分页、超限、损坏、版本、到期、原字节 |
| 4 | 共用上传与输入 | 混合粘贴、部分失败、同名、作用域、中文输入与回缩 |
| 5 | 开发者观察与统计 | 隐藏入口回退、轮询、草稿、来源、计量口径 |
| 6 | 实际桌面/窄屏和定向回归 | 真实系统剪贴板、布局、返回焦点与阅读连续性 |

组件替身覆盖竞态和错误，真实浏览器覆盖布局、系统剪贴板与焦点，后端真实解析器覆盖格式，实际模型专项只证明像素编码链路。必须区分各自条件，不能合称新部署端到端全面通过。命令入口见 [UI 指南](../../ray_agent/ui/README.md#检查与构建)和 [API 指南](../../ray_agent/api/README.md)。
