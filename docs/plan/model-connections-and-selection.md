# 模型目录与端点配置优化方案

状态：模型目录、内部端点映射、逐模型参数、Responses 通信和最近选择已实施并收尾。本篇保留接入设计、责任和依赖，问题形成过程见 [交互与配置背景](../background/interaction-and-configuration.md#模型接入从猜域名转向明确目录)。

## 目标与范围

用户只选择模型与思考，部署维护者配置实际连接。模型能力不由上游域名推断，端点变化不改变模型身份；前端从后端目录取得可用选择，不维护第二份白名单。

范围覆盖端点读取、模型映射、参数保存、通信编码、运行快照和选择交互。保持现有会话结构、自研单循环及工具流程，不建设连接管理 CRUD、自动端点回退、多渠道调度或费用硬预算。配置示例和操作方法只维护在 [运行指南](../../ray_agent/README.md#模型与工具)。

## 能力、连接与参数分开

| 信息 | 责任位置 | 契约 |
|---|---|---|
| 模型 ID、厂商与思考、工具、视觉能力 | 后端模型目录 | 模型身份决定请求规则，代理地址不改变能力识别 |
| URL 与 Key | API 环境配置及端点加载器 | YAML 只保存环境变量引用，真实凭据不返回选择接口 |
| 模型到端点的映射 | 应用配置 | 已知模型缺失端点明确失败，不回退到其他模型服务 |
| 温度、生成上限和窗口 | 逐模型配置 | 整体校验后原子保存，预算按目录封顶 |

端点加载统一使用 API 所属环境；仅缓存配置类结构，不缓存凭据。非法 URL 隔离到所属端点，显式清空 Key 不恢复旧值。缺 Key 的已配置模型仍可读取目录和预览容量，实际调用前拒绝；一个不可用端点不阻止其他可用模型。

同一模型只出现一次，维护者通过内部映射选择兼容上游。新增模型需要补充并核验能力目录，新增通信协议需要适配；新增兼容地址不自动证明参数、工具与视觉可用。标题和项目摘要使用辅助模型机制及对应端点，辅助失败不阻塞主任务。

## 对话参数与运行快照

对话首次运行冻结采样参数，同模型后续运行沿用；对话中换模型后，新运行读取目标模型当前参数并重新估算容量。正在执行及等待续接的运行始终使用自己的模型、思考、通信协议和提示快照。

思考开关、档位和回传规则来自模型目录，同名档位不能假定跨系列等价。快照区分未发送字段与显式关闭，GPT effort 不根据 DeepSeek 开关猜测。实际 usage、缓存和推理用量沿上游返回记账，容量估算不代替账单。具体预算规则和数值见 [运行参数与限额](../limits.md)。

## Responses 通信与最近选择

模型通信由基础设施适配，工具、审批、压缩、历史和运行状态仍由 RayAgent 管理。默认协议与兼容选项见运行参数页，不引入服务端会话或托管工具。

适配转换领域消息和工具声明，完整终态后归一结果与用量。推理条目随对应助手消息保存，按模型及回传规则复用；不将其他模型的加密推理转发。旧 Chat 消息转换为输入条目，持久事件不改写，等待按冻结协议重建客户端。

语义流失败与 SDK 异常统一分类。连接、限流、服务错误和明确暂时中断可有限重试；参数、鉴权、额度与未知错误不重试。连接未建立的退避与普通尝试分开，但都受请求预算约束。部分文本和半截工具参数不作为成功结果执行，日志保留诊断身份，不输出密钥或完整请求。

最近模型与思考成对保存在同源浏览器。新对话及项目新对话恢复有效本地选择，已有会话优先其服务端选择；仅浏览历史不更新偏好，菜单保存成功或发送成功才更新。恢复值进入实际请求，记录读完前不把目录默认当作已选择；目录不支持时回退有效默认，存储不可用时仍可操作。

模型菜单只承担模型与思考选择，关闭时提交变化，失败保留草稿。设置页承担逐模型参数，部署连接不进入普通选择流程。详细交互契约见 [UI 设计说明](../../ray_agent/ui/DESIGN.md#草稿弹层与视图连续性)。

## 模块责任与依赖

| 责任范围 | 必须保持的依赖 |
|---|---|
| 模型目录与端点加载 | 能力、环境凭据和映射先统一，再组装客户端及辅助请求 |
| 通信适配与运行器 | 编码、错误分类、推理回传和快照恢复一致，完整终态先于动作执行 |
| 配置服务 | 逐模型保存原子校验，不改写既有对话参数或运行快照 |
| 前端选择与偏好 | 消费后端能力，恢复结果进入请求，已有会话与新对话偏好隔离 |

## 完成条件

目标端点缺失时明确失败，可用模型互不阻塞；更换地址或凭据后读取新值，配置响应不泄露密钥。逐模型保存原子失败，切换后容量重估，等待保持冻结配置。两种通信编码、完整终态、推理回传、历史转换、图片、压缩和错误分类保持调用契约。前端保存失败、字段未加载、失效偏好和多标签变化不污染草稿或已有会话。

代码及定向检查不能证明真实上游支持，实际部署和多轮工具任务需在当前配置下重新运行。检查入口见 [API 指南](../../ray_agent/api/README.md#responses-模型通信)和 [UI 指南](../../ray_agent/ui/README.md#检查与构建)。
