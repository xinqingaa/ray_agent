# 模型目录与端点配置优化方案

状态：模型目录、端点映射、逐模型参数、Responses 通信与最近选择已实施并收尾。形成过程见[交互与配置背景](../background/interaction-and-configuration.md#模型接入从猜域名转向明确目录)。

## 目标与范围

用户选择模型与思考，部署维护者配置连接。能力由模型目录定义，端点变化不改变模型身份；前端不维护第二份能力白名单。

范围覆盖端点读取、模型映射、参数保存、通信、运行快照与选择交互。配置方法见[运行指南](../../ray_agent/README.md#模型与工具)，当前机制见 [Harness 执行适配层](../harness.md#执行适配层)。

## 能力、连接与参数分开

| 信息 | 所属责任 | 关键契约 |
|---|---|---|
| 模型身份、思考、工具与视觉 | 后端模型目录 | 地址不决定能力，新增模型需适配及核验 |
| 地址与密钥 | API 环境与端点加载器 | 配置只保存环境引用，凭据不返回选择接口 |
| 模型到端点映射 | 应用配置 | 缺失明确失败，不自动送到其他服务 |
| 温度、输出上限与窗口 | 逐模型配置 | 整体验证后原子保存，按目录封顶 |

端点读取的失败隔离：

- 仅缓存配置结构，不缓存凭据；显式清空 Key 不恢复旧值。
- 非法 URL 只影响所属端点，其他可用模型继续工作。
- 缺 Key 仍可查看目录和估算容量，实际请求前拒绝。
- 同模型只展示一次，兼容地址由内部映射选择；兼容声明不证明真实支持。
- 标题与项目摘要走辅助模型及对应端点，辅助失败不阻塞主任务。

## 对话参数与运行快照

| 对象 | 固定或更新时机 | 依赖 |
|---|---|---|
| 同模型对话参数 | 首次运行固定，后续沿用 | 不被设置修改追溯覆盖 |
| 换模型后的新运行 | 读取目标当前配置，重新估算容量 | 不复用另一模型的计数 |
| 活动或等待运行 | 始终沿本运行快照 | 模型、思考、协议、提示一致 |
| 思考参数 | 按目录及回传规则编码 | 区分字段未发送与显式关闭，不套用其他系列开关 |

实际 usage、缓存及推理用量按上游返回记账，估算不代替账单。数值见[运行参数与限额](../limits.md)。

## Responses 通信与最近选择

### 通信适配

1. 将领域消息与工具声明编码为所选协议，不使用供应商托管会话或托管工具。
2. 收到完整终态后归一结果与用量；半截文本和参数不作为成功动作执行。
3. 推理条目随对应助手消息保存，按模型规则复用，不转发其他模型的不透明推理。
4. 旧消息按请求编码转换，不重写持久事件；等待按冻结协议重建客户端。

连接、限流、服务错误和明确暂时中断可以有限重试；参数、鉴权、额度与未知错误不盲目重发。连接未建立采用独立退避，但仍计入请求预算。

SDK 异常与语义流错误统一分类，日志保留诊断身份，不输出凭据或完整请求。重试与期限见参数页。

### 选择与偏好

- 新对话及项目新对话恢复同源浏览器最近确认的模型与思考，恢复结果进入实际请求。
- 已有会话以服务端选择为准，浏览历史不改变新对话偏好。
- 菜单确认或发送成功才保存偏好，关闭菜单提交变化，失败保留草稿。
- 偏好失效时回退有效默认，存储不可用仍可操作；记录未读完时不冒充已恢复。

菜单只负责模型与思考，设置负责逐模型参数，连接由部署配置管理。详细交互见 [UI 设计说明](../../ray_agent/ui/DESIGN.md#草稿弹层与视图连续性)。

## 模块责任与依赖

- 目录、端点加载器与模型适配共同保持能力编码、快照恢复和完整响应契约。
- 配置服务原子校验，不改写已有对话参数或运行快照。
- 前端消费后端目录，将恢复选择送入请求，隔离已有会话与新对话偏好。

## 完成条件

- 端点故障隔离，地址与凭据变更可生效，响应不泄密。
- 配置原子保存，模型切换重估容量，等待保持冻结条件。
- 两种编码保持工具、图片、推理回传、压缩及错误分类契约。
- 失效偏好、字段未加载、保存失败与多标签变化不污染已有会话或草稿。

静态与替身检查不证明真实上游支持，部署及多轮任务须按当前配置验证。入口见 [API 指南](../../ray_agent/api/README.md#responses-模型通信)和 [UI 指南](../../ray_agent/ui/README.md#检查与构建)。
