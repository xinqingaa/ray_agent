# 项目空间与数据管理

本轮已获用户授权实施，按用户复审意见收敛重复入口、工具栏及弹窗导航。项目对话与独立对话继续共用 SessionItem，不改成卡片或添加摘要。

## 范围与契约

- 项目主页默认为对话页，稳定导航连接文件、说明、笔记；取消固定资料辅栏与关闭项目按钮。
- 项目文件页统一宽度、搜索、上传、下载、刷新和预览；默认省去系统目录，保留用户目录，不暴露系统目录开关。
- 说明和笔记复用现有版本比较、草稿保护和修改记录；对话保留专注阅读及项目资源入口。
- 保留归档，新增永久删除项目及设置中的全局业务数据清空。确认显示准确范围，非空项目输入名称，全局输入确认短语。
- 清理包含所属数据库记录、附件字节、项目目录与保存点、托管沙箱；配置保留。活动运行与文件操作需先结束。
- 清理通过持久任务固定对象与进度，失败可重试；防止清理期间新增目标数据，不将列表移除当成清理成功。
- 本轮不修改课程、执行循环或模型配置。

## 完成条件

核对统一对话行、空/有内容项目、文件查看、草稿返回、窄屏、项目占用及确认流程。后端验证清理归属、共享附件保护、占用冲突、并发准入、失败重试与数据库约束；真实清理仅使用独立测试数据，不清空用户已有数据。完成后将事实合入产品、UI、架构和能力文档。
