# 开发者模式与对话展示

本轮授权实施前端展示分层，执行 Harness 保持现有机制。普通用户的统一目标是把材料交进去，减少操作，取得可使用、可核验的成果；开发者可打开完整技术观察。图片展示同步调整为 96×96 缩略图，名称、大小、尺寸与下载在大预览里显示。

## 范围与契约

显隐策略集中在 `useDeveloperMode` hook 与其纯工厂函数，按区域返回能力标记。偏好默认关闭、保存在当前浏览器、即时生效并同步同源标签页，不写入服务配置。关闭不会影响运行、模型、工具权限、事件或持久记录。

普通模式隐藏开发者切换与事件/轮次/压缩详情、工具原始参数与协议结果、技术计数和耗时、上下文环、手动压缩入口、终端、内部执行与模型参数、连接编辑、记忆原文与容量估算。保留用户消息、进展、计划、模型选择与思考选项、提问审批、停止、失败、未知结果、业务结果、文件与页面内容、项目记忆来源、文件保护及执行权限。连接信息只读。

工作台普通模式为“结果与资料”，只跟随可显示的结果；切换模式不能落入隐藏标签。开发者视图关闭后回到对话，再开启可恢复观察状态。关闭开发者模式前，设置存在未保存修改时先保存或撤销，隐藏字段保存时保留原值。终端隐藏时不继续轮询，会话事件订阅不受影响。

网址、旁白去重适用于两种模式。图片在 96×96 内裁切展示，原图完整内容在预览中查看；适应窗口与原始尺寸使用不同图标。失败与恢复入口保留。

## 完成条件与验证

- 统一 hook 决定区域显隐，普通模式与开发者模式使用相同执行事实。
- 刷新及同源标签页保持偏好，模式切换保留输入和阅读状态，不改变审批或配置。
- 历史与实时过程都能查看成果、异常和恢复入口，隐藏终端后不发生空白页或额外轮询。
- 定向组件检查覆盖策略、偏好与切换，类型、lint 和生产构建通过；浏览器核对图片、预览图标、设置、历史会话与工作台。
- 完成后将当前交互合入产品说明与 UI 设计/开发指南；不修改历史验收或课程。

## 区域清单

| 区域 | 关闭时的展示 | 开启时增加的内容 |
|---|---|---|
| 会话顶部 | 直接显示对话；结果与资料入口 | 对话／开发者切换，工作台入口 |
| 工具过程 | 动作与状态、单个网址链接、展开可读正文、错误及查看内容 | 原始参数、调用标识、工具名、技术结果、耗时及计数 |
| 过程分组 | 动作摘要；展开后旁白只显示一次 | 工具数量 |
| 运行汇总 | 用时 | 模型轮次、工具次数、tokens |
| 输入栏 | 模型名；弹层仍可选择思考档位 | 按钮上的档位、上下文用量环、手动压缩命令 |
| 压缩／重试 | 整理对话及重试提示 | 压缩计数、重试次数与上限 |
| 右侧 | 文件、项目文件、页面内容；旧结果有新结果时显示返回入口 | 终端、原始结果；成功调用状态与技术标题 |
| 通用设置 | 开发者开关、项目快照保留份数 | 模型请求上限、重试上限、搜索条数 |
| 模型配置 | 对话中的模型与思考选择 | 提供商、密钥、连接和逐模型采样配置 |
| 外部连接 | 名称、状态、能力数量或描述 | MCP/A2A 协议、工具名称、地址、添加、删除及启用开关 |
| 项目记忆 | 说明、笔记、摘要、来源、编辑及冲突处理 | 版本数字、辅助模型用量、系统固定原文、容量估算 |
| 执行权限 | 保留完整权限设置、提问及审批 | 不因模式改变权限 |
