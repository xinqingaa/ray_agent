# 浏览器观察与视觉资源优化方案

状态：文本观察、显式视觉、按需资源、动作失败处理和真实视口已实施。本方案保留成组设计与完成条件。

诊断和方案形成过程见 [工具观察背景](../background/tools-and-interface.md)。本篇保留动作、观察、引用和资源的配套契约。

## 目标与范围

普通文本任务以文本和结构化状态为主，减少不必要的截图、重复正文和展示补读。视觉任务让实际像素进入模型，并保留可解释的捕获与清理边界；动作失败不能继续依赖写入。

保留 Playwright/CDP、自研 DOM/Markdown、工具管线、统一整形与事件源。范围包含浏览器、公开网页读取、模型图片装配和事件展示；不迁移浏览器框架，不建设通用依赖调度或移动设备仿真。

## 同一次动作与观察

动作是否发生、观察是否成功、页面范围和图片用途分别返回。工具结果包含实际页面及动作信息，模型和 UI 从同一次结果取得各自的有界内容，运行器不再访问环境补一张历史画面。

| 信息 | 契约 |
|---|---|
| 动作状态 | 成功、失败及明确错误；参数不足不得假成功 |
| 页面归属 | 指定 tab、URL、标题及观察身份，不自动跟随不相关页面 |
| 文本与元素 | 按需要选择范围，注明局部、截断和读回路径 |
| 观察状态 | 成功、失败或未请求，不能覆盖动作结果 |
| 截图 | 显式用途、实际尺寸、来源与文件引用 |
| 展示 | 实时与历史回放同一投影，不用当前页替代旧画面 |

正文提取避免父子重复与隐藏内容污染，长正文在统一落盘前保持可恢复信息。页面 readyState 不证明业务完成，必要检查仍以目标状态为准。日志采集包括错误及页面异常，空日志不能断言页面没有问题。

## 节点引用、输入与动作批次

元素引用绑定具体标签页和真实 DOM 节点。节点被替换、语义改变、导航或环境重建后引用需要核对，拒绝失效引用而不是重新匹配一个相似节点。观察可保存引用信息，等待续接仍需同一页面和实际节点有效。

点击、输入和选择有明确参数约束；坐标输入需要实际输入目标，不因未聚焦仍向旧框追加。动作部分生效后不通过回退路径无条件重复提交。任意 JS 属于有副作用能力，不能默认当所有网页的主操作路径。

模型可在一次响应中生成多个已知参数动作，程序顺序执行；后一步需要前一步结果时保留下一轮判断。动作失败或动作已成功而观察失败后，依赖写调用停止，剩余调用得到未执行结果。补观察不重放原动作，完整调用配对与审批机制保持一致。

有限独立读取并发维护在 [执行方案](execution-and-context.md)，不推广为同页动作并发或未知外部操作调度。

## 公开网页与渲染浏览器的分工

公开、无需登录的正文使用轻量读取；登录、JS 状态及交互继续使用浏览器。用户明确指定浏览器时遵守其要求。正文抓取不是浏览器替代品，不承诺对所有站点提取完整。

导航支持明确的 HTTP(S)/about:blank 范围，file:// 不通过试错绕过。自建页面可在沙箱提供静态服务再用浏览器检查，不增加通用预览代理。依赖安装、环境准备和清理仍受运行权限与所有权约束。

## 显式截图、视觉装配与留存

截图分别选择分析与交付，普通导航、日志和文本读取零自动补图。图像只有在当前模型支持视觉且符合容量时进入实际请求；下载 URL 和用户手动预览不能替代模型像素输入。

| 层次 | 设计要求 |
|---|---|
| 捕获 | 明确范围和用途，有单张、运行级次数/字节及超时约束 |
| 编码 | 按模型输入要求规范尺寸和字节，实际格式及哈希可核对 |
| 请求 | 像素数量与预留容量有上限，尚未观察图片超额明确失败 |
| 历史 | 保存来源、哈希、MIME、尺寸与引用，请求时再装配字节 |
| 分析图 | 运行归属，运行和等待期间保护，终态且到期后回收字节 |
| 交付图 | 沿附件交付规则永久保存，不自动清理用户成果 |
| 到期 | 元数据保留，读取明确到期，不能伪造空白成功图 |

旧图可退出像素预算而保留文字引用，新图不能静默丢失。非视觉模型明确说明未启用视觉，不猜答案或自动换模型。图片编码或存储失败也不改变已经发生的动作结果。具体限额见 [运行参数与限额](../limits.md)。

用户图片沿附件归属和同一像素治理接入，能力/限制自动决定输入方式，说明随消息保存。普通识图、明确 OCR 和文件编辑的边界由通用规则指导，不把每次上传都扩展成安装识图环境；交互设计见 [输入方案](interface-and-preview.md)。

## 真实视口与恢复

指定 tab 设置真实 viewport，返回实际 innerWidth/innerHeight 和页面尺寸，不修改页面 CSS 冒充手机。尺寸有合法范围，参与动作批次和权限校验，计划模式不放行视口改变。

记录修改前尺寸和运行所有权，等待续接从快照恢复；终态、失败与停止只恢复仍属于本运行的标签页，记录结果。强杀进程不能保证立即恢复，也不模拟真实触屏、软键盘与设备性能。

视觉检查选择关键状态、区域和视口，文字或业务检查使用独立断言；不能因为页面可截图就声称交互与口径正确。自建页面可用一批独立预期检查核心行为，外部站点继续优先真实元素动作。

## 模块责任与依赖

| 责任范围 | 必须保持的依赖 |
|---|---|
| 浏览器适配 | 参数、标签页和真实节点有效性先成立，动作与观察分别报告 |
| 工具管线 | 校验、授权和失败批次仍配对，补观察不重放原动作 |
| 应用运行器及存储 | 图像归属、配额与期限随运行保存，活动图受保护，永久附件按交付规则处理 |
| 模型适配 | 能力、实际图像字节与容量治理共同决定像素输入 |
| 前端 | 从本次工具结果展示正文、图片和到期状态，不读取当前环境伪造旧画面 |

显式视觉依赖文本结果和无图展示已可用；临时图回收依赖运行终态与持久元数据；视口恢复依赖标签页和运行所有权。按需准备继续遵守项目保护与等待快照。

## 完成条件

普通动作无自动补图，正文及错误在实时和回放可见。节点替换、错误焦点和观察失败不产生错误重放。支持视觉的请求包含实际像素，非视觉与超额情况明确说明；临时图到期回收且不影响活动图与永久附件。视口调整与恢复作用于正确标签页，不修改页面 CSS 代替验证。

本方案已实施并收尾。观察是有限 DOM 提取，视口不代表真实移动设备；任意网页提取、视觉质量和跨平台性能需按实际目标另行验证。检查入口见 [API 指南](../../ray_agent/api/README.md#浏览器与网页读取的定向检查)。
