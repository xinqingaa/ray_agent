# 浏览器观察与视觉资源优化方案

状态：文本观察、显式视觉、按需资源、动作失败处理和真实视口已实施并收尾。形成过程见[工具观察背景](../background/tools-and-interface.md)，当前使用见[产品说明](../product.md#工具与观察)。

## 目标与范围

普通任务优先文本和结构化观察，视觉任务提供真实像素；减少重复正文、截图与展示补读，同时保持动作结果、观察状态和资源归属可解释。

范围包括 Playwright/CDP、自研 DOM/Markdown、公开网页读取、工具管线、模型图片装配及事件展示。

## 同一次动作与观察

同一次结果要能够说明动作和观察分别发生了什么：

- 动作报告成功、失败及明确错误，参数不足不能假成功；观察失败不能覆盖动作已发生的事实。
- 页面带标签页、URL、标题和观察身份，不自动跟随无关页面。
- 文本与元素说明范围、截断及读回路径，不将局部结果当整页。
- 观察报告成功、失败或未请求；截图记录显式用途、真实尺寸、来源与文件引用。
- 模型和 UI 使用当次结果，页面有预览不等于模型收到像素，当前画面不能冒充历史。

正文去除父子重复与隐藏内容污染，统一整形前保留有效长文本。页面 readyState 不证明业务完成，空日志不证明无错误；日志采集应覆盖错误、警告及页面异常。

## 节点引用、输入与动作批次

- **引用有效性**：绑定标签页及真实 DOM 节点，导航、替换、语义变化或环境重建后核对；不自动匹配相似节点。等待续接也受实际节点有效性限制。
- **输入语义**：参数不足或焦点无效不向旧目标追加。部分生效后不通过回退路径重复提交；任意 JS 按有副作用能力处理。
- **批次顺序**：已知参数可同批顺序执行，依赖新结果时保留下一轮决策。动作失败或成功后观察失败时停止依赖写调用，剩余调用配对为未执行。
- **恢复观察**：补观察不重放原动作，审批与完整结果配对保持原机制。

独立读取并发见[执行方案](execution-and-context.md#准备资源与发现能力)，不扩展为同页动作并发。

## 公开网页与渲染浏览器的分工

公开且无需登录的正文优先轻量读取，登录、JS 状态与交互使用浏览器；用户明确指定浏览器时遵从。轻量读取不承诺任意站点完整提取。

自建页面通过沙箱静态服务与浏览器检查，不用 file:// 试错绕过，也不增加通用预览代理。

导航允许明确的 HTTP(S) 与 about:blank 范围。依赖安装、环境准备及清理继续受权限与所有权约束。

## 显式截图、视觉装配与留存

截图分别选择分析与交付，普通导航、日志及文本读取不自动补图。模型实际接收像素需要能力、编码与容量同时成立。

| 层次 | 配套设计 | 失败或到期处理 |
|---|---|---|
| 捕获 | 范围、用途、单张与运行级配额、总期限 | 不改变已发生的动作结果 |
| 编码与请求 | 按模型规范尺寸和字节，保存哈希；像素受输入预算限制 | 新图超额明确失败，旧图可退出像素预算并保留文字引用 |
| 历史 | 来源、内容标识、MIME、尺寸与引用 | 请求时再读取字节装配 |
| 分析图 | 按运行归属，执行与等待期间保护 | 终态且到期后回收字节，元数据保留并明确到期 |
| 交付图 | 进入正式附件 | 不按临时图期限清理 |

非视觉模型说明未启用视觉，不猜图或自动换模型；下载 URL 与手动预览不能替代模型输入。限额见[运行参数与限额](../limits.md)。

用户图片沿同一治理链路，原图与输入副本分开；普通识图、OCR、属性读取及编辑按明确目标分工，不自动扩展为安装识图环境。输入交互见[界面方案](interface-and-preview.md#共用输入上传与图片)。

## 真实视口与恢复

1. 为指定标签页设置真实 viewport，返回实际窗口与页面尺寸，不修改业务 CSS 冒充设备。
2. 记录原值与运行所有权，参与工具权限和模式校验；计划模式不允许视口修改。
3. 等待保留记录，续接恢复所有权信息；终态、失败和停止只恢复本运行持有的标签页并记录结果。

强杀不能保证立即恢复，视口也不模拟触屏、软键盘或设备性能。视觉检查选择关键状态与区域，业务判断使用独立断言。

## 模块责任与依赖

- 浏览器适配先确认参数、页面与节点有效，再分别报告动作和观察。
- 工具管线对失败和挂起保持配对，补观察不重放原动作。
- 运行器与存储保存资源归属、配额及期限，区分活动图和正式附件。
- 模型适配依据能力、字节与容量装配像素；前端使用当次结果展示内容和到期状态。

先建立无图文本反馈，再接入显式视觉；先保存资源归属，再回收临时图；视口恢复依赖标签页与运行身份。

## 完成条件

- 普通动作无自动补图，文本及错误在实时和历史中一致。
- 节点失效、焦点错误与观察失败不导致错误重放。
- 视觉请求含真实像素，非视觉、超额与到期明确表达，活动图及正式附件受保护。
- 视口修改和恢复作用于正确标签页，不篡改页面 CSS 代替验证。

不承诺任意网页提取或真实移动设备等价性。检查入口见 [API 指南](../../ray_agent/api/README.md#浏览器与网页读取的定向检查)。
