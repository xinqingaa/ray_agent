# 对话底部统计简化

2026-10-11 用户授权实现。只调整 UI 展示与现有数据接入，不改变后端用量发布、工具权限或模型执行。

## 契约与实现

- 输入框上方不显示运行统计。生成中统计跟随当前回复或执行过程，使用 `18s · 3轮 · 32 tok/s`，与开发者模式无关；时长超过一分钟后使用分、秒单位。
- 生成中复用流式可见文本和首段到达时间估算平均速度，随文本及秒级时钟更新；轮次结束后优先使用实际用量与模型耗时。估算说明只出现在悬浮提示与读屏名称，缺失时显示 `— tok/s`。
- 工具等待保留最近生成速度；同一运行的统计移动位置时保留临时速度。运行完成后统计留在最终回复下方，停止、失败和中断留在对应结束记录下方，无最终回复也保留统计。
- 终态统计使用本次运行汇总，包含各轮模型调用及自动压缩已记录的输入与输出；缓存命中不重复加算。上下文圆环详情的“用量统计”保留整个会话累计值。
- 每次运行只显示一条统计，过程标题和分组不显示工具数量；具体动作、失败、审批与原始事件保留。
- 继续使用现有开发者区域策略控制其他技术信息，不把 requestMetrics 整体开放，避免连带展开压缩及尝试细节。
