## 实现契约

### 计划展示

- 折叠条显示“第 2/5 步”和当前步骤；完成数量在展开后以“已完成 1/5 项”呈现。
- 无进行中项显示“下一步”，不冒充正在执行；计划全完成显示“计划 5/5 项已完成”，不由此推导运行或成果验收成功。
- 停止、失败、中断时保留完成项数与未完成信息；不显示计划逐项计时。原时间只是模型记录状态的时刻。
- 计划依据所属运行展示状态；新运行尚未更新旧清单时标为“上次计划”。
- 底部只留进度入口，点击时清单向上浮动展开，与进度条共用一个背景、外框和轻阴影；卡片绝对定位，底边和宽度固定，仅清单高度过渡，只列最新计划有效步骤，无新增、删除、刚完成标签和历史版本。关闭时卸载清单，不改变对话或输入区布局；历史事件仍在开发者视图中核对。

### 停止表达

- 输入按钮使用停止图标，名称为“停止生成”，受理中显示“正在停止”；相关输入提示统一词汇。
- 时间线只有一个主要停止记录：“已停止生成”，下方提示“可以补充要求，或发送‘继续’接着处理。”不固定宣称文件已写入或永久保留，不解释新运行这一内部概念。
- 标题不重复停止状态，普通模式隐藏被取消请求的次级提示；开发者模式仍可看到该请求的停止记录，使用中性图标。
- 继续沿用现有上下文创建新运行；没有用户暂停后精确恢复同一运行的能力。清理异常与失败、中断的记录保留。

### 步骤身份

- 新步骤省略 id，工具分配 UUID，并通过工具结果返回完整清单与 plan_id。
- 已有步骤更新、改标题和重排复用返回的 id；未知或重复 id 被拒绝，失败不改变当前计划。省略 id 明确表示新增，不按文字或位置猜测身份。
- `reset=true` 创建新任务的全新计划；延续原任务保持 plan_id。删除的步骤不能使用原 id 在下一版重新插入。
- SSE 保留步骤 id 并增加 explanation。前端按 ID 比较文字、状态和顺序、沿用状态记录时间；plan_id 改变时重置版本计数。
- 中文与英文系统提示同步要求阶段切换前更新、例行更新保留标题与 ID、范围变化说明原因。旧数字身份或缺失字段不转换，不设置旧格式兼容分支。

### 有限计划核对

- 有未完成计划，连续 5 个已完成的有效工具批次没有计划更新时，在下一次请求前注入“[计划核对]”。
- 每批最多计一次；成功计划更新重置间隔。计划调用、轮询观察、失败或被拒调用不推进计数。每个运行最多 2 次提醒，无计划或全完成不提醒。
- 原始工具、计划、轮次与上下文事件用于恢复计数，等待或审批续接不重新获得两次提醒；压缩后的 replace 不重复统计已有提醒。
- 提醒写入记忆和 ContextEvent，保持 system 消息不变，不作为用户原话改变预算阶段判定，也不在普通时间线冒充用户消息。
- 提醒请模型核对是否进入下一阶段，不强制更新、不阻断工具、不自动标完成。真实阶段进度仍由模型记录；绑定步骤与阶段验收不在本次范围。
