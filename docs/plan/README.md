## 后续工作的规划方式

日常缺陷、局部逻辑和 UI/UX 调整按实际影响修改实现并验证，不续写已结束的 W0–W11。文档是否更新由[文档地图](../README.md#文档职责与更新条件)决定，样式或图标微调通常无需文档改动。

只有需要跨模块协调、改变能力或结构的成组工作才新建计划：说明问题、范围、实现契约、依赖、完成条件和验证入口。计划不自动授权实施；获授权后推进，完成时把当前事实合入对应文档，仅保留有长期价值的验收证据。

新工作不得把历史验收改写成当前版本已通过，也不因一个新需求同时维护多个状态表。当前没有预设的新阶段范围。
