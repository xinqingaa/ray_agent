## 推荐：`docs/design/`

在项目根目录下创建 `docs/design/` 目录：

```
ui/
├── docs/
│   └── design/          ← UI 设计稿放这里
│       ├── home.png
│       ├── chat.png
│       └── ...
├── src/
├── public/
└── ...
```

**原因：**

- **与源码分离**：设计稿不是运行时资源，不应放在 `src/` 或 `public/` 中
- **`public/` 目录**仅用于需要被 Web 服务器直接访问的静态资源（如 favicon、logo），设计稿不需要对外暴露
- **`docs/`** 是业界通用的项目文档目录，语义清晰
- 可在 `.gitignore` 中按需忽略大文件（如 PSD/Sketch），只保留轻量的 PNG/JPG 参考图

> **提示**：如果设计稿文件较大（如 Figma/Sketch 源文件），建议只在本地保留或使用在线链接，仅将导出的截图/参考图提交到仓库，避免仓库体积膨胀。
