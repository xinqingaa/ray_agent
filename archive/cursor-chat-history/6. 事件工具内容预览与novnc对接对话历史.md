## 滚动问题修复总结

### 🔧 问题描述
之前左侧对话区和右侧文件预览区共享同一个滚动容器，导致滚动时两个区域会互相影响。

### ✅ 修复方案

#### 1. **左侧对话区（主内容区）**
- 添加了独立的滚动容器：`overflow-y-auto`
- 结构调整为：
  ```
  左侧容器 (overflow-hidden)
    ├─ Header 区域 (flex-shrink-0, 固定不滚动)
    └─ 内容滚动区 (overflow-y-auto)
        ├─ 对话消息列表
        └─ 底部输入区 (sticky bottom-0, 固定在滚动容器底部)
  ```

#### 2. **右侧预览区**
- 添加 `overflow-hidden` 到外层容器
- `FilePreviewPanel` 组件内部已有独立的 `ScrollArea`，不受左侧影响

### 📋 关键改动

**修改前的问题**：
- 左侧和右侧共享滚动，互相影响
- 没有独立的滚动容器

**修改后的结构**：
```tsx
<div className="flex flex-row h-full"> // 父容器
  {/* 左侧 - 独立滚动 */}
  <div className="flex-col flex-1 overflow-hidden">
    <div className="flex-shrink-0"> // Header 固定
      <SessionHeader />
    </div>
    <div className="overflow-y-auto"> // 独立滚动区域
      {/* 对话内容 */}
      <div className="sticky bottom-0"> // 输入框固定在底部
        <ChatInput />
      </div>
    </div>
  </div>
  
  {/* 右侧 - 独立滚动 */}
  <div className="w-[600px] overflow-hidden">
    <FilePreviewPanel /> // 内部有独立滚动
  </div>
</div>
```

### 🔧 问题分析

使用条件渲染 (`{previewFile && ...}`) 替代条件定位，让预览面板真正从 DOM 中移除。

#### **修复前的实现（有问题）**：
```tsx
<div 
  className={`w-[600px] ${previewFile ? 'translate-x-0' : 'translate-x-full'}`}
  style={{ 
    position: previewFile ? 'relative' : 'absolute',  // ❌ 导致布局问题
    right: 0,
    visibility: previewFile ? 'visible' : 'hidden'
  }}
>
  {previewFile && <FilePreviewPanel />}
</div>
```

**问题**：
- 关闭时虽然设置了 `absolute` 和 `hidden`
- 但容器仍然存在于 DOM 中
- flex 布局仍然为其预留空间

#### **修复后的实现（正确）**：
```tsx
{previewFile && (  // ✅ 条件渲染
  <div className="flex-shrink-0 w-[600px] h-full animate-in slide-in-from-right duration-300">
    <FilePreviewPanel />
  </div>
)}
```

**优点**：
- 关闭时完全从 DOM 中移除
- flex 布局自动调整主内容区宽度
- 打开时才添加到 DOM 并播放动画
