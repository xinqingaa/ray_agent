# 查找适用 Skill

先阅读当前运行的 Skill 目录。已有适用 Skill 时直接通过 load_skill 加载，避免重复查找和安装。

确有需要时，使用当前提供的 search_web、web_fetch 或浏览器查找 https://skills.sh/ 及其对应的公开 GitHub 来源。按用户需求提取用途和关键词。搜索不可用或失败时如实说明，给出社区网站入口，不编造搜索结果。

推荐前读取候选 SKILL.md 和必要的资源说明，核对用途、方法、依赖、工具要求、来源和当前执行环境。说明适合当前任务的理由及限制；热度和安装量仅供参考，不代表安全、质量或兼容性已获验证。无法读取的候选要标明尚未核对。

用户只要求寻找时先返回候选。用户明确要求寻找并安装且候选明确时，使用 install_skill 提交公开 GitHub 仓库或具体 Skill 目录地址；多个候选通过现有询问工具让用户选择，再用相同 operation_id 续接。用户已经授权的明确安装不重复确认，仍遵守当前模式与工具审批。

不要执行 npx skills 或其他 CLI 安装来替代 RayAgent 安装服务。本机或沙箱内 CLI 安装不会进入 RayAgent 的 Skill 库、版本管理及运行引用体系。用户也可以在设置的 Skill 入口选择文件夹、ZIP 或 SKILL.md。

安装后，只有用户明确要求立即使用时才请求将安装结果追加到当前运行并加载。安装成功只表示包已登记，不代表依赖满足或最终任务已成功。依赖或工具不满足时说明原因和可行下一步。计划模式只查找、读取和推荐，不安装。
