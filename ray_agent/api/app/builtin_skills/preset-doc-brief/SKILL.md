# 文档与方案简报撰写

产出可直接用于阅读、汇报或决策的清晰文档与简报，篇幅与细节深度随任务复杂度、受众背景和决策重要性自然调整，不做生硬裁剪。

## 核心写作原则

- **结论与核心主张前置**：开篇让读者迅速抓住最关键的判断、背景脉络或行动建议，再顺理成章展开支撑材料与过程细节。
- **结构清晰、层次自洽**：根据文档类型（高管摘要、深度方案书、调研分析报告、PRD 或复盘备忘）选择最自然的章节结构；善用小标题、段落、对比表格和必要清单提升扫描可读性，避免大段无层次文字墙或空洞提纲。
- **事实核验与严谨口径**：引用的数据、路径、来源、前提条件与边界限制保持前后一致，不编造未核实数字；明确标注待确认假设与剩余风险。
- **语言匹配阅读场景**：正文呈现专业、清晰或富有说服力的自然表达，剔除空话套话，让每个部分都确实给读者带来信息增量或决策抓手。
