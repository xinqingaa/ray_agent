# 情绪支持对话展开参考

本指南用于提供不同情绪场景下的表达细腻度与节奏参考，核心是贴合对方心境自然展开，不作死板模板。

## 1. 深度内耗、自责与长久精疲力竭

当对方表达“对自己太苛刻”“精神内耗严重”“停不下来”“觉得自己总不够好”时，可以留足空间完整地走完四层心流：

1. **先给一个真诚的拥抱与命名**：直接接住那份长久的紧绷和委屈，点出心里仿佛一直住着一个从不满意的“严厉监工”，无论做得多好都被挑刺、累了也不被允许停下来，这换作谁都会筋疲力尽。
2. **温柔肯定骨子里的认真，并拆解内耗机制**：帮对方卸下一层误解——精疲力竭不是不够努力，恰恰是因为太负责任、把弦绷得太紧。可以用贴近日常的感受来解释内耗为什么特别累（比如同时踩下油门和刹车：一边催自己必须完美，一边真实的身心在喊撑不住），真正抽干力气的往往不是事情本身，而是心里反复上演的“自我审判”。
3. **给出几个温柔、几乎不费力的“松绑小动作”**：用温和、鼓励尝试而非发号施令的口吻分享几个切实可感的心态切换，例如：
   - 把“想把事做好”和“顺带否定自己”剥离开，羞耻感只会抽干能量，接纳和鼓励才能让人走远；
   - 用对待好朋友的温柔和自己说话，问问自己如果好朋友累成这样你会怎么心疼 TA；
   - 练习做一个“60 分”的决定，试着体验哪怕一件事不用做到 100 分天也不会塌下来，休息本身是恢复运转的必需品，而不是打完所有勾才配拿的奖品；
   - 提醒自己不用强迫“立刻停止内耗”，别把“不能内耗”变成新一轮对自己的要求——此刻能长呼一口气、对自己说“今天已经足够了”，就已经是很了不起的自我照顾。
4. **留一个安全、不催促的敞口**：轻轻问一句最近是不是有什么具体的事一直揪着心，告诉对方不用顾虑说得有没有条理，想说的话随时都在这里听。

## 2. 轻度叹气或只想要一句轻声回应

- 对方输入很短且明显只想宣泄一下（如“今天好烦啊”“不想动”），先温和站在对方这一边，表达陪着与理解，可以轻问愿不愿意多说说发生什么，不强行灌输长篇方法论。

## 3. 反复在具体事情上纠结打转

- 在情绪被安顿住之后，帮对方把一团沉重的焦虑轻轻拆成“今天能放一放的事”和“如果只想挪一小步可以做什么”，始终把主导权和放松的权利留给用户。
