# 单文件互动网页小工具实战模式

## 一、干净的单文件状态架构（无需框架，极易维护与局部迭代）

1. **单一真相源（Single Source of Truth）**：把核心数据、筛选条件、排序和选中项集中放在一个 `state` 对象里；所有交互动作只改 `state` 并调用统一的 `render()`（或局部更新函数），彻底避免界面数字和列表不同步。
2. **安全渲染**：用户输入的文本一律使用 `textContent` 或严格的 HTML 转义函数，绝不把未经转义的用户文本直接拼进 `innerHTML`。
3. **防御性本地存储**：读写 `localStorage` 一律包 `try/catch`（兼容受限 iframe 或隐私模式），解析 JSON 失败时安全回退到初始状态而不让整页白屏。

## 二、让小工具“真正顺手”的 5 个细节

1. **即开即懂的初始态**：如果空页面不好理解功能，可放 2–3 条清晰标明「示例」的示范记录，顶部放一个醒目但不打扰的「清空示例」按钮；清空后展示友好的空状态引导。
2. **即时反馈**：计算器/筛选器/搜索框随输入实时响应（无需每次点“查询”）；保存、复制、导出后给一句轻巧的内联状态提示（如按钮旁淡显“已复制”1.5 秒），不弹刺眼的 `window.alert()`。
3. **数据带得走**：
   - CSV 导出自动加 UTF-8 BOM（`\uFEFF`），防止中文在 Excel 打开乱码，并正确转义含逗号、双引号或换行的单元格；
   - JSON 导出带版本号，支持一键重新导入恢复状态。
4. **顺手的键盘体验**：表单支持 `Enter` 提交、弹窗/编辑态支持 `Esc` 取消、焦点态（`:focus-visible`）清晰可见。
5. **稳固的响应式布局**：主容器用 `max-width` + 居中 + 合适内边距；工具栏使用 `flex-wrap: wrap`；宽表格外包 `overflow-x: auto`；手机窄屏（`390px`）下双栏自然折为单栏，保证 `scrollWidth <= clientWidth`。

## 三、交付前避坑清单
- 不要引用外网 Google Fonts、Unpkg 或 CDN 脚本（离线或网络波动会直接导致样式崩溃或白屏）。
- 不要把事件绑定写成脆弱的内联字符串拼接（优先 `addEventListener` + 事件委托 `data-action` / `data-id`）。
- 凡是界面上画出来的开关、Tab、搜索框、导出键，在最终检查时必须确认已绑定真实逻辑。
