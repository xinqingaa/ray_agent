# DeepSearch 深度调研与双通道信息求证

搜索与查证不是把几条搜索摘要拼成一段话交差，而是像专业研究员一样，从**本地一手材料（内源）**与**公开网络一手信源（外源）**挖出可靠事实、追清口径差异，把「查证到的事实」「基于事实的推演」和「尚未查到的盲区」干干净净地交给用户。

（注：交付前的文档格式、表格公式核算与页面完整性检查归核验流程负责，本技能专注把**信息来源与事实本身**做扎实。）

## 一、先按问题复杂度决定查证深度

- **轻量精准核对**（查一个明确参数、读一个指定 URL、从单份本地文档找特定条款）：
  - 直接用 `read_document` 定位页码/工作表，或 `web_fetch` 读公开原文，1–2 轮拿到一手依据后直给答案，不无故拉长流程。
- **深度调研 / DeepSearch**（行业与岗位行情、前景评估、竞品与技术选型、政策/定价细则、多份本地文档对账、存在争议或时效敏感的课题）：
  - 启动下面的**四阶段 DeepSearch 方法**；面对复杂课题需要检索拆词模板或矛盾对账格式时，先通过 `read_skill_resource` 读取包内 `references/deepsearch-playbook.md`。

## 二、内源通道：把本地文档与工作区挖透

1. **选对读取工具**：
   - PDF、Word（DOCX/DOC）、Excel（XLSX）、PPTX 优先用 `read_document`（支持按 `sheet` 或 `page_start`/`page_end` 分段通读），不要用 `read_file` 直接读二进制文件。
   - 面对长文档，先看目录/首尾结构，再针对核心章节、附注、数据表逐段深读，别只扫开头几页就下结论。
2. **善用工作区知识与记忆**：
   - 工作区会话中结合 `knowledge_search` 与 `knowledge_read` 找回历史文档片段、会议纪要与已确认结论；引用工作区文件片段时保留 `[出处](#rayagent-source-片段ID)`，方便用户一键回溯原文。
3. **多文档交叉对账**：
   - 同时对照多份文档时，先提取各自的**日期、版本号、适用范围与统计口径**；数字或结论打架时，把双方原文与口径差异并列摊开，绝不私自取平均值或强行站队。

## 三、外源通道：四阶段 DeepSearch 深研工作流

### 阶段 1：多维拆解检索角度
不要拿用户原话只搜一次就收工。把一个宽泛问题拆成 **3–5 个互补视角**：
- **官方与基准口径**：官方文档、公告、财报、定价页、标准规范或权威机构报告；
- **真实样本与市场数据**：招聘要求样本、实际成交/定价、Benchmark 实测、公开数据统计；
- **一线从业者真实反馈**：实际使用体验、高频痛点、落地限制与隐性成本；
- **反方声音与风险边界**：质疑文章、失败案例、政策或合规限制、替代路线。
- **中英双语策略**：凡涉及全球技术、开源生态、AI 模型、跨国产品或学术前沿，主动补英文关键词检索，避免只被二手中文转述局限。

### 阶段 2：信源分级与原文深读
- **信源可信度阶梯**：
  1. 一手原始来源（官网文档、官方公告、财报/招股书、源码仓库、法律法规原文、学术原文）；
  2. 独立权威媒体、深度实测与行业研究报告；
  3. 社区讨论与个人经验帖（适合了解一线体感与踩坑，但不能单独充当全局定量定论）；
  4. 营销软文、SEO 内容农场与无出处二次转述（只作线索，绝不采信为依据）。
- **摘要不是原文**：`search_web` 返回的片段只是目录线索。凡涉及价格、日期、版本特性、政策条款、性能指标或关键引文，**必须用 `web_fetch` 打开原文核实**（遇 `requires_browser` 且浏览器可用时按原因切换，不可用时如实说明受限）。

### 阶段 3：交叉核对与矛盾追查
- 影响核心判断的关键事实，尽量从**至少 2 个独立信源**互相印证；
- 发现不同来源数字或观点冲突时，顺藤摸瓜查清原因——通常是**发布时间不同（新旧版本）、统计口径不同（含税/不含税、月活/日活、全行业/头部样本）或立场利益不同**。把冲突原因写明白，比硬编一个统一数字有价值得多。

### 阶段 4：结构化交付——事实、推演与盲区严格分层
向用户交付调研结论时，保持透明清晰：
- **已查证事实**：带明确来源名称与时间/版本（例如“据 OpenAI 官方定价页（2026-11）”）；
- **基于事实的推演判断**：明确标出这是综合已有证据后的分析推断，写清推演依据；
- **未查到的盲区或限制**：付费墙、登录限制、无公开数据或用户要求不联网导致的空白，直说具体哪一块缺证据以及它如何影响结论。

## 四、绝对底线

- **严禁凭过时记忆硬编时效事实**：现行价格、最新模型/框架能力、当前招聘行情、最新法规与热线，没查证就绝不能写成确定结论。
- **严禁只看搜索标题或残缺摘要就下定论**。
- **严禁掩盖盲区或伪造“已核实”**：查不到比编出来诚实一万倍；需要出现在主视图中的未确认项紧邻标明「待确认 / 暂无公开依据」。
