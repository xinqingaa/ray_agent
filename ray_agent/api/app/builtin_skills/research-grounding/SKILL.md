# 双通道信息求证（内源深挖 + 外源核查）

专注取得并核对一手事实来源；交付前的格式、公式汇总与完整性把关交由核验流程完成，不重复执行。

## 轻 / 重档位判断

- **IF 简单查证、单文档关键点确认或明确 URL 核对 → 走轻档（默认）**：
  - 本地文档优先调用 `read_document` 直接定位页码或工作表读取原文，或通过 `web_fetch` 读公开链接原文，1–2 轮即直给结论。
- **IF 行情调研、技术/产品选型、多份本地文档交叉比对或存在口径冲突 → 走重档**：
  - 本地侧先通览涉及的所有文件（`read_document` / 工作区 `knowledge_search` + `knowledge_read`），提取日期、版本号、适用范围并逐条对照差异；
  - 联网侧从多个角度拆词（`search_web`），对关键数字、日期、定价或政策必须 `web_fetch` 读一手原文，交叉比对至少 2 个独立信源。

## 内源通道（本地文档与工作区）

1. **优先工具**：读取 PDF、Word（DOCX/DOC）、Excel（XLSX）、PPTX 等文件，优先调用 `read_document`（按 `sheet` 或 `page_start`/`page_end` 分段读取），不要用 `read_file` 读二进制文件。
2. **工作区检索**：有工作区时配合 `knowledge_search` 与 `knowledge_read` 找回历史记忆、摘要与切片原文；引用工作区文件片段时保留 `[出处](#rayagent-source-片段ID)`。
3. **口径冲突追查**：若文档 A 与文档 B 数字或结论不一致，同时列出双方原文出处、时间或统计口径差异，不私自取平均值或强行选边。

## 外源通道（联网检索与信源分级）

1. **信源优先级**：官方文档 / 公告 / 财报 / 一手仓库 > 权威行业媒体与实测报告 > 社区转述或聚合摘要。
2. **摘要不等于原文**：`search_web` 的片段仅作线索，凡涉及价格、参数、发布时间、政策条款或定量结论，必须用 `web_fetch` 读原文确认（遇 `requires_browser` 再按可用能力切换浏览器）。
3. **事实与推断分离**：已查证的写明来源与日期；基于现状的推演明确标注为「推断」；未查到的标注「未核实 / 暂无公开依据」。

## 反模式红线

- **禁止凭过时记忆硬编**：涉及现行价格、最新特性、热线号码、法规版本等时效事实，未查证不得当作确定结论输出。
- **禁止只看搜索摘要下结论**：不得在未打开原文的情况下复述不完整摘要数字。
- **禁止掩盖缺口**：工作区无材料或联网受限导致盲区时，直接在主视图对应位置标注「待确认」或说明限制，不编造“已核查”。
