# 整合与清洗 Excel 工作流

把散乱、脏数据多、口径打架的原始表格，变成一份**结构规范、公式可自动重算、变更全程可追溯、汇总数字经代码双重验证**的干净工作簿——帮用户省掉最耗神的手工核对与查错。

## 一、先盘点真实数据，摸清脏数据与口径冲突

1. **全面探查再动手**：
   - 先用 `read_document`（按 `sheet` 分段）或随包 Python 脚本盘点所有输入文件的工作表清单、真实表头行位置（警惕多级表头或标题占前几行）、字段类型、空值比例、重复记录、日期/金额格式混杂，以及藏在明细里的「小计/合计」行。
2. **低摩擦处理歧义**：
   - 结构清晰、映射明确 → 直接给出默认清洗整合策略并动手，不无故卡住用户；
   - 真正遇到**合并主键无法对应**、**多表同名字段口径冲突**（如含税 vs 不含税）或**是否剔除某类边界行会显著改变总额**时，用 1–2 个高杠杆选择题快速向用户确认（附推荐默认项）。

## 二、清洗整合与规范工作簿建模

详细脏数据清单与公式规范见包内 `references/excel-engineering.md`（复杂整合前用 `read_skill_resource` 读取）。

1. **推荐的标准工作簿分层**（按任务繁简灵活精简，不必强凑 4 页）：
   - **总览汇总表**（放最前，方便打开即看核心指标与分组统计）；
   - **清洗后明细表**（统一日期格式、数值类型、规范分类名、去重并移除混入的原始合计行）；
   - **清洗与异常日志表**（如实记录：原始行数、去重条数、剔除异常行原因、未匹配键明细，绝不静默丢行）；
   - **原始数据快照**（必要时保留原表备份，确保可追溯）。
2. **公式与排版质量**：
   - 所有汇总、占比、均值、分组统计一律写入标准可重算 Excel 公式（如 `SUM`、`SUMIFS`、`COUNTIFS`、`AVERAGEIF`、`IFERROR` 等），**绝不把算好的死数字硬编码进汇总格**；
   - 规范数字格式（金额千分位 + 2 位小数、百分比 `0.0%`、日期 `YYYY-MM-DD`）、表头加粗微底色、冻结首行、设置合理的自适应列宽，防止单元格出现 `###` 截断；
   - 临时清洗脚本和额外依赖放进会话 `scratch` 目录，绝不污染用户工作区交付目录；
   - 后续局部调整已有表格时，先读原文件在原基础上修订并另存清晰新版，不覆盖丢失用户已有工作表。

## 三、独立核算、校验与诚实交付（必做）

1. **Python 独立全量核算**：不依赖 Excel 缓存，用 Python 直接基于清洗后明细表重新算出总览表里的每一项核心合计数、分组小计、占比与同比/环比，并检查“各分组之和 == 总计”。
2. **结构与公式检查**：调用 `verification-critique` 的 `scripts/verify_office.py <输出.xlsx>` 检查工作簿可读性、工作表与未缓存公式情况。
3. **交付与透明说明**：
   - 调用 `deliver_files` 交付 `.xlsx`；
   - **最终答复必须附上「代码核算后的关键汇总表」与「清洗处理摘要（行数变化/异常项）」**，并坦诚提醒：应用内表格预览不会自动重算未缓存的公式单元格，下载后用 Excel / WPS 打开即可完整触发公式计算。
