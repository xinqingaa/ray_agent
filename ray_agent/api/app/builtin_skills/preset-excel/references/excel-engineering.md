# Excel 清洗、建模与公式防错实战参考

## 一、盘点原始表格时的 7 类高频脏数据

写清洗脚本前逐项扫描，避免“看着合并成功、实则总额算错”：
1. **表头不在第 1 行 / 合并单元格表头**：前 1–3 行常是报表大标题或导出时间，先定位真正列名行再读取。
2. **混在明细里的小计 / 合计 / 空白尾行**：直接 `SUM` 会把金额重复翻倍，必须先识别剔除并在清洗日志里写明剔除了哪几行。
3. **文本型数字与货币符号**：`"¥1,234.50"`、`"1200 "`、全角空格、千分位逗号或 `"-"` 占位符，必须洗成标准数值类型，否则 Excel `SUM` 会静默跳过文本格导致汇总偏小。
4. **混合日期格式**：同一列同时出现 `2026/1/5`、`2026-01-05`、`20260105` 与 Excel 序列号，统一转为标准日期对象并应用 `yyyy-mm-dd` 显示格式。
5. **隐藏前后空格与全角/半角差异**：`"华东 "` 与 `"华东"`、`"A-01"` 与 `"A－01"` 会导致 `SUMIFS` / 分组统计拆成两行，分组键与关联键必须 `strip()` 并做基础规范化。
6. **重复行判断**：区分“整行完全重复（脏导入）”与“同主键不同日期/不同金额的合法多条流水”，不要粗暴按单列去重。
7. **跨表关联漏匹配**：左连接/合并后统计未匹配上的记录数与涉及金额，单独列出在清洗日志里，绝不静默丢弃。

## 二、规范公式与错误处理习惯

- **用动态条件汇总替代手工圈散行**：分组汇总优先用 `SUMIFS(明细!$D$2:$D$N, 明细!$B$2:$B$N, A2)`、`COUNTIFS(...)`，行号范围覆盖全部清洗明细行，锁定绝对引用 `$`。
- **除法与查找必包 `IFERROR`**：占比、增长率、均价公式统一写成 `=IFERROR(B2/$B$10, 0)` 或 `=IF(C2=0, 0, (B2-C2)/C2)`，避免报表出现 `#DIV/0!`、`#N/A`。
- **禁止循环引用与硬编码**：合计行用 `=SUM(B2:B9)`，严禁在总览表里把 Python 算出的静态数字直接写死替代公式。
- **跨表引用加单引号防表名含空格/特殊字符**：如 `'清洗明细'!$E$2:$E$120`。

## 三、专业视觉与可读性底线（`openpyxl` 落地要点）

- 表头：加粗、浅中性灰底（如 `#F3F4F6`）、细下边框、开启筛选器与首行冻结（`ws.freeze_panes = 'A2'`）。
- 合计行：顶部细线 + 底部双线（或浅底加粗），一眼与明细区分。
- 数字格式：金额 `#,##0.00`、整数 `#,##0`、百分比 `0.0%`、日期 `yyyy-mm-dd`；数字统一右对齐，文本左对齐。
- 自适应列宽：按列内容最大显示宽度计算（中文字符按 2 个半角宽度估算，再加 `4` 个字符余量并设合理上限如 `48`），彻底避免打开全是 `###`。
