# 幻灯片常用版式模板

编写自包含 HTML 演示稿时按每页信息类型选用不同版式，避免全篇同一种布局：

1. **封面页（Cover）**：居中或左对齐大标题 + 一行副标题 + 日期/汇报人元信息；克制留白，不堆装饰图。
2. **结论总览页（Executive Summary）**：顶部一句话核心结论（Action Title）+ 3 个关键指标/核心抓手横向排列。
3. **对比分析页（Comparison）**：双栏并列（现状 vs 目标、方案 A vs 方案 B）或结构化对比表格，明确标出差异与取舍。
4. **流程与里程碑页（Timeline / Roadmap）**：横向 3–5 步节点卡片，每步写清动作、产出与判断标准。
5. **数据解读页（Data & Takeaways）**：左侧轻量内联 SVG 图表或表格，右侧 2–3 条洞察与行动建议。
6. **交互与打印脚本要点**：
   - 键盘 `ArrowLeft` / `ArrowRight` / `Space` 翻页，页面底部显示 `当前页 / 总页数` 与上一页/下一页按钮；
   - 在 `@media print` 中展开全部 `.slide` 为独立分页（`break-after: page`），隐藏翻页控件。
