# 演示文稿端到端制作

统筹内容策划、视觉版式与实际可打开演示文件的生成和核验，做出观点明确、视觉舒适、真正能直接上场或发出的演示文稿。

## 制作流程

1. **吃透场景与叙事主线**：先明确受众、展示方式（现场演讲 vs 邮件传阅详版）与整套稿件要传递的核心逻辑，根据内容量自然规划合适页数，不强行压缩导致每页挤爆，也不为凑页数注水。
2. **遵循 `presentation-design` 策划逐页结构**：确保每页有明确核心结论、贴合该页逻辑关系的版面样式，并按需要搭配图表、数据对比或详细备注，保持整套风格与留白一致。
3. **选择可靠工艺生成与核验交付**：优先选用环境中已就绪且最稳妥的生成工具/库产出文件；如环境有转换与渲染预览能力，抽查关键页面的版面溢出、文本截断与对齐问题，修复后再完成交付与使用说明。
