# 演示文稿端到端制作

统筹内容策划、视觉版式与实际可打开演示文件的生成和核验，做出观点明确、视觉舒适、真正能直接上场或发出的演示文稿。

## 制作流程

1. **吃透场景与叙事主线**：先明确受众、展示方式（现场演讲 vs 邮件传阅详版）与整套稿件要传递的核心逻辑；修改已有文稿前先通读现有 `.pptx`、会议纪要与进度表并对齐最新口径，再按内容量自然规划页数，不强行压缩或注水。
2. **遵循 `presentation-design` 策划逐页结构**：确保每页有明确核心结论、贴合该页逻辑关系的版面样式，并按需要搭配图表、数据对比或详细备注，保持整套风格与留白一致。
3. **选择可靠工艺生成与核验交付**：环境随附的受管 `python3` 已内置 `python-pptx` / `openpyxl` / `python-docx` / `pypdf`，可直接用于读取与生成演示文件；用 `verify_office.py` 核验产出结构；若另导出为 PDF，务必调用 `read_document` 或 `pypdf` 实查中文文本可完整提取、无乱码或方块后再交付。
