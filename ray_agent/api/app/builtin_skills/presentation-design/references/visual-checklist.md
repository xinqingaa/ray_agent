# 视觉设计、排版与版式实用参考

制作互动网页小工具、HTML 演示稿、数据看板或长篇 HTML 报告前参考本手册，结合具体主题灵活取舍。

## 一、四类常见场景的视觉调性配方（按主题选用，不生搬硬套）

1. **效率工具 / 数据看板 / 经营分析**
   - 气质：精密、干净、长看眼睛不累。
   - 色彩参考：中性微暖浅灰底 `#F7F7F5` + 纯白工作面 `#FFFFFF` + 细边框 `1px solid #E5E7EB` + 深炭主字 `#18181B` + 次字 `#52525B`；单一沉稳强调色（深靛 `#2563EB` 或深青 `#0F766E`），警示/负面仅在数据状态中少量出现。
   - 细节：指标与表格数字全开 `font-variant-numeric: tabular-nums`；减少重阴影，靠细腻层级与 1px 边界区分区域。

2. **汇报演示稿 / 方案提案（16:9 HTML Slides）**
   - 气质：节奏鲜明、一页一观点、大标题直接下结论。
   - 色彩参考：干净纸白 `#FAFAF9` 或素白 `#FFFFFF` 为主，搭配 1 个契合行业的深主色（如藏青 `#1E3A5F`、墨绿 `#14532D`、石墨 `#1F2937`）+ 1 个主提亮色用于关键数据和主推项；封面或章节转场页可适度用深色底拉出节奏反差，正文页保持高对比浅底。
   - 细节：每页留白不少于视觉面积的 25%；连续两页尽量不重复完全相同的布局。

3. **深度阅读长报告 / 调研简报**
   - 气质：杂志/专栏阅读感，适合沉浸细读。
   - 色彩参考：柔和纸面 `#FCFCFA` + 墨黑 `#1C1917` + 细分割线 `#E7E5E4`；小面积强调色用于结论框与引用竖线。
   - 细节：正文单栏最大宽度 `65ch`–`74ch`，行高 `1.7`–`1.8`，图表与表格配清晰编号标题和来源注脚。

4. **轻量个人 / 生活向互动工具**
   - 气质：温和亲切、零压迫感、操作路径一眼明白。
   - 色彩参考：柔和暖白 `#FAF8F5` + 卡片 `#FFFFFF` + 温润低饱和主色（鼠尾草绿 `#3F6255`、柔和陶蓝 `#3B6786` 等），圆角舒展统一。

## 二、中文与混排排版基准

- **原生高水准字体栈（离线与 PDF 导出均稳定不缺字）**：
  - 现代无衬线：`'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', -apple-system, BlinkMacSystemFont, sans-serif`
  - 专栏/报告衬线：`'Songti SC', 'Noto Serif SC', 'Source Han Serif SC', Georgia, serif`
  - 代码与精密数字：`'SF Mono', 'JetBrains Mono', Menlo, Consolas, monospace`
- **清晰字阶（避免全屏字号差不多大）**：
  - 主标题 / 封面标题：`28px`–`44px`（紧字距 `-0.02em`，行高 `1.15`–`1.25`）
  - 节标题 / 页标题：`20px`–`24px`（`font-weight: 650`，行高 `1.3`）
  - 正文：`15px`–`16px`（演示稿正文 `16px`–`18px`，行高 `1.6`–`1.75`）
  - 辅助说明 / 来源 / 表头：`12px`–`13px`（降低对比度，不抢正文视觉权）
- **阅读纪律**：同一页面最多使用 1–2 个字体家族；重点信息靠字号、字重、留白和位置建立层级，而不是靠满屏加粗或彩色底纹。

## 三、信息形态与可视化选型

| 内容本质 | 优先表达形式 | 避免的错配 |
|---|---|---|
| 多维方案 / 产品对比 | 结构化对比表（突出主推列与关键差异） | 写 3 段各 200 字纯文字让读者自己找不同 |
| 数值趋势 / 占比 / 排名 | 轻量内联 SVG 图表（直接标数值、去多余网格线） | 只丢一串文字百分比，或引入重型外部 CDN 图表库导致离线白屏 |
| 步骤 / 里程碑 / 演进 | 横向或纵向时间线（每节点写动作 + 产出 + 判据） | 随便用大段无序列表平铺 |
| 现状 vs 目标 / 冲突双方 | 双栏对照（左现状/痛点，右方案/收益） | 混在同一列里混着写 |
| 核心 KPI 总览 | 2–4 个核心指标卡（大数 + 含义 + 口径/变化） | 凑 8 个无关紧要的装饰数字 |

**内联 SVG 图表要点**：设置明确 `viewBox` 保持缩放清晰；坐标轴与数据标签预留边距，绝不让文字与柱子/折线/边框重叠；所有数值必须来自真实数据或代码核算，缺失数据明标「占位」。

## 四、交互、响应式与打印 / PDF 导出自检清单

1. **布局与适配**：
   - 桌面宽屏（`1280px`）与窄屏（`390px`）下均无 `scrollWidth > clientWidth` 横向溢出；
   - 表格在窄屏套 `overflow-x: auto` 容器，防止把整页撑破；
   - 弹性容器内文本节点加 `min-width: 0`，避免长词/长链接顶出边界。
2. **真实交互与无障碍底线**：
   - 页面上每一个按钮、Tab、筛选器、输入框、翻页和导出控件都绑定真实逻辑，绝不留“装饰性假按钮”；
   - 交互元素具备清晰 `:focus-visible` 焦点态；使用 `prefers-reduced-motion: reduce` 关闭非必要动画；
   - 空状态、加载态、输入错误提示清晰具体。
3. **打印与 PDF 导出友好（演示稿与报告必检）**：
   - 增加 `@media print` 与 `@page { size: A4 landscape; margin: 12mm; }`（横版演示稿）或 `@page { size: A4 portrait; margin: 14mm; }`（长报告）；
   - 演示稿打印时展开全部 `.slide`（`break-after: page`）并隐藏翻页/工具栏控件；
   - 为卡片、表格和图表容器设置 `break-inside: avoid; page-break-inside: avoid;`，防止分页时被腰斩。
