# 运行时视觉与版式检查清单

在编写重视觉产物（互动网页小工具、HTML 演示稿、长篇 HTML 报告）前参考本清单：

## 1. 场景调性选型

- **效率工具 / 仪表盘 / 数据看板**：中性浅灰画布 `#F7F7F5` + 纯白面板 `#FFFFFF` + `1px solid #E5E7EB` 细边框；单一沉稳强调色（深靛 `#2563EB` 或墨绿 `#0F766E`）；数字使用 `font-variant-numeric: tabular-nums`。
- **汇报演示稿 / 方案提案**：16:9 画布比例，支持左右方向键、点击翻页与页码指示；每页正文不超过 3–5 条短句或 1 张清晰图表/对比表；封面、目录/议程、结论页、对比页、结尾页版式有节奏变化。
- **阅读型长文 / 提炼报告**：单栏最大阅读宽度 `68ch`–`76ch`，行高 `1.65`–`1.75`，图表与表格有简短标题与数据来源标注。

## 2. 导出与打印友好（用于生成 PDF 时）

- 增加 `@media print` 与 `@page { size: A4 landscape; margin: 12mm; }`（演示稿）或 `A4 portrait`（长文报告）；
- 为关键容器设置 `break-inside: avoid; page-break-inside: avoid;`，避免卡片或表格被硬生生腰斩；
- 使用系统原生中文字体（`PingFang SC`, `Hiragino Sans GB`, `Songti SC`），确保导出 PDF 后字体可完整嵌入与提取。

## 3. 自检要点

- 桌面宽度（`1280px`）与窄屏宽度（`390px`）下均无 `scrollWidth > clientWidth` 横向滚动条；
- 所有按钮、输入框、标签页和翻页操作均有实际交互绑定，不存在无响应的装饰按钮；
- 图片、图表与 SVG 无重叠遮挡或文字截断。
