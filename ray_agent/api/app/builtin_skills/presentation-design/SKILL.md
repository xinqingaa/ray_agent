# 演示文稿内容与视觉设计

根据沟通场景（高层汇报、产品路演、专业培训或详尽方案书）自然组织每页节奏、版式层次与视觉重点，不为追求表面“极简”而牺牲核心论证与可用信息，也不堆砌无意义的装饰元素。

## 内容与结构节奏

- **一页一个核心判断**：每张幻灯片有明确想让观众记住的观点或结论，标题直接点出判断或要点（“结论型标题”优于空泛的“工作进展”），正文与图示共同支撑这一判断。
- **信息密度贴合使用场景**：
  - 现场路演或演讲型页面注重视野留白、大字号关键词与强烈视觉锚点；
  - 邮件传阅或深度决策汇报材料需要自洽可独立阅读，充分给出关键数据、对比依据、逻辑拆解与完整演讲备注（Speaker Notes）。
- **页面结构多样化**：根据内容天然关系选择最合适的布局（关键指标卡、左右对比、时间轴、漏斗/流程图、矩阵四象限、结构化数据表或全图沉浸页），避免整套演示文稿千篇一律套用“标题+三点列表”。

## 视觉层级与排版工艺

- **清晰的三层视觉阶梯**：页面主标题 → 关键数字/分栏小标/结论摘要 → 辅助说明与数据来源，通过字号、字重、间距与色彩对比自然引导视线。
- **色彩搭配和谐统一**：确立 1 个主品牌色 + 1 个点缀强调色 + 充足中性背景/正文色；强调色留给真正需要高亮的结论、关键数字和动作节点。
- **对齐、留白与安全边界**：全套页面保持一致的网格对齐与边距留白，字体兼容运行环境常用字体族，避免文本截断、重叠或图表标签挤压。
