# RayAgent 界面设计说明

本文记录已经落地的设计 token、运行视图组件与设置页约定。会话页、工作台、开发者视图和首页已在 W5 阶段二落地；后续界面微调也记在这里。方案来源是 [W5 子计划](../../docs/plan/w5-ux.md)；颜色与字体的取值以 [globals.css](src/app/globals.css) 为准。

阶段一实现过程中的对照修改没有另存记录。下面按已落地的样式与组件整理，不补写当时没有留下的自审条目。

2026-10-03 侧栏胶囊切换、字体层级、项目文件导入与输入框入口的[修订草案](../../docs/plan/w5-ux.md#侧栏与项目文件交互修订草案2026-10-03)已获用户确认并落地，下面描述当前界面；验证条件见总计划证据。

## 原则

- 给操作者长时间使用的专业工具。信息密度和可扫读优先，没有营销式首屏。
- 记忆点只放在运行视图：状态条、计划条和工具流。设置页与其余区域保持安静。
- 界面只展示视图模型里已有的数据。没有运行时状态条显示“空闲”；用量没有数据时上下文环显示不可用，不估算一个百分比。
- 文案用用户能执行的动词（“读取文件”“运行命令”“交付文件”）。模型看到的工具名只在展开详情里出现。
- 错误写发生了什么、接下来可以做什么，不道歉。

## 颜色

浅色采用接近白色的中性纸面，侧栏只比主画布深一档；钴蓝 `signal` 仍只负责交互强调。深色保留石墨层次。状态色语义固定，亮暗各一套；文字色与浅底色成对使用（`text-state-*` 与 `bg-state-*-soft`）。

| 语义 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| 画布 `background` | 页面底 | `#fafbfc` | `#171a1e` |
| 侧栏 `sidebar` | 导航底面 | `#f6f7f8` | `#1b1e23` |
| 内容面 `card` | 卡片、状态条 | `#ffffff` | `#1e2227` |
| 墨色 `foreground` | 正文 | `#14181d` | `#e6e9ed` |
| 次级 `muted-foreground` | 说明、标签 | `#56606b` | `#a3acb6` |
| 更弱 `faint` | 占位、无计划说明 | `#606973` | `#8a939d` |
| 强调 `signal` | 正在运行、当前项、链接、焦点环 | `#2549c4` | `#8fa8ff` |
| 弱底 `muted` | 次级控件与代码背景 | `#f0f2f4` | `#262b31` |
| 侧栏选中 `sidebar-accent` | 当前会话、悬停 | `#edf0f2` | `#2a3037` |
| 边界 `border` | 面与面之间 | `#e2e7ea` | `#343a42` |
| 运行中 | 与 signal 相同 | `#2549c4` / `#e6ecfb` | `#8fa8ff` / `#233056` |
| 等待 | 等回复、等审批、未保存标记 | `#8a5300` / `#fbf0dc` | `#f0b35a` / `#3a2e1a` |
| 成功 | 完成、已连接 | `#1c7340` / `#e2f3e8` | `#6bcb8f` / `#1d3527` |
| 失败 | 失败、校验错误 | `#b42318` / `#fce8e6` | `#ff8f85` / `#3d2222` |
| 已停止 | 停止中、已停止、被拒绝、已取消 | `#56606b` / `#eceff2` | `#a3acb6` / `#2a3037` |
| 已中断 | 服务重启等中断 | `#8a3a8f` / `#f5e6f5` | `#e09ce4` / `#3a2440` |

深色不是纯黑。面与面靠明度台阶区分：画布、侧栏、卡片、弹出层逐级抬高。状态色在深色里整体提亮，浅底降低明度，避免浅色那套直接反色后对比不足。

业务组件使用上表 token，例如 `bg-background`、`text-muted-foreground`、`text-state-running`、`bg-signal`。不要在新界面里写 `gray-*` 或十六进制颜色。终端输出使用 `terminal` / `terminal-foreground`，不跟正文底色混用。

## 品牌标记

标记是一条构成 `R` 的执行路径，末段使用 `signal` 色表示从当前回路进入下一步；没有机器人、齿轮或装饰性光效。界面组件在 `src/components/brand-mark.tsx`，与文字 RayAgent 一起出现在侧栏，首页任务入口只放小尺寸标记。浏览器标签使用同形的 `public/brand-mark.svg`；旧的手势 PNG 已移除。深色界面的标记跟随文字和 `signal` token，标签图标则始终使用与画布相同的淡白底 `#fafbfc`，以保持小尺寸辨认度。

## 字体

西文与数字用 IBM Plex Sans（可变字重），中文依次回落到苹方、冬青黑体、微软雅黑、思源黑体和系统无衬线。命令、路径和代码用 IBM Plex Mono，中文等宽回落同样带系统中文字体。

正文 14px、字重 500、行高 1.6。侧栏普通对话标题明确使用 400；项目名称与选中对话使用 500，辅助信息使用 400，避免继承正文造成层级混淆。辅助信息用 `text-meta`（13px / 20px）。计时、轮次、token、字节数和表格数字加 `tabular-nums`。根布局在 `src/app/layout.tsx` 引入这两套字体。

## 间距、圆角与密度

间距沿用 Tailwind 的 4px 网格，没有另设间距 token。常用节奏：时间线条目 `gap-3`，状态条内边距 `px-4 py-2`、最低高度 3rem，设置页内容区 `px-5`（中等宽度起 `px-8`），目录页内容区 `px-6`。

圆角以 `--radius: 0.5rem`（8px）为基准，`rounded-sm` 到 `rounded-4xl` 在此之上加减。工具行、输入和卡片用 `rounded-md` 或 `rounded-lg`，不使用大圆角胶囊作为主容器。

侧栏宽度 288px。设置页在容器宽度达到约 48rem 时，左侧为 11rem 的分区导航，更窄时改为顶部横向标签。窄屏目标是可读可操作，不另做移动端布局。

## 主题

`next-themes` 挂在根布局，`attribute="class"`，默认跟随系统，也可选浅色或深色。选择保存在浏览器本地。主题选择位于设置页的“外观”分区；组件状态目录页的页头另有测试用切换控件。切换时关闭主题过渡，避免整页闪色。

`globals.css` 用 `@custom-variant dark (&:is(.dark *))`，因此深色样式挂在带 `.dark` 的祖先下。`html.dark` 同时设置 `color-scheme: dark`，让滚动条和表单控件跟随。

## 动效

运行状态行不使用持续扫光。暂停在输入框的发送位；停止中按钮禁用，转圈只留在时间线那一句。开发者视图的事件原文与轮次请求面板在展开和收起时使用 200 ms 的高度与透明度过渡，轮次箭头同步旋转。桌面工作台的宽度和主区随打开、收起操作在 220 ms 内过渡；窄屏抽屉使用同样时长。

`prefers-reduced-motion: reduce` 时动画和过渡时长压到几乎为零。

## 布局

侧栏使用“对话 / 项目”胶囊，默认对话。新建是顶栏里的线框图标，随当前标签切换：对话是气泡内加号，项目是文件夹右下角加号，后者打开「空白项目 / 从文件夹创建」。收成图标栏时，这两个图标在展开按钮下方。列表项一行，行与行之间留 4px：标题在左，时间在右；今天只显示时分，昨天显示「昨天」，更早显示月/日。准备中、运行中、压缩中、等你回复、等你批准、失败和已中断用状态词替换时间；还不知道是回复还是批准时写「等你」。已完成和已停止只显示时间。空列表留白。项目行不铺悬停或选中底，名称前只在不可用、需修复、运行或等待时放一颗状态圆点，悬停写「等你回复」或「等你批准」；当前项目的文件夹图标用正文色。点项目行收起或展开其对话；没有对话的项目点了不展开，也不留出空档。行内不放展开箭头。进入项目用行上的气泡加号或更多菜单里的「在此项目新对话」；已归档项目不显示气泡加号。子对话缩进，不画层级线，并显示时间。当前分页外项目临时置顶。切换标签保留页面与草稿；项目直接导航，归档单独管理；打开项目不创建会话，发送才创建。

项目记忆从会话顶栏和项目页以同一枚页面图标打开，右侧抽屉宽 480px。日常分区是说明、笔记、摘要。修改记录和运行内容预览是顶栏图标。三句分工说明放在问号里；有冻结内容时，问号再补「这次续接仍用原版本」。保存成功后才写「下一次新运行生效」。

项目工作区承载文件、快照和近期对话。已有对话不更换项目。

会话页中间是时间线，用时和轮次放在输入框上方，其下是计划条与输入框，右侧工作台按操作展示结果、终端、浏览器与文件。同一时刻只在时间线末尾写一句当前状态：刚送出或模型请求是「正在思考」，沙箱未就绪是「正在准备执行环境」，停止中是「正在停止」，压缩是「正在压缩上下文」。工具执行不再另写一句，动词留在工具行。发送按钮同时变成暂停图标。失败、已停止和已中断的原因只在时间线终态条；失败条只留原因和一枚「重试」。点重试或再发消息时先收起上一轮终态并回到「正在思考」，发送失败则把终态条放回来。加号仅提供计划模式与压缩上下文，回形针直接添加附件，斜杠保留上传与项目导航命令。项目归属在页面标题区显示文件夹图标和名称，输入工具行不重复显示项目名；主体标题区移除新对话 `+`。上下文只显示圆环，悬停、聚焦、点击共用数据，弹层打开时不叠 Tooltip；实测优先，估算和缺失明确标注。按计划执行只在有效计划后显示。窄屏侧栏和工作台为抽屉。

项目文件页明确 loading/error/empty，上传先扫描确认；导入弹窗用较大的树与节点详情表达层级、大小、排除和确认原因，窄屏详情位于树下，底部汇总与操作固定。上传完成后以“完成”结束流程。快照显示保护、恢复和清理结果；清单为空但对象待回收时仍提供重试。运行、等待、文件操作和环境收尾分别展示，409 有返回占用对话和停止入口。交付标明项目文件引用、副本已保存或失败重试。Git 与宿主机目录入口已移除。

开发者视图与对话在同一位置切换，不另开路由。窄屏（约 768px 以下）时，侧栏用原有抽屉，工作台改为右侧抽屉。进入任何会话时工作台默认关闭，顶部入口或时间线工具操作可打开。

会话页在 `components/session-detail-view.tsx`，消费 `useSessionDetail` 的 `view`。工作台在 `components/workbench/workbench.tsx`，开发者视图在 `components/developer/developer-view.tsx`。首页把任务输入置于主区中央。组件状态目录仍用夹具，不接真实会话。

运行中与等待时，输入框上方只显示用时和轮次，不写阶段词；等人时句子在提问卡「等你回复」或审批卡「等你批准」。暂停在发送按钮上。计划模式运行额外显示“计划模式”标记。手动压缩不改变运行状态。压缩期间侧栏写「压缩中」，时间线末尾写「正在压缩上下文」，标题和状态行不写；压缩结果写入后替换该行。完成与停止后状态行收起，标题旁保留低调的「已完成」或「已停止」。失败与中断不放在标题和状态行。顶部不显示累计 tokens 或速度。工作台打开时只在右侧面板保留标题，顶部只在关闭时显示打开入口；搜索、MCP、远程 Agent、计划等工具落在“结果”页，不进入终端页。开发者视图页头用紧凑的事件类型菜单与“导出 JSON”操作；事件类型显示中文，原始类型可在菜单及表格悬停提示中查看。事件表格固定序号、时间、类型、运行与原文操作列的宽度，摘要占余下空间；窄屏在表格内横向滚动，短字段不折成竖排。`context` 事件按追加、清理推理字段、替换上下文分别命名，只有 `compact` 事件称为“上下文压缩”。事件原文和轮次请求都可再次点击收起；某轮请求紧跟该轮条目显示，切换轮次时不跳到列表底部。

**计划后续：** 是否显示「按计划执行」见 [W9 U6](../../docs/plan/w9-input-commands.md#设计契约)。不要只因为最近一次计划运行已完成就显示该入口。

## 组件与状态

每个组件在开发模式的 `/dev/components` 列出下表状态。数据形状是 [W4 视图模型](../../docs/plan/w4-ui-data.md#视图模型契约)，夹具在 `src/fixtures/`。标“真实”的来自 W1 评测与走查事件；标“合成”的是这些事件里不会出现的状态。

| 组件 | 目录中的状态 |
|---|---|
| 运行状态条 | 空闲、已完成、已停止、失败、已中断不占位；进行中和等待只显示用时与轮次。当前一句在时间线：正在思考、正在准备执行环境、正在停止、正在压缩上下文 |
| 计划条 | 无计划、进行中（折叠与展开）、全部完成、运行结束时有未完成项、计划被修改（状态变化，以及新增与删除） |
| 工具卡 | 运行中、成功、未成功、被拒绝、未执行、已取消、结果被截断、参数过长；另有在工作台中选中 |
| 工具组 | 部分完成、全部成功、含未成功 |
| 旁白与最终回复 | 旁白、短文本、长文本与代码块、表格；另有 W6 增量渲染入口 |
| 用户消息 | 普通、带附件、补充要求 |
| 提问卡 | 等待回复、已回复 |
| 审批卡 | 待审批、提交中、已批准、已拒绝、已失效 |
| 交付卡 | 单文件、多文件、预览不可用 |
| 压缩提示 | 正在压缩上下文、一次压缩、手动压缩 |
| 失败尝试提示 | 已重试、最终失败 |
| 终态条 | 失败、已停止、已中断 |
| 上下文环 | 实测、估算、缺失、超限、处理中；悬停/聚焦/点击共用数据 |
| 输入框命令 | 加号短名称菜单、斜杠筛选、不可用原因、草稿与发送恢复 |
| 按计划执行 | 只在有效计划后显示 |
| 会话列表项 | 选中弱底；准备中、运行中、压缩中、等你回复、等你批准、原因未知时的「等你」、失败、已中断在标题右侧显示文字；已完成和已停止只显示标题与时间；可访问名称保留状态；另有长标题 |
| 项目选择器 | 加载、错误、空列表、分页、归档与新建；过期请求不覆盖当前页 |
| 工作台项目页 | 空目录说明、文件预览（文本 / 二进制 / 过大）、项目不可用 |
| 项目快照页 | 保护降级、恢复未完成与两种修复、归档清理及残留对象重试 |

设置页另有 MCP、A2A 列表行和工具策略，同样列在目录页，便于回归分区外观。

## 设置页

路由 `/settings`。分区为通用、外观、模型提供商、MCP 服务器、远程 Agent 和工具策略。通用与模型表单使用同一套草稿：字段说明、即时校验、保存中、保存结果，以及未保存时离开页面的提示。切换分区不丢草稿。只调用现有设置接口。

外观分区只修改当前浏览器的主题；其余分区的保存方式见相应设置说明。
