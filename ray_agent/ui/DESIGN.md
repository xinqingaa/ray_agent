# RayAgent 界面设计说明

本文维护专业工具界面的设计原则和交互契约。具体颜色、字号、尺寸、图标与动效数值以 [globals.css](src/globals.css)及组件实现为准，不在文档复制。用户功能见[产品说明](../../docs/product.md)，数据与验证入口见 [UI 开发指南](README.md)。

## 设计原则

- 为持续操作和复杂任务提供可扫读的信息，界面保持安静，当前动作与阻塞原因优先。
- 只展示已有数据，缺失值给出不可用状态，估算、历史请求和实测值明确区分。
- 工具文案使用动作和结果；错误说明发生了什么以及可执行的下一步。
- 同一状态尽量在一个主要位置表达，避免标题、状态条和时间线重复播报。
- 重复行内动作可以用图标，提供可访问名称与提示；主要和不可逆动作使用清楚的文字。
- 界面只保留完成当前操作需要的短标签、状态和错误原因。设计解释、实现原理、长篇能力说明维护在文档，不放入正常操作流程；不可用状态给简短原因与下一步，不靠常驻说明教学。
- 主题、键盘焦点、窄屏与减少动态效果偏好作为组件状态的一部分处理。

## 视觉语义

| 语义 | 用途 |
|---|---|
| background / sidebar / card | 画布、导航与内容面，通过明度区分层次 |
| foreground / muted-foreground / faint | 正文、说明和更弱信息 |
| signal | 当前交互、选中、链接和焦点强调 |
| border / muted / sidebar-accent | 边界、次级底面及导航选择 |
| state-* 与 state-*-soft | 运行、等待、成功、失败、停止和中断的文字与弱底配对 |
| terminal / terminal-foreground | 终端区域，与正文底面区分 |

业务组件使用语义 token，不另写灰阶或固定十六进制颜色。浅色保持中性纸面，深色以明度阶梯区分区域；状态不只靠颜色表达。数字统计使用 `tabular-nums`，命令、路径和代码使用等宽字体。阅读字号选择保存在本地，字号变化不同时放大间距、图标和圆角。

品牌标记使用执行路径构成的 R，与主题和 signal 保持一致；导航及业务操作使用统一图标系统。局部图标替换和尺寸调整只修改实现。

## 页面与状态契约

| 区域 | 必须保持的行为 |
|---|---|
| 导航 | 对话之间与设置页可切换，草稿与当前页面保留；不在列表中的当前对话仍可定位；旧请求不覆盖新页 |
| 首页与输入 | 独立首页只保留品牌、目标提示与输入区，进入时恢复草稿并聚焦一次；共用输入随内容增高和回缩，达到上限后滚动；Enter 发送，Shift + Enter 换行，兼容 Alt + Enter；中文组合输入的回车不发送；文字与图片混合粘贴保留文字，附件上传中禁发，迟到响应归属原草稿 |
| 用户图片 | 上传和粘贴共用附件；输入区只显示缩略图，悬浮或键盘聚焦时显示右上角预览与移除，触屏保留操作入口；复用通用预览，名称与大小在预览详情展示；不显示视觉能力提示，不因能力未知或图片数量阻止发送；后台自动组织像素与文件材料，不自动切换模型 |
| 会话 | 时间线承载过程，模型处理且没有可见文本增量时持续显示思考状态，包括工具完成后的下一轮和工具参数生成；输入区域支持补充和回答；等待审批时引导处理审批，停止状态不冒充完成 |
| 计划 | 本次写出或承接清单才显示，确认执行与查看分开；保持顶层计数、层级和稳定状态。详细规则见[计划展示](#计划展示) |
| 计划历史 | 右上角清单图标打开只读弹框，复用当前计划的简洁结构与状态；各份只显示最新清单，多份可切换，无计划显示明确空态。任务标题旁用短状态标记表达停止和失败，可见标题使用任务标题，下方展示描述；关闭恢复入口焦点；新计划不抢走当前选择 |
| 工作台 | 进入会话默认关闭，操作入口打开；自动跟随新工具，手选后固定，可返回最新；窄屏使用抽屉 |
| 浏览器与截图 | 展示本次文本、URL、结果及显式图；图片加载失败或到期给明确说明，大图可适应窗口或查看原始尺寸 |
| 开发者视图 | 保留筛选、展开与滚动状态；区分事件、轮次和压缩；请求原文紧跟所选轮次，导出使用持久记录 |
| 上下文 | 区分最近请求、压缩估算、预算版本与累计用量；没有数据不伪造占用百分比 |
| skill | 列表只展示摘要与启停，新增和详情使用独立弹框；来源只分 GitHub 和本地内容，本地包含直接编写；获取或上传后直接打开内容，返回保留输入；宽屏目录与内容并列、窄屏切换目录，文件整行可点；默认渲染 Markdown，源码可切换，编辑显式进入；安装成功留在详情；输入框与用户消息用同一整段高亮名称，点击打开只读预览；社区及帮助使用带提示的图标；叠层关闭恢复原视图及焦点 |
| 设置与模型 | 分区切换保留草稿；未保存退出需提醒；模型能力按目录表达，活动运行与下一运行设置分开 |

全局清空放在危险操作区，显示范围、占用冲突和不可恢复后果；需输入确认短语，取消默认聚焦。清理进度独立于弹窗，失败可读回与重试，完成后刷新导航并清除相关草稿。

主题由 `next-themes` 管理，默认跟随系统，选择保存在本地。深色用统一 token，不在组件再维护一套颜色。动效帮助说明状态切换与面板关系，减少动态效果时禁用或缩短。持续动画只用于时间线中仍在处理的那一行（状态点与文字微光），减少动态效果时为静态；其他区域不以持续装饰动画表达运行。

## 回复排版

助手回复、Markdown 预览与 skill 正文共用一套排版：标题按级别拉开字号，一二级带分隔线，五六级只降为弱色；嵌套无序列表逐级换用实心圆、空心圆与方块。表格有表头底色、斑马纹与悬停行，保留 GFM 对齐，宽表在容器内横向滚动。代码块标注语言时显示语言名与复制按钮，只高亮显式标注的语言；未标注时复制按钮在悬停或聚焦时出现。高亮颜色沿用图表色阶，随主题切换。对话正文与表格、代码块共用聊天栏宽度，不再单独收窄段落。

## 计划展示

计划模式形成有效清单并结束后，回复下方提供简短说明与“按计划执行”图标入口；底部计划面板负责查看，执行需通过有效性判断。准备执行、业务阶段和工具活动分别表达。

摘要条在展开和收起时均显示整体计数、进度、当前阶段及已标明的当前子步骤。平铺标“项”，有子步骤标“阶段”；固定一行，长内容省略。进度用中性轨道的填充长度表达，执行中不改色。展开箭头在摘要右侧，只有读屏“收起计划”名称，没有重复可见文字。

展开主体和历史清单只显示简短标题、任务描述、层级任务项与状态，标题高于描述，不重复整体或子步骤计数。子步骤轻缩进，活动运行中的当前项使用 loading，终态未完成项不转动。后续安排保留在整体分母，缺少必要成果显示部分交付。

完整目标、范围、变更、成果和核验记录保留内部；成果在交付区查看，范围变化及阻碍在对话说明。主面板保持稳定身份、焦点与展开状态，向上展开的外框不挤占阅读布局。普通任务不显示进度未确认，历史只取各份最新清单。

## 状态表达与恢复路径

侧栏会话行用图标而不是状态词：运行中和压缩中显示旋转图标，等回复、等批准、失败与中断显示对应的状态色图标并替换时间，状态词只在悬停提示和读屏名称里。运行完成时用户不在该会话，时间前显示成功色圆点；打开会话且页面可见后清除，已停止和已查看的完成只显示时间。

时间线承担当前动作与最终原因：模型请求、资源准备、停止和压缩各有明确状态；工具动作写在对应工具行。同一时刻不在标题、状态条和时间线重复解释。

会话组件消费统一事件投影，按调用身份合并开始与结果，旧快照不覆盖新事件。投影本身不读取时钟，实时走秒由组件计算；模型请求耗时、工具耗时与任务墙钟分别表达，不能由其中一项推断全部时长。

运行统计在所有模式下跟随当前回复或执行过程并靠右排列，每项是弱色线描图标加数值（时长、轮次、tok/s，结束后加紧凑写法的 tokens），项间用间距分隔，不加“用时”“速度”文字或常驻估算符号；悬停提示说明每项含义。运行中的状态词与统计共用一行，状态靠左、统计靠右；状态行与工具行左对齐，走秒只计当前模型请求或停止请求，不冒充任务墙钟。统计整体是一个按钮，点开显示开始时间与逐轮的模型耗时、首字延迟、输出和速度，开发者模式增加工具耗时；速度来源与终态用量在明细中说明，读屏名称同样说明来源。完成后统计留在最终回复下方，并补上本次运行已记录的输入与输出 Token（含自动压缩）；停止、失败和中断附在结束记录下方。输入框上方不显示统计，上下文圆环详情保留会话累计用量。工具执行时保留最近生成速度，未获得速度时显示 `— tok/s`。过程标题和操作分组不显示工具数量，失败说明保留。失败、停止和中断不借加载动画表达。

主动停止只在时间线保留中性“已停止生成”与继续处理的提示，输入按钮称“停止生成”；普通模式不重复播报被取消的模型尝试，标题不再重复停止状态。

失败原因与重试入口留在垂直居中的终态条；点击重试立即隐藏旧失败提示，保留一次原始提问并隐藏本次重试回显，提交失败则恢复原终态说明，重试运行失败显示新失败。展示关联保存在本地，刷新和重新进入沿用；原始运行及事件保留。

提问和审批明确说明在等谁做什么。审批卡在提交中禁用重复操作，结果留在同一张卡；已失效不能继续批准。等待审批期间输入引导批准、拒绝或停止。按钮可用性依据实际运行与调用状态，不能仅凭最后一条文本判断。

文件交付以附件表达，可预览和下载；下载失败给出原因，不把未保存的文件显示为已交付。

终端读取失败保留已经取得的输出并提示，恢复连接后继续读取。工具动作成功但后续观察失败保留动作结果，补观察不能诱导重复写入。截图的加载失败、到期和不支持预览分别说明，关闭大预览返回原工作台。

## 开发者模式

设置中的开发者模式默认关闭，偏好保存在本地。普通模式显示进展、计划、可读业务结果、文件、页面内容及回复下方统计，隐藏开发者切换、上下文容量、原始工具参数、工具耗时、终端和连接编辑。失败、审批、停止、文件保护与执行权限保持可见。开发者模式增加技术观察；关闭后回到对话，再开启保留已有筛选和阅读状态。回复下方统计及工具数量隐藏不受开关影响。显隐通过统一 hook 和区域策略工厂控制，调整展示不改变执行内核。

普通模式右侧称为“查看”，“查看最新结果”只在存在可返回的新结果时出现。成功工具的重复状态行隐藏，失败说明保留；隐藏或关闭终端后停止输出轮询。设置存在未保存修改时不能关闭开发者模式，隐藏字段保留原值。网址只提供一个主链接，展开的过程标题不重复正文旁白。运行中各轮过程可单独展开收起；运行结束后，连续过程段收进默认收起的“执行过程”折叠块；遇到用户补充、提问、审批、交付或其他运行时分段，保持原始消息顺序，最终回复、交付与提问始终可见。

## 导航与任务查看

侧栏只列对话：顶部是“对话”标题与新对话图标按钮，列表有加载、失败与空态，当前对话不在已加载列表中时单独取回显示。新增对话全局复用双气泡图标；文件上传、下载、刷新等操作统一为带悬停提示和无障碍名称的图标按钮，确认、保存等需明确表达结果的操作保留文字。

对话右侧只有一层“本次对话／页面”：交付在输入之前；没有浏览器记录则无页面入口。普通列表省去系统目录层，不伪造材料/成果分类；路径在文件详情按需展开，开发者模式不改变默认列表。新结果不强制切走用户正在阅读的文件。

公共 Tooltip 使用主题卡片表面、正文色、边框与轻阴影，延迟出现；IconAction 与 PreviewAction 不额外设置原生 title。面板打开时聚焦容器，不自动弹出关闭按钮的 Tooltip；用户按 Tab 后进入操作按钮。

斜杠菜单在一次展开期间保持高度稳定，内容超出时只在列表内滚动；过滤结果和空态不触发高度动画。鼠标移动只更新高亮，滚轮与触控板不自动跟随选中项；方向键导航越出可视范围时才做最小滚动，静止指针不抢回键盘选择。搜索变更从首项开始，Escape 关闭并保留输入，松键不重开同一片段。压缩命令的描述区只展示与右侧入口共用数据和图形的上下文圆环，圆环不形成嵌套按钮；无数据用未知态，不可用原因通过提示及可访问名称表达，沿用现有开发者模式显隐。

## 文件与图片阅读

对话中的图片附件和交付图片使用固定尺寸缩略图，裁切填充、圆角和轻阴影，不带文件卡边框、底板、文件名、大小或操作栏；文件信息与下载放在单击打开的大预览里。其他文件保留类型图标和文件卡。缩略图按阅读区域延迟读取，加载失败或到期时保留必要的原因与恢复入口，不以文件图标冒充图片预览。

助手消息中的文件路径链接按消息发生时已交付的附件关联下载，旧回复不关联后来产生的新版；未交付或无法明确匹配的沙箱路径显示为文字。普通网页链接保留原行为，HTML 查看复用交付卡的隔离预览。

文件卡片和文件行整体承担打开查看的主操作，图标、名称、大小及空白区域均可单击打开；下载等操作使用同级按钮，不触发预览。对话文件直接打开大预览，工作台文件在当前区域打开，预览标题可点击展开；HTML 文件单击交给系统浏览器渲染，不先下载。不支持的类型仍有明确的元数据和下载入口；短状态说明当前对象的读取、到期或部分预览结果。对话、交付和工作台共用预览能力，不把工具回执展示成文件正文。

工作簿提供工作表、行列导航及放大查看，保留文件关键格式；纸面颜色独立于界面主题，避免深色主题改变源文件颜色的含义。图片与浏览器截图共用适应窗口、缩放、原始尺寸、拖动和下载；适应窗口和原始尺寸使用不同图标及明确提示。关闭大预览回到原对象和阅读位置；主动打开文件固定当前查看对象，回到最新恢复自动跟随。格式边界见[产品说明](../../docs/product.md#文件预览)，具体预算见[运行参数与限额](../../docs/limits.md)。正常界面不展开技术说明。

## 草稿、弹层与视图连续性

设置入口打开覆盖应用的弹层，底层会话保持挂载，关闭后回到原页面与输入草稿。点击遮罩不关闭；关闭按钮和 Escape 共用未保存提醒，弹层使用统一焦点管理。直接访问 /settings 展示同一设置内容的独立页面，关闭返回首页。分区切换保留各自草稿，逐模型保存不覆盖其他模型草稿。模型提供商页只读展示模型连接：配置文件路径、缺失或格式问题、各提供商的地址、协议、可用模型与密钥掩码，以及“打开配置文件”和“重新读取”；界面不编辑地址或密钥，配置文件变化后逐模型参数列表随之刷新。

新对话沿用本机最近确认的模型与思考强度，恢复时按模型目录核对有效性，本地记录读完前不采用目录默认值；已有会话优先其服务端选择。仅浏览旧对话不更新最近偏好，菜单确认或发送成功才成对记忆，正在执行的运行仍使用冻结配置。模型菜单打开后先编辑草稿，关闭时提交一次；未改变则直接关闭，保存失败保持菜单与原因。列表来自后端目录，全部模型按厂商分组同时列出，组标题带单色厂商标志，触发器在模型名前显示同一标志；思考控件跟随选中模型。模型行为单行的模型名加上下文窗口，输出上限在悬停提示中，不显示“支持看图”标记，也不写目录之外的评价。菜单只展示模型与思考选项，不展示内部端点或运行配置对照。换模型、开关思考、默认档位提示与保存失败都不改变菜单高度：思考区只有标题行与档位控件，标题旁显示当前档的中文短名，改用默认档、保存中与保存失败写在标题行右侧，不另起说明行；不能关闭思考的模型开关置灰保留。有序档位用胶囊轨道滑块，只含开启档，填充到当前档、刻度在轨道内、白色圆形拖柄压在轨道上，点按、拖动与方向键切换，原始档位词留在刻度提示中；无序档位用列表选择。语义不兼容时明确说明改用了该模型的默认档位。活动运行保持冻结配置，当前预算改变不重写旧请求的占用口径。

对话靠近底部时跟随新增内容；离开此区域停止跟随，消息区底部显示向下箭头按钮，点击滚到底部并恢复跟随。

会话使用“聊天／日志”分段按钮切换，采用横向翻页，减少动态效果时关闭过渡。聊天与日志保留各自滚动位置，以及日志筛选、分页和原文展开；日志模式隐藏底部输入区，切回聊天恢复已有草稿，组件不因切换重新挂载。工作台跟随与手动固定是明确的查看模式，可返回最新。窄屏侧栏和工作台使用抽屉，关闭后回到原阅读位置。列表分页、会话切换和迟到请求依据当前上下文处理，旧结果不覆盖新页面。

## 组件状态清单

以下列出修改组件时需要核对的状态，保留会影响行为和回归的差异；不逐项规定图标、像素和短文案，也不表示全部状态都有真实窗口验收。数据形状与实现入口统一见[代码地图](../../docs/code-map.md)。

| 组件或区域 | 应核对的状态与约束 |
|---|---|
| 运行与终态 | 空闲、执行、资源准备、等待回复、等待批准、停止中、完成、失败、已停止、已中断；当前原因只在主要位置表达 |
| 计划 | 无计划、新运行未写计划、承接准备执行、顶层计数、简短标题与描述、内部记录不挤占清单、当前和后续安排、受阻及部分交付、全完成、计划模式待确认；稳定身份、刷新和历史选择；按计划执行有效性 |
| 工具卡与工具组 | 执行中、成功、失败、被拒绝、未执行、取消、结果截断、长参数；组内部分完成或含失败；工作台选中 |
| 消息与回复 | 普通消息、附件、运行中补充、旁白、短/长回复、代码和表格；文本增量被完整消息替换或在终态移除 |
| 提问与审批 | 等待/已回复；待审批、提交中、已批准、已拒绝、已失效，重复提交不可导致重复执行 |
| 交付 | 单文件、多文件、预览不可用、附件下载失败 |
| 工作台与终端 | 初始关闭、跟随最新、固定查看、回到最新、长输出、暂时读取失败、恢复读取及窄屏抽屉 |
| 浏览器与截图 | 文本/URL、动作失败、动作成功但观察失败、引用过期、图片加载失败/已过期、大图适应窗口/原始尺寸 |
| 开发者视图 | 事件/轮次/压缩、筛选与清除、分页、空结果、原文开合、请求读取失败、摘要原文/Markdown、持久记录导出 |
| 上下文环 | 无数据、正常、接近阈值、压缩中、压缩后估算、预算已变；最近请求与累计用量分开，弹层打开不叠提示 |
| 输入与命令 | 草稿、附件、计划模式、手动压缩、斜杠筛选、不可用原因、中文组合输入、发送失败与受理读回 |
| 标题与列表 | 临时/自动/手动标题、AI 建议待保存、改名失败、长标题、等待原因已知或未知；未知不伪造等待类型 |
| 工作区列表与入口 | 读取中、空、读取失败可重试；可用、不可用、已归档以文字加色点表达；非桌面环境禁用“打开文件夹”并说明原因，仍可新建 |
| 打开与冲突 | 取消选择无提示；认回已有工作区只用轻提示；复制文件夹的冲突对话框并列说明“作为新工作区”与“改绑到这里”各自后果；扫描摘要一次性显示 |
| 重新定位 | 桌面窗口内可用；进行中禁用并改字；取消无提示；成功后横幅消失、树换成新位置；失败按原因各有说明（已绑定、标记属于他处、写入占用、运行中、版本不符、目标不可用、授权失效） |
| 工作区页与状态横幅 | 读取中、不存在、读取失败、正在删除；文件夹不可用（带核心给出的原因、重新检查、重新定位，对话仍可发送）、已归档（只读、输入框换成说明）；重命名、归档与版本冲突提示 |
| 文件夹面板 | 标题栏“在 Finder 中显示”只在桌面窗口、有可显示目标时出现；读取中、空文件夹、目录读取失败可重试、目录过大截断、符号链接与特殊文件不展开；键盘上下左右展开收起；预览中返回；添加文件的目标说明、进行中、同名另存提示、部分失败；归档与不可用时不可添加；拖放高亮；“本次成果”空与有、交付版本与文件夹当前版本区分；窄屏抽屉 |
| 外部变更与撤销 | 外部变更合并后只刷新受影响目录；预览中的文件被改动时在预览上方提示“重新载入”，不自动替换；文件夹失联与恢复立即反映在横幅与面板；运行结束条在有可撤销修改时给出“撤销本次修改”，进行中、归档、不可用或无净变化时不出现；撤销对话框区分可直接撤销、已是运行前状态、冲突（默认不勾、说明原因、只有允许时才有“仍要覆盖”）、二进制与过大文件只说明大小、提交后逐项结果与再次覆盖、明确只恢复文件不改变对话；文件夹面板的“最近修改”页仅在有记录时出现，运行与撤销操作分别标注，撤销操作可撤回 |
| 写入占用 | 别的对话或文件夹自己的写入占用时用横幅说明占用者并可跳转，自己的正常写入不提示；停止中、停止后未确认（“重试收尾”）各有文案；添加文件与撤销被占用时显示占用者 |
| 右侧面板切换 | 工作区会话右侧在“文件夹”与“工作台/查看”间切换，两块都保持挂载；点工具卡片切到工作台并选中该工具；窄屏抽屉里同样可切换 |
| 工作区删除进度 | 清理中（带阶段与计数）、失败可重试与关闭、完成提示；不随页面切换消失；确认框写明文件夹不受影响 |
| 设置与模型 | 分区草稿、即时校验、保存/撤销、保存失败、未保存关闭、目录失败、有序/无序档位、默认回退及活动运行冻结 |
| 通用可访问性 | 可访问名称、焦点和键盘、长内容、浅深主题、窄屏、减少动态效果；状态同时有文字含义 |

## 组件检查

开发环境的 `/dev/components` 用实际视图模型夹具展示运行、计划、工具、审批、交付、上下文和设置等状态；合成数据明确标注，不替代真实服务验收。生产环境该路由返回 404。

修改组件时按实际影响核对正常、等待、失败、恢复、长内容、键盘和窄屏状态。自动检查及其边界见 [UI 指南](README.md#检查与构建)。
