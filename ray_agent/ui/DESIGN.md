# RayAgent 界面设计说明

本文记录已经落地的设计 token、运行视图组件与设置页约定。会话页、工作台、开发者视图和首页已在 W5 阶段二落地；后续界面微调也记在这里。方案来源是 [W5 子计划](../../docs/plan/w5-ux.md)；颜色与字体的取值以 [globals.css](src/app/globals.css) 为准。

阶段一实现过程中的对照修改没有另存记录。下面按已落地的样式与组件整理，不补写当时没有留下的自审条目。

## 原则

- 给操作者长时间使用的专业工具。信息密度和可扫读优先，没有营销式首屏。
- 记忆点只放在运行视图：状态条、计划条和工具流。设置页与其余区域保持安静。
- 界面只展示视图模型里已有的数据。没有运行时状态条显示“空闲”；用量没有数据时上下文环显示不可用，不估算一个百分比。
- 文案用用户能执行的动词（“读取文件”“运行命令”“交付文件”）。模型看到的工具名只在展开详情里出现。
- 错误写发生了什么、接下来可以做什么，不道歉。

## 颜色

浅色采用接近白色的中性纸面，侧栏只比主画布深一档；钴蓝 `signal` 仍只负责交互强调。深色保留石墨层次。状态色语义固定，亮暗各一套；文字色与浅底色成对使用（`text-state-*` 与 `bg-state-*-soft`）。

| 语义 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| 画布 `background` | 页面底 | `#fafbfc` | `#171a1e` |
| 侧栏 `sidebar` | 导航底面 | `#f6f7f8` | `#1b1e23` |
| 内容面 `card` | 卡片、状态条 | `#ffffff` | `#1e2227` |
| 墨色 `foreground` | 正文 | `#14181d` | `#e6e9ed` |
| 次级 `muted-foreground` | 说明、标签 | `#56606b` | `#a3acb6` |
| 更弱 `faint` | 占位、无计划说明 | `#606973` | `#8a939d` |
| 强调 `signal` | 正在运行、当前项、链接、焦点环 | `#2549c4` | `#8fa8ff` |
| 弱底 `muted` | 次级控件与代码背景 | `#f0f2f4` | `#262b31` |
| 侧栏选中 `sidebar-accent` | 当前会话、悬停 | `#edf0f2` | `#2a3037` |
| 边界 `border` | 面与面之间 | `#e2e7ea` | `#343a42` |
| 运行中 | 与 signal 相同 | `#2549c4` / `#e6ecfb` | `#8fa8ff` / `#233056` |
| 等待 | 等回复、等审批、未保存标记 | `#8a5300` / `#fbf0dc` | `#f0b35a` / `#3a2e1a` |
| 成功 | 完成、已连接 | `#1c7340` / `#e2f3e8` | `#6bcb8f` / `#1d3527` |
| 失败 | 失败、校验错误 | `#b42318` / `#fce8e6` | `#ff8f85` / `#3d2222` |
| 已停止 | 停止中、已停止、被拒绝、已取消 | `#56606b` / `#eceff2` | `#a3acb6` / `#2a3037` |
| 已中断 | 服务重启等中断 | `#8a3a8f` / `#f5e6f5` | `#e09ce4` / `#3a2440` |

深色不是纯黑。面与面靠明度台阶区分：画布、侧栏、卡片、弹出层逐级抬高。状态色在深色里整体提亮，浅底降低明度，避免浅色那套直接反色后对比不足。

业务组件使用上表 token，例如 `bg-background`、`text-muted-foreground`、`text-state-running`、`bg-signal`。不要在新界面里写 `gray-*` 或十六进制颜色。终端输出使用 `terminal` / `terminal-foreground`，不跟正文底色混用。

## 品牌标记

标记是一条构成 `R` 的执行路径，末段使用 `signal` 色表示从当前回路进入下一步；没有机器人、齿轮或装饰性光效。界面组件在 `src/components/brand-mark.tsx`，与文字 RayAgent 一起出现在侧栏，首页任务入口只放小尺寸标记。浏览器标签使用同形的 `public/brand-mark.svg`；旧的手势 PNG 已移除。深色界面的标记跟随文字和 `signal` token，标签图标则始终使用与画布相同的淡白底 `#fafbfc`，以保持小尺寸辨认度。

## 字体

西文与数字用 IBM Plex Sans（可变字重），中文依次回落到苹方、冬青黑体、微软雅黑、思源黑体和系统无衬线。命令、路径和代码用 IBM Plex Mono，中文等宽回落同样带系统中文字体。

正文 14px、字重 500、行高 1.6。辅助信息用 `text-meta`（13px / 20px）。计时、轮次、token、字节数和表格数字加 `tabular-nums`。根布局在 `src/app/layout.tsx` 引入这两套字体。

## 间距、圆角与密度

间距沿用 Tailwind 的 4px 网格，没有另设间距 token。常用节奏：时间线条目 `gap-3`，状态条内边距 `px-4 py-2`、最低高度 3rem，设置页内容区 `px-5`（中等宽度起 `px-8`），目录页内容区 `px-6`。

圆角以 `--radius: 0.5rem`（8px）为基准，`rounded-sm` 到 `rounded-4xl` 在此之上加减。工具行、输入和卡片用 `rounded-md` 或 `rounded-lg`，不使用大圆角胶囊作为主容器。

侧栏宽度 288px。设置页在容器宽度达到约 48rem 时，左侧为 11rem 的分区导航，更窄时改为顶部横向标签。窄屏目标是可读可操作，不另做移动端布局。

## 主题

`next-themes` 挂在根布局，`attribute="class"`，默认跟随系统，也可选浅色或深色。选择保存在浏览器本地。主题选择位于设置页的“外观”分区；组件状态目录页的页头另有测试用切换控件。切换时关闭主题过渡，避免整页闪色。

`globals.css` 用 `@custom-variant dark (&:is(.dark *))`，因此深色样式挂在带 `.dark` 的祖先下。`html.dark` 同时设置 `color-scheme: dark`，让滚动条和表单控件跟随。

## 动效

运行状态行不使用持续扫光，停止按钮在停止中改为旋转指示。开发者视图的事件原文与轮次请求面板在展开和收起时使用 200 ms 的高度与透明度过渡，轮次箭头同步旋转。桌面工作台的宽度和主区随打开、收起操作在 220 ms 内过渡；窄屏抽屉使用同样时长。

`prefers-reduced-motion: reduce` 时动画和过渡时长压到几乎为零。

## 布局

左侧会话列表，中间是按状态显示的轻量运行行、时间线、计划条和输入框，右侧是可收起的工作台（结果、终端、浏览器、文件）。开发者视图与对话在同一位置切换，不另开路由。窄屏（约 768px 以下）时，会话列表用侧栏原有的抽屉，工作台改为右侧抽屉。进入任何会话时工作台默认关闭，顶部入口或时间线工具操作可打开。

会话页在 `components/session-detail-view.tsx`，消费 `useSessionDetail` 的 `view`。工作台在 `components/workbench/workbench.tsx`，开发者视图在 `components/developer/developer-view.tsx`。首页把任务输入置于主区中央，最近会话只在侧栏。组件状态目录仍用夹具，不接真实会话。

侧栏顶部保留 RayAgent 入口与折叠控件，新建任务在其下，设置入口在底部；折叠后保留对应图标。侧栏会话标题固定单行，超出宽度时视觉截断；完整内容可在标题提示和重命名对话框中查看。未选中的会话只显示标题和时间；选中时左侧强调条使用当前状态的语义色，选中背景仍为中性色。悬停或聚焦时显示状态名称，键盘和读屏也能取得名称。会话顶部标题旁有常驻编辑按钮，可使用同一重命名对话框；绑定了项目时同栏显示项目名与当前分支（分支随变更页刷新更新，不可用时显示原因）。运行中与等待时只显示轻量状态、当前动作、用时和停止入口；计划模式运行额外显示“计划模式”标记。完成与停止后状态行收起，标题旁保留低调的终态文字；失败与中断保留原因。顶部不显示累计 tokens 或速度，底部上下文环明确指最近一次模型请求。工作台打开时只在右侧面板保留标题，顶部只在关闭时显示打开入口；搜索、MCP、远程 Agent、计划等工具落在“结果”页，不进入终端页；会话已绑定且项目可用时出现「项目」「变更」页签，不参与按工具家族自动切换。开发者视图页头用紧凑的事件类型菜单与“导出 JSON”操作；事件类型显示中文，原始类型可在菜单及表格悬停提示中查看。事件表格固定序号、时间、类型、运行与原文操作列的宽度，摘要占余下空间；窄屏在表格内横向滚动，短字段不折成竖排。`context` 事件按追加、清理推理字段、替换上下文分别命名，只有 `compact` 事件称为“上下文压缩”。事件原文和轮次请求都可再次点击收起；某轮请求紧跟该轮条目显示，切换轮次时不跳到列表底部。

**输入框命令：** 工具行 `+` 与行首 `/` 共用 [`lib/commands.ts`](src/lib/commands.ts) 注册表（菜单组件 [`input-command-menu.tsx`](src/components/input-command-menu.tsx)）。`/` 仅在开头或空白后触发，路径内的 `/` 不打开列表；输入法组合期间不响应。不可用命令仍列出并显示原因，高亮可读但 Enter 不执行。上传、Plan、压缩为固定三项；配置 `PROJECT_ROOTS` 后增加「选择项目」，未配置时不渲染选择器且命令列表不含该项。Plan 在输入框显示可移除的「计划模式」标记，发送时带 `mode: plan` 并在成功后清除。压缩调用 `sessionApi.compact`，进行中禁用发送。

**上下文环：** 悬停仍显示简短说明（自动压缩刻度与占用含义）。点击打开 Popover：已用与窗口、剩余、最近一轮、压缩水位、已压缩次数与最近触发；「立即压缩」与注册表里 `compact` 命令共用可用性判断。最近一次压缩晚于最近一轮 `turn(started)` 时，占用可标为压缩后估算。

**计划后续：** 最新运行为 `mode=plan` 且已完成、会话无活动运行时，时间线末尾（最终回复之后）显示 [`PlanExecuteBar`](src/components/run/run-end-bar.tsx)「按计划执行」，以普通模式发送固定文案。

**变更页：** 列表展示 Git 状态；选中条目后取单文件 diff。仅暂存改动时 `scope=staged`，否则 `scope=worktree`（暂存与工作区同时有改动时只展示工作区 diff，不做双栏并列）。

## 组件与状态

每个组件在开发模式的 `/dev/components` 列出下表状态。数据形状是 [W4 视图模型](../../docs/plan/w4-ui-data.md#视图模型契约)，夹具在 `src/fixtures/`。标“真实”的来自 W1 评测与走查事件；标“合成”的是这些事件里不会出现的状态。

| 组件 | 目录中的状态 |
|---|---|
| 运行状态条 | 空闲与已完成、已停止不占位；模型思考中、工具执行中、等待回复、等待审批、停止中显示轻量状态；失败、已中断保留原因 |
| 计划条 | 无计划、进行中（折叠与展开）、全部完成、运行结束时有未完成项、计划被修改（状态变化，以及新增与删除） |
| 工具卡 | 运行中、成功、失败、被拒绝、未执行、已取消、结果被截断、参数过长；另有在工作台中选中 |
| 工具组 | 部分完成、全部成功、含失败 |
| 旁白与最终回复 | 旁白、短文本、长文本与代码块、表格；另有 W6 增量渲染入口 |
| 用户消息 | 普通、带附件、补充要求 |
| 提问卡 | 等待回复、已回复 |
| 审批卡 | 待审批、提交中、已批准、已拒绝、已失效 |
| 交付卡 | 单文件、多文件、预览不可用 |
| 压缩提示 | 一次压缩 |
| 失败尝试提示 | 已重试、最终失败 |
| 终态条 | 失败、已停止、已中断 |
| 上下文环 | 无数据、正常、接近水位、已压缩；详情 Popover 与「立即压缩」 |
| 输入框命令 | Plan 标记、压缩不可用原因；`+` / `/` 与注册表一致 |
| 按计划执行 | 合成条（`PlanExecuteBar`） |
| 会话列表项 | 七种状态的选中条颜色、状态提示与可访问名称；未选中时只显示标题和时间，另有长标题 |
| 项目选择器 | 未选择、已选择、目录不可用（禁用）；PROJECT_ROOTS 关闭时不渲染 |
| 工作台项目页 | 空目录说明、文件预览（文本 / 二进制 / 过大）、项目不可用 |
| 工作台变更页 | 非 Git 仓库、无改动、列表与 diff、手动刷新 |

设置页另有 MCP、A2A 列表行和工具策略，同样列在目录页，便于回归分区外观。

## 设置页

路由 `/settings`。分区为通用、外观、模型提供商、MCP 服务器、远程 Agent 和工具策略。通用与模型表单使用同一套草稿：字段说明、即时校验、保存中、保存结果，以及未保存时离开页面的提示。切换分区不丢草稿。只调用现有设置接口。

外观分区只修改当前浏览器的主题；其余分区的保存方式见相应设置说明。

## W9–W11 待实现状态设计（2026-09-30）

本节是已确认方案的实现前状态目录；组件目录与真实浏览器核对尚未完成，不表示下表能力已落地。当前返工契约见 [执行入口](../../docs/plan/execution.md)。沿用本文 token：中性画布与石墨深色、钴蓝交互强调、IBM Plex 字体、细分隔和紧凑行高。

主路径为独立草稿 → 项目分区加号 → 打开/添加项目 → 工作区空白输入 → 项目内对话 → 点击项目名返回空白工作区 → 下一段项目内对话 → 关闭或归档。项目名称导航、项目子列表折叠、分区折叠和加号分别使用独立点击目标。

| 界面 | 主状态与异常 | 恢复与作用域 |
|---|---|---|
| 首页 | 空白独立草稿、创建中、创建失败、已有 session 首发失败、受理结果未知 | 按独立作用域保留文字/附件/计划模式；先读回再手动重试 |
| 项目选择器 | loading、读取失败、未配置、共享沙箱不支持、根失效、空目录、已有项目、添加中/失败 | 打开入口常驻；不可用原因可读；打开不建 session/沙箱 |
| 侧栏 | 项目与对话两分区、分区折叠、项目子列表折叠、空态、长列表、选中项不在最近五条 | 项目区独立滚动，对话区固定置底且限高；手动折叠不被刷新覆盖；收栏与窄屏保留固定语义入口 |
| 工作区 | 可用/不可用项目、最近对话、查看全部分页、空白输入、设置草稿、归档/恢复失败 | 项目名返回空白输入；关闭只离开；历史可读，目录不可用禁止启动 |
| 项目内对话 | 准备环境、执行、等待回复/审批、停止中、准备失败、受理结果未知、同项目被占用 | 追问保留 session；冲突指出占用对话；失败保留草稿；停止独立操作 |
| 无 session 工作台 | 文件/Git loading、error、empty、unavailable、选中路径消失、两段 diff、过大/二进制 | 项目级读取；刷新保留路径；切项目清旧数据；不虚构终端/浏览器 |
| 上下文入口 | 纯圆环、无数据、实测/估算/请求中/压缩后/旧配置/超限、压缩忙碌/失败/超时 | 悬停、聚焦、点击共用快照；弹层打开压制 Tooltip；读回操作状态与事件，不自动重压 |

布局自审：左栏负责归属导航，主区负责草稿和连续对话，右栏负责项目当前内容；无额外大卡片或装饰。项目/对话的加号与输入加号使用同一图标语言，但动作各自固定。完成实现后将本节已验证内容合入对应事实章节，移除过时设计描述。
