# RayAgent 界面设计说明

本文维护专业工具界面的设计原则和交互契约。具体颜色、字号、尺寸、图标与动效数值以 [globals.css](src/app/globals.css)及组件实现为准，不在文档复制。用户功能见[产品说明](../../docs/product.md)，数据与验证入口见 [UI 开发指南](README.md)。

## 设计原则

- 为持续操作和复杂任务提供可扫读的信息，界面保持安静，当前动作与阻塞原因优先。
- 只展示已有数据，缺失值给出不可用状态，估算、历史请求和实测值明确区分。
- 工具文案使用动作和结果；错误说明发生了什么以及可执行的下一步。
- 同一状态尽量在一个主要位置表达，避免标题、状态条和时间线重复播报。
- 重复行内动作可以用图标，提供可访问名称与提示；主要和不可逆动作使用清楚的文字。
- 界面只保留完成当前操作需要的短标签、状态和错误原因。设计解释、实现原理、长篇能力说明维护在文档，不放入正常操作流程；不可用状态给简短原因与下一步，不靠常驻说明教学。
- 主题、键盘焦点、窄屏与减少动态效果偏好作为组件状态的一部分处理。

## 视觉语义

| 语义 | 用途 |
|---|---|
| background / sidebar / card | 画布、导航与内容面，通过明度区分层次 |
| foreground / muted-foreground / faint | 正文、说明和更弱信息 |
| signal | 当前交互、选中、链接和焦点强调 |
| border / muted / sidebar-accent | 边界、次级底面及导航选择 |
| state-* 与 state-*-soft | 运行、等待、成功、失败、停止和中断的文字与弱底配对 |
| terminal / terminal-foreground | 终端区域，与正文底面区分 |

业务组件使用语义 token，不另写灰阶或固定十六进制颜色。浅色保持中性纸面，深色以明度阶梯区分区域；状态不只靠颜色表达。数字统计使用 `tabular-nums`，命令、路径和代码使用等宽字体。阅读字号选择保存在浏览器，字号变化不同时放大间距、图标和圆角。

品牌标记使用执行路径构成的 R，与主题和 signal 保持一致；导航及业务操作使用统一图标系统。局部图标替换和尺寸调整只修改实现。

## 页面与状态契约

| 区域 | 必须保持的行为 |
|---|---|
| 导航 | 独立对话和项目可切换，草稿与当前页面保留；分页之外的当前项可定位；旧请求不覆盖新页 |
| 会话 | 时间线承载过程，输入区域支持补充和回答；等待审批时引导处理审批，停止状态不冒充完成 |
| 计划 | 展示完整清单与变化；按计划执行需通过有效性判断，不能仅凭上次 plan 运行完成 |
| 工作台 | 进入会话默认关闭，操作入口打开；自动跟随新工具，手选后固定，可返回最新；窄屏使用抽屉 |
| 浏览器与截图 | 展示本次文本、URL、结果及显式图；图片加载失败或到期给明确说明，大图可适应窗口或查看原始尺寸 |
| 开发者视图 | 保留筛选、展开与滚动状态；区分事件、轮次和压缩；请求原文紧跟所选轮次，导出使用持久记录 |
| 上下文 | 区分最近请求、压缩估算、预算版本与累计用量；没有数据不伪造占用百分比 |
| 文件导入 | 扫描与审核后上传；筛选不改变上传集合；展示排除、敏感与覆盖确认；区分字节传输和已发布文件 |
| 项目占用 | 运行、等待、文件操作、恢复与收尾分别说明，冲突保留当前数据并提供所属对话入口 |
| 项目记忆 | 说明、笔记、摘要分别编辑；切换和离开保护脏草稿；冲突提供最新版本，不静默覆盖；历史取回先进入草稿 |
| 设置与模型 | 分区切换保留草稿；未保存退出需提醒；模型能力按目录表达，活动运行与下一运行设置分开 |

项目文件页支持加载、失败、空目录、预览不可用及下载状态；快照恢复失败保留修复入口。上传取消需等待在途文件确认，不把取消请求直接展示为所有文件已撤销。

主题由 `next-themes` 管理，默认跟随系统，选择保存在浏览器。深色用统一 token，不在组件再维护一套颜色。动效帮助说明状态切换与面板关系，减少动态效果时禁用或缩短；不以持续装饰动画表达运行。

## 状态表达与恢复路径

时间线承担当前动作与最终原因：模型请求、资源准备、停止和压缩各有明确状态；工具动作写在对应工具行。同一时刻不在标题、状态条和时间线重复解释。输入区用时与轮次支持过程观察，失败、停止和中断不借加载动画表达。失败原因与重试入口留在终态条；重新发送时切换到当前过程，发送失败则恢复原终态说明。

提问和审批明确说明在等谁做什么。审批卡在提交中禁用重复操作，结果留在同一张卡；已失效不能继续批准。等待审批期间输入引导批准、拒绝或停止。按钮可用性依据实际运行与调用状态，不能仅凭最后一条文本判断。

文件交付分别表达附件与项目持久副本。附件可下载、项目副本待存或失败是不同结果；失败提供补存入口，读取状态失败显示“未确认”。快照恢复未完成时保留只读访问与修复入口；清单为空但对象待回收时仍可重试。上传区分扫描、确认、字节传输、发布及部分失败，取消后等待在途文件确认。

终端读取失败保留已经取得的输出并提示，恢复连接后继续读取。工具动作成功但后续观察失败保留动作结果，补观察不能诱导重复写入。截图的加载失败、到期和不支持预览分别说明，关闭大预览返回原工作台。

## 开发者模式

设置中的开发者模式默认关闭，偏好保存在当前浏览器并同步同源标签页。普通模式显示进展、计划、可读业务结果、文件和页面内容，隐藏开发者切换、上下文用量、原始工具参数、技术计数、终端和连接编辑。失败、审批、停止、文件保护与执行权限保持可见。开发者模式恢复完整技术观察；关闭后回到对话，再开启保留已有筛选和阅读状态。显隐通过统一 hook 和区域策略工厂控制，调整展示不改变执行内核。

普通模式右侧称为“结果与资料”，“查看最新结果”只在存在可返回的新结果时出现。成功工具的重复状态行隐藏，失败说明保留；隐藏或关闭终端后停止输出轮询。设置存在未保存修改时不能关闭开发者模式，隐藏字段保留原值。网址只提供一个主链接，展开的过程标题不重复正文旁白。

## 文件与图片阅读

对话中的图片附件和交付图片使用固定 96×96 缩略图，裁切填充、圆角和轻阴影，不带文件卡边框、底板、文件名、大小或操作栏；文件信息与下载放在单击打开的大预览里。其他文件保留类型图标和文件卡。缩略图按阅读区域延迟读取，加载失败、到期或项目副本未保存时保留必要的原因与恢复入口，不以文件图标冒充图片预览。

文件卡片和文件行整体承担打开查看的主操作，图标、名称、大小及空白区域均可单击打开；下载和补存等操作使用同级按钮，不触发预览。对话文件直接打开大预览，工作台文件在当前区域打开，预览标题可点击展开。不支持的类型仍有明确的元数据和下载入口；短状态说明当前对象的读取、到期或部分预览结果。对话、交付和工作台共用预览能力，不把工具回执展示成文件正文。

工作簿提供工作表、行列导航及放大查看，保留文件关键格式；纸面颜色独立于界面主题，避免深色主题改变源文件颜色的含义。图片与浏览器截图共用适应窗口、缩放、原始尺寸、拖动和下载；适应窗口和原始尺寸使用不同图标及明确提示。关闭大预览回到原对象和阅读位置；主动打开文件固定当前查看对象，回到最新恢复自动跟随。资源预算与格式边界统一维护在能力文档，正常界面不展开技术说明。

## 草稿、弹层与视图连续性

设置入口打开覆盖应用的弹层，底层会话保持挂载，关闭后回到原页面与输入草稿。点击遮罩不关闭；关闭按钮和 Escape 共用未保存提醒，弹层使用统一焦点管理。直接访问 /settings 展示同一设置内容的独立页面，关闭返回首页。分区切换保留各自草稿，逐模型保存不覆盖其他模型草稿；连接配置单独保存。

模型菜单打开后先编辑草稿，关闭时提交一次；未改变则直接关闭，保存失败保持菜单与原因。仅有序多档采用离散滑块，厂商标签不是额外焦点，滑块承担键盘操作；语义不兼容时明确使用默认。活动运行展示冻结配置，当前预算改变不重写旧请求的占用口径。

项目记忆的说明、笔记与摘要分别编辑。切换分区、关闭或导航离开保护未保存内容；浏览修改记录与运行预览保留草稿。历史取回先进入笔记草稿。版本冲突提供最新内容供处理，不静默覆盖当前输入。摘要管理范围与运行注入范围分别表达，不把当前对话摘要显示为已纳入下一请求的其他对话材料。

对话与开发者视图在同一会话中切换，保留各自滚动位置，以及开发者筛选、分页和原文展开；不是切换一次就重建整个阅读状态。工作台跟随与手动固定是明确的查看模式，可返回最新。窄屏侧栏和工作台使用抽屉，关闭后回到原阅读位置。列表分页、项目切换和迟到请求依据当前上下文处理，旧结果不覆盖新页面。

## 组件状态清单

以下列出修改组件时需要核对的状态，保留会影响行为和回归的差异；不逐项规定图标、像素和短文案，也不表示全部状态都有真实浏览器验收。数据形状与实现入口统一见[代码地图](../../docs/code-map.md)。

| 组件或区域 | 应核对的状态与约束 |
|---|---|
| 运行与终态 | 空闲、执行、资源准备、等待回复、等待批准、停止中、完成、失败、已停止、已中断；当前原因只在主要位置表达 |
| 计划 | 无计划、展开/折叠、当前项、全部完成、结束仍有未完成项、清单修改/增删；按计划执行检查有效性 |
| 工具卡与工具组 | 执行中、成功、失败、被拒绝、未执行、取消、结果截断、长参数；组内部分完成或含失败；工作台选中 |
| 消息与回复 | 普通消息、附件、运行中补充、旁白、短/长回复、代码和表格；文本增量被完整消息替换或在终态移除 |
| 提问与审批 | 等待/已回复；待审批、提交中、已批准、已拒绝、已失效，重复提交不可导致重复执行 |
| 交付 | 单文件、多文件、预览不可用、附件下载失败、项目文件引用、副本待存/成功/失败/未确认及补存 |
| 工作台与终端 | 初始关闭、跟随最新、固定查看、回到最新、长输出、暂时读取失败、恢复读取及窄屏抽屉 |
| 浏览器与截图 | 文本/URL、动作失败、动作成功但观察失败、引用过期、图片加载失败/已过期、大图适应窗口/原始尺寸 |
| 开发者视图 | 事件/轮次/压缩、筛选与清除、分页、空结果、原文开合、请求读取失败、摘要原文/Markdown、持久记录导出 |
| 上下文环 | 无数据、正常、接近阈值、压缩中、压缩后估算、预算已变；最近请求与累计用量分开，弹层打开不叠提示 |
| 输入与命令 | 草稿、附件、计划模式、手动压缩、斜杠筛选、不可用原因、中文组合输入、发送失败与受理读回 |
| 标题与列表 | 临时/自动/手动标题、AI 建议待保存、改名失败、长标题、等待原因已知或未知；未知不伪造等待类型 |
| 项目导航 | 加载、失败、空列表、分页、当前项在分页外、归档/恢复、新建、迟到响应、打开项目尚无对话 |
| 导入审核树 | 层级/长路径、大小、排除项、敏感项、覆盖确认、节点详情、筛选、键盘、窄屏；筛选不改集合 |
| 上传 | 扫描、确认、传输、发布、成功项复用、部分失败、读回、取消后在途收敛；成功文件不冒充被撤销 |
| 项目文件 | 加载、错误、空目录、文本/二进制/过大预览、项目不可用、单文件/ZIP 下载 |
| 项目占用与快照 | 运行/等待/文件操作/环境收尾、保护降级、恢复失败、两种修复、归档清理和残留对象重试 |
| 项目记忆 | 空内容、阅读/编辑、保存中/失败、版本冲突、脏草稿、历史取回、摘要生成中/失败/过时、材料预览与固定快照 |
| 设置与模型 | 分区草稿、即时校验、保存/撤销、保存失败、未保存关闭、目录失败、有序/无序档位、默认回退及活动运行冻结 |
| 通用可访问性 | 可访问名称、焦点和键盘、长内容、浅深主题、窄屏、减少动态效果；状态同时有文字含义 |

## 组件检查

开发环境的 `/dev/components` 用实际视图模型夹具展示运行、计划、工具、审批、交付、上下文、导入和设置等状态；合成数据明确标注，不替代真实服务验收。生产环境该路由返回 404。

修改组件时按实际影响核对正常、等待、失败、恢复、长内容、键盘和窄屏状态。自动检查及其边界见 [UI 指南](README.md#检查与构建)；历史运行与界面证据见[关键验收](../../docs/plan/README.md#关键验收)。

## 更新规则

本文件只在设计规则或交互契约变化时更新。局部样式、图标、间距、动效参数与短文案以源码为准，不追加微调日志；用户流程变化更新产品说明，跨服务契约和资源路径变化更新架构及能力文档。
