# RayAgent V5 交互原型

V5 没有在 V1–V4 的结构上挪位置，而是先定一套交互与视觉规则，再把所有页面放进去。设计思路、视觉语言与组件规则见 [DESIGN.md](DESIGN.md)，本文只说明怎么打开、能试什么、边界在哪。

只修改 `prototype/`，不改 `ray_agent/ui` 与 `docs/plan`，也不推进实施状态。

## 打开

在仓库根目录运行：

```bash
python3 -m http.server 4177 --bind 127.0.0.1 --directory prototype
```

| 地址 | 内容 |
|---|---|
| [工作区对话](http://127.0.0.1:4177/v5/index.html#/ws/review/s1) | 已完成的任务：结论、表格、引用、交付、本次参考、撤销修改 |
| [运行中](http://127.0.0.1:4177/v5/index.html?state=running#/ws/review/s1) / [待批准](http://127.0.0.1:4177/v5/index.html?state=approval#/ws/review/s1) | 过程实时展开、计划清单、审批；批准后自动走到完成 |
| [工作区背景](http://127.0.0.1:4177/v5/index.html#/ws/review/context) | 工作方式与版本历史、Agent 建议、记忆冲突、常驻排序与拖拽钉住 |
| [知识](http://127.0.0.1:4177/v5/index.html#/ws/review/knowledge) | 检索与预览、引用到新任务；索引页的状态、暂停、排除与重试 |
| [工作区首页](http://127.0.0.1:4177/v5/index.html#/ws/review) | 在工作区里开始任务；[出差报销](http://127.0.0.1:4177/v5/index.html#/ws/expense) 演示找不到文件夹 |
| [独立对话](http://127.0.0.1:4177/v5/index.html#/chat/c1) | 不带文件夹、记忆与背景的对话 |
| [Skill](http://127.0.0.1:4177/v5/index.html#/skills) | 按来源筛选、启用与「每次带上」、同名冲突、包阅读器、添加 |
| [运行组件](http://127.0.0.1:4177/v5/index.html#/components) | 浏览器、语义检索、文字识别的安装、进度、失败与重试 |
| [设置](http://127.0.0.1:4177/v5/index.html#/settings) | 覆盖应用的弹层；轨道底部图标或 `⌘,` 也能打开 |

`?theme=dark` 打开深色。左下角深色条是评审工具，可切换运行状态、模拟拖入文件、切换深浅，不属于产品界面。

## 可以试的操作

| 区域 | 操作 |
|---|---|
| 外层框架 | 轨道切换与悬停提示；`⌘N` 新对话、`⌘\` 收起列表；顶栏图标组切换视图；拖动右侧面板左缘调整宽度 |
| 对话 | 点步骤在右侧「查看」；悬停或点击引用角标；展开「本次参考」；「记住了 2 条」逐条撤回；「撤销修改」打开逐文件撤销 |
| 输入框 | 输入 `/` 打开命令与 Skill，方向键与回车选择；点模型名切换模型与思考档位（可拖动滑块）；运行中点计划条展开清单 |
| 上传 | 从桌面拖入文件，或用评审条模拟；选择「随消息发送」或「只加入文件夹」并选目录 |
| 背景 | 接受、改一下再接受或忽略 Agent 建议；打开版本历史并以旧版本另存；处理记忆冲突；拖动记忆到「钉住」 |
| 知识 | 输入关键词、切换范围、选结果看原文、引用到新任务；索引页暂停、排除目录、重新纳入、重试 |
| Skill | 筛选来源、处理同名冲突、启停与「每次带上」、打开详情切换渲染与源码、从 GitHub 添加 |
| 设置 | 改工具策略后出现保存条，未保存时不能关闭；切换主题与阅读字号；数据管理里的清空需要输入确认短语 |
| 窄窗口 | 把窗口缩到 1100 以下：列表变为抽屉、右侧面板变为浮层且默认收起 |

## 边界

- 静态原型，不连接核心、模型、真实文件系统、索引或组件下载。上传阶段、索引、安装进度、撤销结果都是定时模拟；真实拖入文件只读取文件名。
- 检索是内存里的关键词匹配，结果固定；不表示语义检索或 OCR 的真实效果。
- 发送只给出提示，不产生新回复；计划历史清单、Skill 正文编辑、MCP／远程 Agent 的连接编辑只有入口。
- 厂商标志是占位几何图形，实施时使用产品现有的厂商图标。
- 窄窗口按桌面最小宽度 960 设计，不包含移动端。

| 文件 | 内容 |
|---|---|
| `index.html` | 外层框架与评审条 |

| `icons.js` | 线描图标、文件类型字标、工作区文件夹标记 |
| `data.js` | 对话、记忆、计划、模型、斜杠命令等示例数据 |

| `app.js` | 路由、外层框架、对话、背景页与通用交互（拖拽、磁吸、FLIP、浮层、提示） |
| `DESIGN.md` | 设计思路、风格与组件规则 |
