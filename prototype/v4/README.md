# RayAgent 工作区交互原型

沿用 V1 的中性底色、钴蓝强调、字体和简短执行过程，补齐工作区结构与后续能力的操作路径。本稿仅修改 `prototype/`，不推进 `docs/plan` 的产品实施，也不修改 `ray_agent/ui`。P4–P8 新增能力均为静态模拟。

## 导航与工作区

左栏同时容纳独立对话与工作区。工作区名称和箭头只展开／收起；子项「工作区概览」与具体会话负责导航。工作区分组标题的加号统一打开添加窗口，选择新建文件夹或使用已有文件夹；每个工作区行右侧的加号只新建该工作区的对话，不再有底部新对话行。更多菜单提供设置、重命名、归档和删除。

全局「工作区首页」呈现工作区卡片。进入一个工作区后，顶部持续保留四个视图：

| 视图 | 内容与可操作路径 |
|---|---|
| 概览 | 直接输入任务、继续最近会话、查看最近成果、进入待处理背景与材料 |
| 对话 | V1 简短过程和可展开细节、审批、引用、交付与撤销；工作区标题下单独显示会话标题 |
| 背景 | 工作方式版本与编辑、Agent 修改提议的差异和来源、自动积累开关、记忆的来源、编辑、置顶、确认、撤回与恢复 |
| 知识 | 当前工作区的文件／记忆／会话摘要搜索、来源预览、引用到消息，以及索引状态与范围 |

切换视图保留当前会话、不同输入区的草稿与阅读位置；搜索词和筛选按工作区保存。背景和知识默认使用主内容区，需要读原文时再显示右侧预览。

## P5–P8 的评审路径

| 计划 | 可试用的原型路径 |
|---|---|
| P5 工作方式与记忆 | 背景中编辑工作方式，或接受／忽略 Agent 提议；处理候选更新、编辑和撤回记忆后使用提示撤销；会话回复的「本次参考」读取运行时保存的工作方式、记忆与 Skill 版本 |
| P6 知识与引用 | 知识中搜索「教育」，打开 PDF 引用页，返回后引用到下一条消息；筛选表格可见单元格范围；索引页区分已登记、处理中、可检索、过时、失败与待组件，可暂停、取消、重试和排除目录 |
| P7 本机组件 | 从扫描合同的组件图标进入全局组件页；模拟下载、校验与就绪，材料再经历文字识别、索引和可检索；语义组件缺失时保留全文搜索；浏览器共用组件入口，但属于 P4 执行规划 |
| P8 多来源 Skill | Skills 中搜索、按范围筛选、查看 `.agents/skills`、`.codex/skills`、`.claude/skills`、应用管理、内置和 GitHub 来源；处理同范围同名冲突；读包目录、Markdown、源码和参考文件；应用管理包可编辑为新版本，外部目录只读引用；输入框 `/` 打开同一选择器，发送后可读回所选版本 |

置顶只影响记忆列表顺序，不等于常驻。自动新增示例直接生效，修改已确认内容的示例需要用户接受；接受更新后替代旧记忆。工作方式修改用于下一次运行，历史运行保存各自的背景与 Skill 正文。停用或移除 Skill 来源引用不删除外部文件。

## 材料与图标

右侧材料栏提供文件夹、本次成果和最近修改。PDF、Word、表格、演示、Markdown、文本、图片、代码、压缩包、未知文件与文件夹共用一组自绘 SVG 图标。添加、索引、刷新、来源、编辑、置顶、放大和系统位置等重复操作使用有名称与提示的图标按钮，主要和不可逆动作保留文字。

文件夹当前版本、引用版本、交付版本分别标注；预览支持放大、返回与收起。示例会话保留引用原文与交付文件入口；撤销只恢复选中的文件，外部修改冲突需要单独确认。文件夹失联、副本改绑、归档与占用通过评审场景演示。

## 打开与演示边界

在仓库根目录运行：

```bash
python3 -m http.server 4177 --bind 127.0.0.1 --directory prototype
```

打开 [概览](http://127.0.0.1:4177/v4/index.html#workspace/review)、[背景](http://127.0.0.1:4177/v4/index.html#workspace/review/background)、[知识](http://127.0.0.1:4177/v4/index.html#workspace/review/knowledge) 或 [成果会话](http://127.0.0.1:4177/v4/index.html#session/review-1)。底部深色条属于原型评审工具，提供运行、审批、失联、空态、组件和检索失败等场景，不属于产品界面。

- 不连接模型、核心、真实文件系统、原生文件选择器、索引、Shell 或自动化浏览器；添加、安装、写入、撤销和删除仅改变页面内的示例数据。
- 搜索使用内存关键词过滤，预览为固定内容样张；版本与状态只用于交互评审，不能推导实际解析、索引或版本存储能力。
- 新发送任务得到明确标注的原型占位回复，已有会话内容、运行状态和用量来自示例。
- 草稿使用原型专用的 sessionStorage；其他修改刷新重置。字体沿用 V1 的 Google Fonts 引用与中文系统回退。
- 支持窄窗口导航和材料抽屉，不展开移动端配对与桌面离线的完整设计。

`app.js` 保存基础夹具、对话与弹层机制；`workspace.js` 实现四视图、材料与 P5–P8 交互；`file-icons.svg` 为文件图标源；样式统一在 `styles.css`。
