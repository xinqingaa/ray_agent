# RayAgent · 工作室原型 v2

这是按已确认的方向单独做的一版静态原型：**工作区就是应用本身**，视觉走“工作室”而不是“聊天客户端”或“后台仪表盘”。它不连接本机核心，也不替代 `ray_agent/ui` 的实现。

## 这版想解决什么

- 打开应用先回到上次的工作区，而不是先看一张工作区卡片仪表盘。
- 工作区、对话、材料和“这里的工作方式”在同一个场所里；切换工作区不离开当前页面。
- 中间不是聊天气泡，而是一份可读的工作日志：你的要求、Agent 的结论、执行记录、计划和需要你决定的事，沿同一条时间线展开。
- 材料是一张可收起的托盘，按文件夹树组织；成果和普通材料有明确区别。
- 启动台（`⌘O`）是项目切换器，不是首页仪表盘；独立对话作为“散页”留在旁边，不混入工作区。
- 全屏预览、添加资料和“这里的工作方式”使用同一套纸面弹层，不在正常界面里展开长篇说明。

## 视觉语言

- **纸面、墨色、深绿**：暖灰纸 `#f2efe6`、墨色 `#1c1f1a`、深绿信号 `#2d5a4a`；状态色只在必要处出现。
- **衬线标题 + Plex UI**：工作区名、页面标题和 Agent 正文用宋体，控件与元信息用 IBM Plex / 苹方，路径与数字用等宽。
- **细线、留白、文件夹标签**：不用卡片网格、渐变和阴影堆层级；工作区用文件夹脊、当前项用左侧细线，执行记录是一条竖向的“工作脊柱”。
- **唯一持续动效**：运行中的状态点呼吸；其余只保留必要的状态切换与悬停。

## 查看

原型按桌面窗口设计，推荐在 1440×900 或更宽的窗口查看；窗口变窄时，对话目录和材料托盘会分别收成抽屉，底部的原型控制条仍然可用。

```bash
python3 -m http.server 4174 -d prototype/v2
```

打开 `http://127.0.0.1:4174/index.html`。

底部深色条是原型控制条，不是产品界面：

- `运行中 / 待决定 / 已完成 / 离线 / 新对话` 切换主工作区的状态；
- `启动台` 打开项目切换器；
- `预览成果` 打开 `对比表.xlsx` 的只读预览；
- `添加资料` 打开添加弹层；
- `夜间` 切换深色纸面；
- `隐藏` 收起控制条，右下角“原型”可恢复。

也可以直接用 URL 打开状态，便于截图或对照：

| URL | 内容 |
|---|---|
| `?state=running` | 主工作区运行中（默认） |
| `?state=approval` | 写入前等待确认；计划收成一行，审批块完整可见 |
| `?state=done` | 完成、成果、撤销入口和运行统计 |
| `?state=offline` | 文件夹失联；横幅、暂停的文件工具和上次读取状态 |
| `?state=empty` | 新对话的空工作区 |
| `?state=launchpad` | 启动台 |
| `?state=preview&file=对比表.xlsx` | 成果只读预览 |
| `?dialog=add` | 添加资料弹层 |
| `?state=style` | 工作方式与记忆（P5 规划） |
| `?theme=dark` | 夜间纸面 |
| `?workspace=course` / `expense` / `review` | 切到其他工作区 |

`⌘O` 打开启动台，`⌘K` 打开并聚焦搜索，`Esc` 关闭最上层弹层。

## 评审渲染图

`preview/` 是 1440×900 窗口的三张评审用渲染（工作区、启动台、等待确认），不是产品素材；方向确认后可删除。

## 能力标注与边界

- 原型使用静态夹具，不访问真实文件夹、核心、模型或文件选择器。
- “这里的工作方式 / 记忆”按 P5 规划展示，带 `P5 · 规划` 标记；扫描合同的“待 OCR”按 P7 规划展示，没有把它画成已实现能力。
- 发送消息只追加一条占位回复，用于检查输入后的排版；不会调用模型。
- “选择文件 / 选择文件夹”和 Finder 操作只给出原型提示。
- 这是 UI 方向样张，不是最终实现；在方向确认前不改 `ray_agent/ui` 和 `docs/plan`。

## 文件

- `index.html`：应用外壳、启动台、弹层容器；
- `styles.css`：纸面视觉、四栏骨架、材料树、预览和深色主题；
- `app.js`：夹具、状态切换、工作日志/材料/启动台渲染与交互；
- `assets/`：本地 Plex Sans 与 Plex Mono 字体；许可见 `assets/LICENSE-IBM-Plex.txt`。
