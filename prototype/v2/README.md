# RayAgent · 工作室原型 v2（目录版）

这是按已确认方向继续修改的静态原型：**工作区是应用的主场所，但导航必须是一份可读的目录**。它在 v2 的工作日志、时间线和弹框基础上，恢复了左侧工作区目录、独立对话一级分区，以及右侧完整的文件夹树；同时把 P5–P8 的界面真正放进了原型，而不只是一个规划标签。

## 这版改了什么

- **左栏从图标条改成目录**：所有工作区可见，当前工作区展开会话；课程笔记、出差报销、产品评审以可读的状态行保留，不再只靠悬停认图标。
- **独立对话恢复为一级分区**：和工作区分开，有自己的最近记录、入口和阅读模式；不读取工作区材料、工作方式或记忆。
- **右侧文件夹树完整展开/收起**：文件夹、空文件夹、文件状态和成果都在树里；成果仍与普通材料区分。
- **中栏保留 v2 的工作日志**：你的要求、Agent 结论、执行记录、计划、审批和交付沿同一条脊柱展开；审批仍然收成一行计划 + 完整决定块。
- **新增工作区视图**：`日志 / 背景（P5）/ 知识（P6）` 在标题下方切换。背景展示工作方式、常驻记忆、本次参考和会话摘要；知识展示搜索、索引状态、来源和引用。
- **P7 / P8 有了入口**：左栏底部 `Skills / 组件 / 设置`，以及应用右上角的设置与资源；Skills 显示本地 `.agents/skills`、`.codex/skills` 和 GitHub 来源；组件显示 OCR、Embedding、浏览器和解析队列。

## 视觉语言

- **纸面、墨色、深绿**：暖灰纸 `#f2efe6`、墨色 `#1c1f1a`、深绿信号 `#2d5a4a`；状态色只在必要处出现。
- **默认系统字体**：统一使用系统无衬线（`-apple-system` / PingFang SC），工作区名、页面标题、Agent 正文、路径和时间都在同一套字体里；层级靠字号、字重和留白，不再混用宋体与等宽字体。
- **细线、留白、文件夹脊**：不用卡片网格和渐变；工作区只用文件夹脊和当前底色，会话只用底色和状态点，选中态不再叠加额外左侧边框。执行记录保留一条竖向的工作脊柱。
- **唯一持续动效**：运行中的状态点呼吸；其余只保留必要的状态切换与悬停。

## 查看

原型按桌面窗口设计，推荐在 1440×900 或更宽的窗口查看；窗口变窄时，工作区目录和材料托盘分别收成抽屉，中栏优先。

```bash
python3 -m http.server 4174 -d prototype/v2
```

打开 `http://127.0.0.1:4174/index.html`。

底部深色条是原型控制条，不是产品界面：

- `运行中 / 待决定 / 已完成 / 离线 / 新对话` 切换主工作区的状态；
- `启动台` 打开全局搜索与总览；
- `预览成果` 打开 `对比表.xlsx` 的只读预览；
- `添加资料` 打开添加弹层；
- `夜间` 切换深色纸面；
- `隐藏` 收起控制条，右下角“原型”可恢复。

`⌘O` 打开启动台，`⌘K` 打开并聚焦搜索，`Esc` 关闭最上层弹层。左栏目录是主入口，启动台不再是切换工作区的唯一方式。

## P5–P8 在哪里

| 阶段 | 入口 | 内容 |
|---|---|---|
| **P5 工作方式与记忆** | 工作区标题下 `背景` 视图；工作方式卡片的“编辑”仍打开原有弹层 | 工作方式、常驻记忆、来源与撤回入口、本次参考、会话摘要、上下文摘要 |
| **P6 全文知识** | 工作区标题下 `知识` 视图 | 文件/记忆/摘要统一搜索、来源与页码、引用到对话、索引状态 |
| **P7 OCR 与语义组件** | 左栏底部 `组件`；或 `设置与资源 → 组件` | OCR、Embedding、浏览器、文档索引状态与解析队列 |
| **P8 Skills** | 左栏底部 `Skills`；或 `设置与资源 → Skills` | 本地 `.agents/skills` / `.codex/skills`、GitHub 来源、启停、搜索、阅读器 |

P5、P6、P7 在界面里明确标注“规划中”；P8 区分“本地库已有实现”和“多来源发现按规划”。这些是信息结构原型，不代表已经接入真实机制。

## 状态 URL

| URL | 内容 |
|---|---|
| `?state=running` | 主工作区运行中（默认） |
| `?state=approval` | 写入前等待确认；计划收成一行，审批块完整可见 |
| `?state=done` | 完成、成果、撤销入口和运行统计 |
| `?state=offline` | 文件夹失联；横幅、暂停的文件工具和上次读取状态 |
| `?state=empty` | 新对话的空工作区 |
| `?state=launchpad` | 启动台 |
| `?view=background` | P5 工作区背景 |
| `?view=knowledge` | P6 知识搜索 |
| `?resources=skills` / `components` / `settings` | P8 / P7 / 设置与资源 |
| `?loose=meeting` | 打开一条独立对话 |
| `?state=preview&file=对比表.xlsx` | 成果只读预览 |
| `?dialog=add` | 添加资料弹层 |
| `?state=style` | 工作方式与记忆弹层 |
| `?theme=dark` | 夜间纸面 |
| `?workspace=course` / `expense` / `review` | 切到其他工作区 |

## 能力标注与边界

- 原型使用静态夹具，不访问真实文件夹、核心、模型或文件选择器。
- 发送消息只追加一条占位回复，用于检查输入后的排版；不会调用模型。
- “选择文件 / 选择文件夹”和 Finder 操作只给出原型提示。
- P5/P6/P7 的交互是设计展示；P8 的本地 skill 库对应已有实现，多来源发现、重名处理和包快照按规划展示。
- 这是 UI 方向样张，不是最终实现；在方向确认前不改 `ray_agent/ui` 和 `docs/plan`。
