# RayAgent · V3 整合原型

这是 V1 与 V2 的整合版：**以 V1 的壳和场景覆盖为主体，用 V2 的纸面与系统字体；V2 的工作日志、审批、文件夹树和 P5–P8 入口装进 V1 的结构里。**

V1、V2 都保留，仅作对照；这一版是当前整合稿。

## 这版怎么整合

| 区域 | 来自 V1 | 来自 V2 | V3 |
|---|---|---|---|
| 应用壳 | 全局侧栏：独立对话 + 工作区；工作区首页 | 纸面、系统字体、单一选中态 | V1 壳 + V2 视觉 |
| 首页 | 工作区卡片、文件数、索引状态、异常状态 | 状态语言、目录入口 | V1 卡片，纸面化；打开仍回上次工作区，首页从品牌/⌘H 进入 |
| 左栏 | 工作区与会话、独立对话 | 当前会话、运行状态、文件夹树入口 | 工作区在上、独立对话在下；每个工作区都可展开/收起，可同时展开多个 |
| 工作区中栏 | 对话、右侧材料、输入框 | 工作日志、计划、审批、运行统计 | V2 工作日志 + V1 的页头/材料栏关系 |
| 右侧材料 | 文件夹 / 本次成果 / 最近修改、拖入、扫描 | 完整文件夹树、成果、最近、弹层预览 | V1 tabs + V2 树、预览与状态 |
| P5–P8 | 待确认提议、记忆计数、解析中结果、组件安装进度、来源徽标 | 工作区 `背景 / 知识`，资源页 `Skills / 组件` | V2 的入口 + V1 的内容 |
| 弹框与状态 | 新建/删除/冲突/扫描/撤销/写入占用/索引中 | 统一纸面弹框 | V2 样式 + V1 覆盖 |

## 结构

- **打开即上次工作区**；首页通过左上角品牌、左栏 `工作区首页` 或 `⌘H` 进入。
- **左栏**：工作区在上，独立对话在下。每个工作区都有展开/收起按钮；可以同时展开多个工作区的会话，活动会话仍然只有一条。
- **工作区**：`日志 / 背景 P5 / 知识 P6` 三个视图；右侧材料有 `文件夹 / 本次成果 / 最近修改`。
- **P7 / P8**：左栏底部 `组件 / Skills`，或应用右上角设置与资源。
- **原型控制条**：状态按钮、`场景` 下拉、`弹框` 下拉；用来覆盖 V1 的状态和弹框。

## 查看

```bash
python3 -m http.server 4175 -d prototype/v3
```

打开 `http://127.0.0.1:4175/index.html`。

底部控制条：

- 状态：`运行中 / 待决定 / 已完成 / 离线 / 新对话`；
- 场景：`工作区 / 工作区首页 / 独立对话 / 空文件夹 / 文件夹失联 / 已归档 / 索引中 / 写入占用`；
- 弹框：`新建工作区 / 删除工作区 / 删除对话 / 副本冲突 / 扫描摘要 / 撤销修改 / 添加资料`；
- 其他：启动台、预览成果、添加资料、夜间、隐藏。

`⌘H` 工作区首页，`⌘O` 启动台，`⌘K` 搜索，`Esc` 关闭最上层。

### 状态 URL

| URL | 内容 |
|---|---|
| `?mode=home` | 工作区首页 |
| `?state=running` | 主工作区运行中（默认） |
| `?state=approval` | 等待确认 |
| `?state=done` | 完成与成果 |
| `?state=offline` | 文件夹失联（主工作区） |
| `?view=background` | P5 背景 |
| `?view=knowledge` | P6 知识 |
| `?resources=skills` / `components` / `settings` | P8 / P7 / 设置与资源 |
| `?loose=meeting` | 独立对话 |
| `?dialog=scan` / `undo` / `delete-ws` / `conflict` / `create` | 对应弹框 |
| `?workspace=course` / `expense` / `review` / `photos` | 切换工作区 |
| `?theme=dark` | 夜间纸面 |

## P5–P8 在哪里

- **P5 工作方式与记忆**：工作区 `背景` 视图。工作方式、待确认提议、记忆计数与列表、本次参考、会话摘要。
- **P6 全文知识**：工作区 `知识` 视图。统一搜索、来源、页码、引用、索引状态与解析中队列。
- **P7 OCR 与语义组件**：左栏底部 `组件` / 设置与资源 → 组件。OCR、Embedding、浏览器、语义索引和解析队列。
- **P8 Skills**：左栏底部 `Skills` / 设置与资源 → Skills。本地 `.agents/skills`、`.codex/skills`、GitHub、启停、搜索和阅读器。

P5/P6/P7 标注规划中；P8 区分本地已有实现与多来源规划。数据仍是静态夹具。

## 边界

- 静态原型，不连接核心、模型、真实文件选择器或索引。
- 移动端未在本版展开；V1 的移动场景暂时保留在原原型里。
- 没有把 P5–P8 的执行机制做成真实能力；它们只展示信息结构、状态和操作位置。
- 这是方向整合稿，不改 `ray_agent/ui` 和 `docs/plan`。

## 文件

- `index.html`：应用外壳、首页、启动台、设置与资源、弹层；
- `styles.css`：纸面视觉、目录、首页、材料栏、P5–P8、弹框和响应式；
- `app.js`：夹具、导航、工作日志、目录、P5–P8、弹框与场景切换。
