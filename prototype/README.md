# RayAgent 原型

这是桌面界面的定稿原型。[原型设计](DESIGN.md)记录采纳的导航、任务流程和视觉规则。

## 打开

在仓库根目录运行下列命令，然后[打开原型](http://127.0.0.1:4177/)。

```bash
python3 -m http.server 4177 --bind 127.0.0.1 --directory prototype
```

## 沿一次任务评审

1. 在[季度复盘首页](http://127.0.0.1:4177/#/ws/review)输入 `/`，用方向键选择命令，或按 Esc 关闭并保留输入。可以打开模型菜单，也可以用评审条模拟拖入文件，查看「随这条消息发给 Agent」和「只加入文件夹」两个落点。
2. 在评审条选择「运行中」，进入「整理竞品表」示例，展开输入框上方的计划清单。再选「待批准」，点击「批准这一次」，观察示例如何继续执行并显示最终回复。也可直接打开[待批准场景](http://127.0.0.1:4177/?state=approval#/ws/review/s1)。
3. 在完成的回复中展开「本次参考」，点击正文引用后打开原文，再打开交付文件「竞品对比表.xlsx」。用「撤销修改」查看可撤销的文件与冲突。
4. 从「设置 → 通用」开启开发者模式，回到会话右上角切换「聊天／日志」。可筛选事件、从模型事件跳到请求原文、从 Shell 步骤打开终端。回到聊天后点击输入框右侧的上下文圆环，或通过 `/` 模拟压缩，观察圆环与日志同步变化。

评审条可切换运行状态、拖入示例文件和切换主题。[深色预览](http://127.0.0.1:4177/?theme=dark)可直接打开。缩窄窗口可查看列表抽屉与右侧浮层。

## 专题入口

- [工作区背景](http://127.0.0.1:4177/#/ws/review/context)可试工作方式版本、Agent 建议、记忆冲突和拖拽钉住。[出差报销](http://127.0.0.1:4177/#/ws/expense)展示文件夹失联状态。
- [知识](http://127.0.0.1:4177/#/ws/review/knowledge)可试检索、引用到任务，以及索引暂停、排除目录和重试。
- [独立对话](http://127.0.0.1:4177/#/chat/c1)展示会议纪要与会话日志。[无请求记录的对话](http://127.0.0.1:4177/#/chat/c2)展示上下文用量未知的状态。
- [Skill](http://127.0.0.1:4177/#/skills)可改「竞品分析」的使用方式，回到季度复盘通过 `/` 核对可选项。「表格整理（用户）」用于体验纳入失败后的状态保留。
- [运行组件](http://127.0.0.1:4177/#/components)展示安装、失败与重试。[设置](http://127.0.0.1:4177/#/settings)可试工具策略的保存、撤销与未保存提醒。

## 演示边界

原型使用静态示例数据模拟审批、上传、索引、安装、撤销与开发者观察。检索在页面内匹配关键词，实际拖入的文件只读取名称。开发者模式偏好保存在当前浏览器，会话视图状态和 Skill 变更随页面刷新恢复示例数据。实施范围与验收方式见[原型落地计划](../docs/plan/prototype-ui.md)。
