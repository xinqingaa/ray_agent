# RayAgent 工作区原型

> 新版方向（工作区优先、工作室视觉）见 [`v2/`](v2/)；本目录保留第一版作对照，两者不混用。

这是依据 `docs/plan` 与现有 UI 机制整理的第一版静态 HTML 原型，入口为 [`ui/index.html`](ui/index.html)。原型只表达信息层级、状态和交互方向，不连接真实文件系统或索引服务。

## 这版定下来的风格

- 工作区是一级对象，工作区之间保持同级；当前工作区的会话只用留白和字号层级表达归属，不使用箭头或竖向树线，最多展示五条记录。
- 桌面首页是工作区仪表盘，优先显示名称、最近活动和文件夹／索引状态；完整路径只作为状态细节出现。
- 工作区内采用“会话／对话／材料”三栏。材料栏宽度足以承载文件名、解析状态和本次成果。
- 添加资料只有一个入口，位于材料栏标题；弹层只负责选择文件或目录，目标位置单独展示。拖入时整栏进入覆盖状态，不再铺一张上传卡片。
- 弹层按 shadcn 的 Dialog、Choice Card 和 Sheet 语义组织：标题、后果／说明、选择项、键盘提示和操作区分开。
- 移动端只展示桌面工作区、对话和审批语境，不提供打开本机目录的入口。

## 计划能力状态

- P5「工作方式与记忆」、P6「全文知识」、P7「OCR 与语义组件」目前按计划中的设计状态展示，标注为“已规划”，不代表源码已经实现。
- P8「Skills」沿用现有 `SkillsSection`、`SkillReader` 的信息结构，展示来源、启用状态、搜索和来源管理；它对应当前已有实现。

## 查看

```bash
python3 -m http.server 4173 -d prototype
```

打开 `http://127.0.0.1:4173/ui/index.html`。顶部控制条可以切换桌面／移动、工作区首页／工作区对话／文件状态，并打开扫描摘要、冲突、撤销和添加材料等状态。顶部“组件墙”用于查看侧栏行、材料行、横幅和弹层的独立状态。

原型中“打开文件夹”“选择文件”“选择目录”等按钮只关闭或展示选择意图，不会访问系统文件选择器，也不会上传或复制实际文件。
