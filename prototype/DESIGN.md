# RayAgent 原型设计

桌面界面围绕一次任务组织。用户从会话提交目标和材料，查看执行进展，在需要时补充要求或做决定，最后阅读结论、核对依据、取得成果。工作区把本地文件夹、工作方式、记忆与知识检索带进这条路径。界面需要同时适合两种阅读节奏：执行中的快速扫读，以及任务结束后的长篇阅读和核对。

本文记录采纳的界面方案。[试用说明](README.md)提供原型路线。[产品说明](../docs/product.md)与[正式 UI 设计说明](../ray_agent/ui/DESIGN.md)记录当前产品行为。实施范围与验收方式见[原型落地计划](../docs/plan/prototype-ui.md)。

## 设计原则

> **界面安静地承托任务；需要人做决定的地方才站出来。**

1. **层级用明度，不用线条。** 能用背景明暗和留白区分的，就不画分割线。
2. **卡片只给两类东西：需要你处理的，和可以拿走的。** 审批、Agent 建议、记忆冲突、交付文件、正在安装的组件是卡片；过程、记忆列表、文件树、搜索结果都是平铺的行。
3. **能力回到发生的地方。** 记忆在回复下方回流（「记住了 2 条」），检索结果以引用角标出现在正文里，Skill 以整段名称出现在输入框开头。独立页面只负责全局管理。
4. **动效回应操作。** 弹性、磁吸、拖拽、重排都由用户的动作触发，用来说明「什么变了、去了哪」。持续动画只留给正在执行的那一步。
5. **一个状态只在一个地方说。** 运行状态在时间线，等待原因在审批卡，索引进度在知识页；顶栏和标题不重复播报。

具体来说那么就是

1. **给任务留出视觉重心。** 画布、列表、纸面和浮层用明度、留白与轻重不同的边缘区分。打开任一视图，先能定位当前工作，再看到需要关注的信息。
2. **把能力放回使用它的地方。** 输入时选 Skill，阅读回答时看引用和「本次参考」，核对结果时打开文件或执行步骤。背景、知识、Skill 页面承担集中审阅和管理。
3. **用不同重量表达不同的操作。** 普通内容用正文或行。需要用户做决定、可直接打开的交付物、需要安装或重试的组件使用卡片。批准、拒绝、接受和清空等操作写出具体动作。
4. **每个状态有一个主位置。** 执行进展在时间线，等待原因在提问或审批卡，索引细节在知识页。导航可以用小点、计数或短标签提示去哪里处理，标题和导航保持可扫读。
5. **保持工作位置。** 看计划、原文或技术细节时，尽量保留原会话、输入和阅读位置。菜单就近出现，文件和执行结果在右侧打开，设置覆盖在当前页面上。

从开发者的角度来说就是
- 先定产品的原则
- 再去根据产品定位、能力等信息去确定产品的审美风格
- 依据上述信息去定义空间结构
- 定义视觉语言
- 定义动效与操作反馈
- 定义导航、顶栏与侧边
- 定义通用交互规范
...根据具体的产品动态规划后续任务

## 视觉语言

### 整体感觉

浅色像摊在暖灰桌面上的纸张。导航轨道清亮，列表文字直接落在画布上，正文纸面略提亮，边缘只有淡描边和轻投影。长回复靠稳定的阅读列、字重和段落间隔形成节奏。用户扫看时，最醒目的是当前选中的入口、需要回应的决定，以及可以打开的成果。

深色沿用同样的空间关系。画布最沉，正文纸面和轨道依次提亮，主动作和轨道选中块使用浅色实心形状。状态底色在深色中降低明度，文字保持可读。组件按用途共用主题色值，新增组件先选定它属于哪一层、哪类动作或哪种状态。

### 色彩与选中态

| 角色 | 使用规则 |
|---|---|
| 画布、轨道、纸面、次级底面 | 画布承载列表与透明顶栏。轨道有独立底色。纸面承载阅读和操作，次级底面用于用户消息、计划条、原文块等纸面内部区域。 |
| 正文、辅助文字、次要信息 | 正文用最清楚的文字色。路径、时间、版本和说明降低视觉重量，关键状态和下一步仍须看得清。 |
| 暮蓝强调色 | 用于全局新建、当前交互焦点、正文引用、进行中的信号。普通的确认动作采用随主题变化的中性实心按钮。 |
| 状态色 | 等待用琥珀，成功用绿，失败用红。需要解释原因或做决定时，配合同色弱底与简短文字。 |
| 类型与工作区标记 | 文件类型以字标和低饱和色辅助识别。工作区文件夹统一用中性色线描，两种形状只表示会话列表的展开与收起。 |

选中态按层级表达。全局轨道使用一个实心圆角块，列表用一层轻底色，视图组在画布上用半透明底面，在纸面上用提亮的小块。每处用一个清楚的选中信号。焦点环用强调色，键盘焦点和当前页面的选中状态可以同时辨认。深浅主题的具体色值和透明度以[原型样式](styles.css)为准。

### 字体、形状与图标

- **文字层级。** 中文和西文采用系统无衬线字体。页面标题标明主题，回复首段用稍大字号与字重带出结论，正文左对齐并限制行宽。阅读字号调整回复、用户消息、记忆和工作方式的文字，图标、间距与圆角沿用各自的尺度。计数、耗时和大小使用等宽数字，命令、路径、版本和原文使用等宽字体。
- **边缘与间距。** 行的圆角最小，主纸面和弹层更完整。常态列表行保持平整，悬停和选中才出现底色。分隔线留给确实需要表达关系的位置，例如轨道组别、工作区子项的归属和表格边界。临时浮层用更明显的阴影，便于识别它盖在哪一层上。
- **图标与文字。** 线描图标共用网格和笔画粗细，线端使用圆角。反复出现的预览、下载、钉住等短动作可使用图标，配有悬停提示与可访问名称。涉及提交、覆盖、拒绝的动作保留文字。

### 动效与操作反馈

颜色、透明度和悬停底色用短缓出过渡。涉及位置或尺寸变化时用轻微弹性，让用户跟得上元素移动或展开的过程。

| 变化 | 表达方式 |
|---|---|
| 导航或视图切换 | 轨道选中块移到目标入口。图标组选中项展开文字，以尺寸变化和淡入让用户跟上视图切换。 |
| 展开或收起 | 会话子列表、执行过程与「本次参考」在原位展开。计划清单从输入区上方浮出，保持时间线布局稳定。 |
| 拖拽和重排 | 文件拖入时先显示可放置区域。记忆拖到钉住区时提示落点，结束后让条目和常驻分界线按新顺序移动。主要动作的轻微磁吸用于指针靠近时的反馈。 |
| 行或卡片离开 | 处理完建议或撤回条目时，先让对应对象淡出，再由相邻内容补位。保留的行从原位置移到新位置，方便继续扫读。 |
| 处理中和等待 | 持续动效用于真正进行中的步骤、运行信号和组件处理。等待用户时改用静态提示。采用系统减少动态效果偏好时缩短过渡，并关闭磁吸。 |

## 导航、顶栏与侧边

### 全局轨道

全局轨道通高，收起列表后仍可访问。顶部固定「新建」，在工作区范围内从当前工作区发起任务，其他范围进入独立对话。中段分两组，第一组在「独立对话／工作区」之间切换，第二组进入「Skill／运行组件」。组间用一条短而淡的分隔线。主题与设置固定在底部。

当前入口共用一个沿轨道移动的圆角选中块。轨道靠图标导航，悬停提示比正文里的提示更早出现，并朝轨道右侧展开。每个入口同时提供可访问名称。工作区有需处理事项时，轨道上的小点只提示有事项，细节由背景视图承接。

### 左侧列表

列表是当前入口下的目录，表头放范围名称和对应的添加动作，内容区独立滚动。

| 当前入口 | 列表内容与行规则 |
|---|---|
| 独立对话 | 按时间归组，行首为会话标题，时间靠右，当前会话用轻底色定位。 |
| 工作区 | 工作区行放中性文件夹、名称和必要的状态文字。打开工作区进入其首页并显示子会话，在该首页再点工作区行可收起子列表。子会话缩进，以淡竖线标明所属。活跃与等待信号优先占用会话行尾的时间位置，具体原因在会话中展开。 |
| Skill | 按来源筛选，右侧附数量，同名冲突集中在待处理区。每个 Skill 的使用方式在主纸面管理。 |
| 运行组件 | 组件内容直接进入主纸面，列表整列让出。 |

列表收起或整列让出时，轨道与主纸面之间保留一道画布。窄窗口把列表改成按需打开的抽屉，选择会话或点到列表外可以回到主区。

### 透明顶栏

顶栏从左到右放**列表开关、位置面包屑、工作区视图组、右侧动作**。列表开关只在有列表的范围出现。面包屑在工作区会话中显示「工作区／会话」，工作区名称可返回其首页。独立对话和单页入口直接显示对应标题。

「对话／背景／知识」紧跟面包屑。它们切换同一工作区的内容，「对话」承载首页和已有会话，「背景」承载新任务的上下文准备，「知识」承载检索与索引。当前项展开文字，其他项保留图标与提示，背景待处理数跟在该项旁。宽度不足时优先省略长标题，给视图组和右侧动作留出空间。

顶栏文字和图标直接落在画布上。顶部负责位置、视图与辅助面板入口。新建留在轨道，发送留在输入框，运行原因留在时间线。会话的「聊天／日志」位于主纸面右上角，两项始终显示名称，和工作区视图组有清楚的位置区分。

### 主纸面与右侧面板

主纸面承载当前任务和阅读内容。工作区首页用居中输入框发起任务，最近对话、待处理背景与已有成果提供返回路径。进入已有会话后，输入移到纸面底部，时间线在输入框上方独立滚动。

右侧面板与主纸面在宽窗口中并排，可从左边缘调整宽度。工作区侧边包含「文件夹／成果／查看／修改」，独立对话保留会话相关内容。文件夹看当前目录，成果定位本次交付，查看承接选中步骤或原文，修改提供最近写入与撤销记录。

点击步骤后直接打开「查看」并定位对应结果。引用角标先展示短片段，选择打开原文后由右侧面板承接。窗口变窄时，右侧面板改用默认收起的浮层。开发者模式下浮层从会话切换入口下方展开。知识页在自己的内容区组织检索与结果预览。

## 通用交互规范

### 就近显示内容

菜单和简要说明贴近触发点，适合当场选择或快速核对。需要留在会话旁继续阅读的内容进入右侧面板。设置、版本历史和涉及多项决策的撤销使用对话框，保留底层页面作为返回位置。弹层的内容随筛选或选择变化时，稳定外框和主要控件的位置，新增的说明留在原区域。

文件行和交付卡的图标、名称及空白区域共同承载打开操作。下载、在 Finder 中显示等次级动作使用独立按钮，每次点击对应一个结果。

### 用布局说明规则

同类数据在同一列对齐，把对象、状态和对应操作放在固定的位置，便于逐行比较。索引列表可以沿状态列扫读，再到同一行重试或安装组件。需要解释顺序或边界时，直接用排列和分组表达。常驻记忆的分界线说明哪些条目会随新任务带上，「本次参考」按装配顺序陈列本次依据。

### 用键盘继续操作

图标按钮提供可访问名称，操作时保留可见焦点。开关可读出当前开关值，滑块可用方向键调整并读出档位。对话框打开时移入焦点，Esc 与关闭按钮走相同的退出规则，关闭后将焦点还给入口。点击遮罩时保留当前对话框。含有未保存修改的设置先给出保存或撤销选项。

### 说清异常和下一步

状态文案写当前发生了什么、影响什么和下一步。空列表解释当前缺少哪类内容，有筛选时区分「暂无记录」和「没有符合条件的结果」。暂时不可用的操作提供短原因，失败后能重试时把入口放在失败项旁。技术数值明确区分最近记录、估算和未知。正常界面保留当前操作所需的短标签。

### 让用户有机会撤回

钉住、撤回记忆等可即时撤销的操作，在反馈里提供「撤销」，并留出比普通提示更长的响应时间。覆盖冲突和清空数据等需要先判断后果的操作，在对话框里说明对象、范围与结果。危险确认默认聚焦取消。

### 窄窗口优先保住主区

先省略导航里的较长标题，再把列表与右侧面板转成按需打开的浮层。主内容、输入和关键入口继续可见。菜单根据触发点与可用空间选择展开方向，长内容在自己的阅读区域滚动。深浅主题下沿用同一套布局、选中语义和焦点规则。

## 发起与继续任务

### 输入与命令

- 工作区首页和独立对话首页将输入框居中。已有会话将输入固定在纸面底部，计划条贴在其上方，展开的清单覆盖时间线，保留阅读区尺寸。
- `/` 菜单按「操作」和「Skill」分组。首页优先向下展开，已有会话优先向上。可用空间不足时选择空间更充足的一侧并收紧列表高度，菜单保持在纸面内。过滤时列表内容独立滚动，鼠标悬停只更新高亮，方向键越界时做最小滚动。Esc 关闭并保留输入。
- Skill 选中后以整段名称出现在输入区，所选条目只用于本次消息。模型菜单按厂商分组，模型名与上下文窗口同列，输出上限可看悬停提示。下方的思考区保留控件位置，默认档位变更等提示写在标题行。菜单关闭时确认选择，下一次运行使用新设置。
- 文件拖入会话时显示落点。工作区可选择随消息发送或只加入文件夹，独立对话可随消息进入会话工作目录。材料按上传、解析、索引、可检索表达进展。

### 执行、依据与交付

- 运行中的执行过程逐步展开，结束后可收起。提问、审批、最终回复和交付留在会话时间线。审批卡写清动作、位置和预期影响，主要操作直接说明后果。
- 回复首段先给结论。引用角标提供原文片段，可定位右侧原文，或引用到下一条消息。「本次参考」依次列出工作方式版本、常驻记忆与检索命中。记忆新增和待确认入口贴近对应回复。
- 文件以可直接打开的交付卡呈现。右侧成果保留交付版本，文件夹树展示现在的文件。运行统计在对应回复下方靠右排列，用图标、数值和悬停提示说明各项含义。窄窗口减少常驻统计项，保留回复与互动入口的位置。
- 「撤销本次修改」逐个显示文件状态。可直接撤销的默认勾选，已恢复原状的不可选，有后续修改的默认不选并要求明确确认。提交后逐项反馈，撤销也写入「最近修改」。撤销范围限于选中文件的内容。

## 工作区背景与知识

**背景**说明在这个工作区开始新任务时会带上什么。工作方式原地阅读和编辑，版本历史能看差异，恢复旧版时另存为新版本。Agent 建议显示变化片段，可直接接受、编辑后接受或忽略。记忆冲突并排呈现已保存与新发现的内容。

常驻记忆按钉住优先、再按约束、偏好、决定、事实及最近使用排序。分界线标出常驻与按需召回的边界。拖拽钉住时，列表重排并同步移动分界线。预算和限额见[运行参数与限额](../docs/limits.md#工作方式与记忆)。

**知识**提供「检索／索引」。检索按文件、记忆和会话摘要查找并预览，可将结果引用到新任务。索引集中展示范围、处理进度、可检索状态与失败原因，提供暂停、重扫、排除、重新纳入和重试。全文、语义和文字识别的可用性在知识页可见，缺组件时可跳转安装。

## Skill、运行组件与设置

### Skill 使用方式

Skill 采用独立页面。顶栏选择全局或指定工作区，左栏显示来源、计数和同名冲突，选中扫描目录来源后在搜索工具条管理总开关和目录。状态筛选和目录采用锚定浮层，开合保留列表位置。页头与视图导航固定，结果在纸面内容区滚动。已安装行展示名称、摘要、来源、版本与一个三态菜单。点击条目打开包阅读器。

| 菜单选项 | 对下一次运行的含义 |
|---|---|
| 停用 | 从 `/` 移除，也不进入运行目录。 |
| 可选择 | 在适用范围内可从 `/` 显式选入当前消息。 |
| 每次带上 | 在适用范围内自动进入新运行的目录，也可从 `/` 选择。Agent 按需加载正文。 |

目录缺失时显示原因并禁用菜单，纳入失败时保留原有状态并反馈原因。工作区私有条目只出现在所属工作区的输入菜单。同名项保留来源，默认偏好影响排序。已安装页头提供唯一手动添加入口，弹窗并列展示 GitHub、本地文件和直接编写。校验预览和返回修改时保持外框尺寸，正文在弹框内滚动。阅读器在渲染和源码之间切换。技能市场按安装量显示带简介的卡片，支持搜索，安装前选择落点。运行时冻结和资源规则以[Skill 机制](../docs/skills.md)为依据。

### 运行组件与设置

组件页说明组件提供的能力、缺失时的影响和当前状态，安装、取消和重试留在对应组件上。设置覆盖应用，底层会话保留。分区切换保留草稿，修改工具策略后提供保存与撤销。模型连接展示配置文件及读取状态。危险操作在数据管理区明确作用范围并要求确认。

## 开发者视图

「设置 → 通用 → 开发者模式」是本机展示偏好，默认关闭。开启后，工作区会话和独立对话的主纸面右上角都有「聊天／日志」。切换保留输入草稿、聊天阅读位置和各会话的日志筛选、选中轮次、展开项与滚动位置。关闭开发者模式回到聊天。窄窗口的右侧查看浮层从切换入口下方展开。

| 入口 | 内容与操作 |
|---|---|
| 日志 → 事件 | 按发生顺序阅读，可按事件类型筛选。展开事件查看原始 JSON，从模型请求事件跳到对应轮次。 |
| 日志 → 轮次 | 行内呈现模型、耗时与输出量，在所选轮次下方展示重建的请求。日志保留 JSON 导出入口。 |
| 日志 → 压缩 | 查看各次压缩的前后估算和摘要。压缩操作也能在事件中定位。 |
| 右侧 → 查看 | 从完成的 Shell 步骤或对应日志事件打开终端输出。命令、输出与退出码归在同一次调用下。 |
| 聊天输入框右侧 | 点击上下文圆环查看最近请求、压缩后估算、当前模型预算与会话累计输入输出。斜杠菜单内的压缩项共用占用数据。缺少请求记录时显示未知态。 |

## V1–V4 的误区

| 曾经的取舍 | 暴露的问题 | 保留下来的判断 |
|---|---|---|
| 一列同时容纳独立对话、工作区、会话和资源入口 | 每扩充一项能力就拉长侧栏，收起会话目录也会牵连导航。 | 全局轨道承担去向，左侧列表只服务于当前范围。 |
| 通过移动入口解决层级问题 | 概览、对话和各专题同时占入口，位置与视图切换互相竞争，窄窗口尤为明显。 | 工作区首页归入「对话」，同一范围的视图紧跟面包屑，会话内切换留在主纸面。 |
| 用分隔线和相近重量的容器组织页面 | 用户需要同时扫读多层边界，很难迅速定位任务正文、当前动作和需要决定的内容。 | 明度与留白建立空间，连续内容用行，决定和交付用卡片。 |
| 先为每项能力安排管理页 | 用户能找到记忆、知识和 Skill，却难从一次任务中看出采用了什么、如何追查。 | 在输入、回答和结果旁保留相应入口，管理页承接集中编辑与审阅。 |
| 把动效当作局部样式 | 展开、拖拽和重排缺少连贯反馈，用户需要重新找变化后的内容。 | 动效交代来源、去向与状态，窄窗口和减少动态效果下也靠结构和文字表达变化。 |
